# 02 模块专项训练与功能清单

> 功能清单不是「命令大全」，而是**可考核的操作点**。每个 L3 点必须能回答四件事：
> 在哪个选项卡 → 参数怎么填 → 怎么判断做对了 → 做错了报什么错。
> 全量机器可读版本：`data/ops_*.psv`（348 点，字段：编码｜模块｜L2｜L3｜菜单路径｜参数域｜校验点｜错误码）。

---

## 1. 三级拆解规范

```
一级：模块（12 个）
 └ 二级：子模块（按功能族划分，如「草图实体创建」「草图约束」）
    └ 三级：操作点（可独立考核的最小单元，如「直线」「镜像实体」「完全定义草图」）
```

**拆解判据**：一个三级点 = 一次完整的「命令调用 + 参数配置 + 结果校验」闭环。
不满足则继续下拆（例：「圆角」拆成等半径/变半径/面圆角/完整圆角四个点，因为参数面板与失败模式完全不同）。

**状态标注**（清单第七列可扩展为 `status`）：

| 状态 | 含义 | 允许进入下一阶段 |
| --- | --- | --- |
| `未训` | 未接触 | 否 |
| `在训` | 已演示未独立完成 | 否 |
| `已训` | 独立完成且自检通过 | 否 |
| `已考` | 模块考核 100% 通过 | 是 |
| `已核` | 原生截图 + 人工签署 | 是（交付条件） |

## 2. 十二模块训练要点

### 2.1 草图绘制（38 点 / 40h）

**必须练到肌肉记忆的判断**
- 颜色语义：黑=完全定义，蓝=欠定义，黄/红=过定义或冲突；不许靠「看起来对」。
- 几何关系优先级：重合/共线 > 水平竖直 > 相切/同心 > 对称 > 尺寸；关系优先可减少过定义。
- 「完全定义草图」是结果不是命令：先加关系，再用尺寸收口。
- 转换实体引用会带来外部参考，必须判断是否需要「断开参考」。
- 剪裁五种模式的区别：强劲剪裁（拖拽）、边角、在内剪除、在外剪除、剪裁到最近端。
- 3D 草图必须锁轴（Tab 切换），否则空间点乱飞。
- 检查草图合法性：开放端点、自交、零长度、重复实体四类问题。

**高频失败**：矩形未闭合、样条自交、等距自交、镜像后过定义、文字未闭合无法拉伸。

### 2.2 特征建模（53 点 / 56h）

- 五大成形特征：拉伸、旋转、扫描、放样、边界；判据是「截面沿路径的变化规律」。
- 终止条件六种：给定深度 / 成形到一顶点 / 成形到一面 / 到离指定面指定的距离 / 成形到实体 / 两侧对称；**能用「成形到面」就不要用数值深度**，避免改尺寸后失效。
- 薄壁特征与抽壳是两条路：薄壁跟随草图，抽壳跟随实体。
- 圆角四型：等半径、变半径、面圆角、完整圆角；失败先降半径，再换类型。
- 异型孔向导：标准（GB/ISO）+ 大小 + 配合（间隙/过渡/紧配）+ 终止条件；改标准会重置尺寸。
- 阵列优先顺序：线性/圆周 → 草图驱动 → 表格驱动 → 填充；能用特征阵列就不要用草图阵列。
- 实体操作（组合/分割/移动复制/删除保留/缩放）是修图主力，必须理解「多实体」而非「多零件」。
- 参考几何体：基准面至少两个参考，否则定义不唯一。

### 2.3 装配设计（47 点 / 48h）

- 自由度模型：刚体 6 自由度（3 平移 + 3 旋转）；每加一个配合要能说出「消掉哪个自由度」。
- 配合顺序：先定「基准件（固定）」→ 同轴心/重合定位置 → 距离/角度定行程 → 机械配合定运动。
- 过定义识别：MateXpert 分组 + 黄色警告；欠定义识别：拖动零件看是否异常游动。
- 高级配合解决「居中/对称/宽度/路径」，机械配合解决「齿轮/齿条/螺旋/万向节/凸轮/槽口/铰链」。
- 性能三件套：轻化（默认）、SpeedPak（子装配）、Large Design Review（只读大装配）。
- 柔性/刚性：子装配要动必须设柔性，但会显著降性能，交付前改回刚性。
- 干涉检查与间隙验证必须同时做：干涉体积=0 不等于装得进去。
- BOM 依赖自定义属性，属性缺失会导致明细表缺行。

### 2.4 工程图生成（36 点 / 44h）

- 图幅与比例：GB 优先 1:1；A0~A4 图框与标题栏必须来自 GB 模板。
- 第一视角是国标默认，投影类型错会导致视图位置全错。
- 视图类型选择：主视→投影→剖视（全剖/半剖/旋转剖/阶梯剖）→局部放大→断裂→裁剪。
- 尺寸三条铁律：不重复、不封闭、不标注到不可见轮廓。
- 公差：配合代号（H7/g6）与极限偏差二选一，不能同时标；未注公差在技术要求声明 GB/T 1804-m。
- 形位公差五要素：符号、公差值、基准、指引线、框格；基准字母不得重复。
- 表面结构用 GB/T 131 符号，统一注写在标题栏右上角，个别另注。
- 图层是线宽的唯一来源：OUTLINE 0.7 / DIM 0.35 / HIDDEN 0.35 虚线 / CENTER 0.35 点画线。
- 导出 PDF 必须 1:1，DWG 必须做字体与图层映射。

### 2.5 曲面设计（26 点 / 32h）

- 曲面是「零厚度片体」，实体是「闭合体」；缝合 + 加厚是曲面转实体的主路径。
- 边界曲面优于放样曲面：可控影响因子，抗褶皱。
- 缝合容差决定成败：缝隙大于容差必失败，先查缝隙再加大容差。
- 剪裁要判断保留侧；剪裁失败多数是工具面未贯穿。
- 中面用于钣金/薄壁件简化，成对面必须近似平行。
- 曲面质量检查：最小曲率半径必须大于料厚，否则加厚必失败。
- 曲率梳看连续性：断裂=位置连续，尖角=相切不连续，突变=曲率不连续。

### 2.6 钣金设计（26 点 / 30h）

- 基体法兰决定厚度、折弯半径、K 因子三件套，后续全部继承。
- 折弯系数四种：K 因子、折弯系数、折弯扣除、折弯计算表；同一零件只能一套。
- 展开失败的两大原因：成形工具未压缩、折弯相互干涉。
- 边线法兰的位置三选项（材料在内/在外/折弯在外）直接改变展开长度。
- 转换到钣金要求实体等厚且有明确折弯边，否则先抽壳。
- 放样折弯要求两轮廓开放且点数一致。
- 展开图导出 DXF 必须把折弯线单列图层，否则下料无法折弯。

### 2.7 焊件设计（20 点 / 24h）

- 结构构件 = 轮廓 + 路径（3D 草图或边线）+ 组；轮廓来自「焊件轮廓」库。
- 剪裁/延伸的顺序由特征树顺序决定，改顺序会改结果。
- 角撑板/顶端盖/支撑板是连接件，不是焊缝。
- 焊缝分「圆角焊缝」与「焊道」，工程图用焊接符号表达。
- 切割清单靠自定义属性（长度/数量/材料），属性不全则清单缺列。
- 焊件工程图必须带切割清单表，且与实体数量一致。

### 2.8 渲染与仿真（28 点 / 40h）

- PhotoView 360 与 SolidWorks Visualize 是两套；2021 内置的是 PhotoView 360。
- 渲染四要素：外观（材质/颜色/纹理）、布景、光源、相机。
- Simulation 算例类型决定夹具与载荷的合法性：静应力/频率/屈曲/热/疲劳/非线性。
- 网格是精度与成本的唯一杠杆：先全局后局部控制，圆角与孔必须细化。
- 结果判读：最大应力位置要能解释；全红通常是网格过粗或载荷过大。
- **FOS ≥ 1.5 是放行线**（与工作区 AGENTS.md 的 CAE 门禁一致）。
- 夹具不足 → 刚体位移；夹具过多 → 人为应力集中。

### 2.9 模具设计（16 点 / 24h）

- 顺序不可乱：缩放 → 拔模分析 → 分型线 → 关闭曲面 → 分型面 → 切削分割。
- 分型线必须闭合，否则后续全断。
- 关闭曲面用于堵通孔，相切优先于接触。
- 分型面要大于零件投影，否则切削分割失败。
- 型心/型腔分离后要检查壁厚与干涉。
- 收缩率按材料给定（ABS 约 0.5%，PP 约 1.5%~2.0%），写在缩放比例里。

### 2.10 管道与布线（18 点 / 24h）

- Routing 是插件，未启用则无工具栏。
- 三条产品线：管道（Piping）、管筒（Tubing）、电气（Electrical）。
- 步路三方式：拖拽、自动步路、正交步路；正交必须锁轴。
- 配件与管径必须同规格，否则接头报错。
- 弯管半径 ≥1.5D，否则制造不出来。
- 从-到清单是交付物，长度必须与三维一致。
- 展平线路用于下料，长度偏差来自折弯系数。

### 2.11 配置与设计表（18 点 / 20h）

- 配置 = 同一零件的多个状态；压缩状态、尺寸、特征、属性都可按配置区分。
- 设计表本质是 Excel：列=参数，行=配置；`$配置$`、`$属性$`、`$备注$` 是保留字。
- 参数名必须与模型完全一致（含 @零件名），否则导入失败。
- 派生配置继承父配置，父改子变。
- 方程式与全局变量是参数化的根，循环引用必崩。
- 打包（Pack and Go）必须包含工程图与参考，否则交付缺件。

### 2.12 宏与二次开发（22 点 / 36h）

- 录制宏只能录「命令级」操作，PropertyManager 内的选择常录不全，需手改。
- API 入口：`SldWorks.Application` → `ModelDoc2` → `SketchManager/FeatureManager/Extension`。
- 2021 类型库随安装注册；早绑定需引用 `SOLIDWORKS 2021 Type Library`。
- 选择是 API 的最大坑：`SelectByID2` 的名称必须与特征树一致。
- 事件需要 `WithEvents`，且对象生命周期要保住，否则回调丢失。
- 批处理必须加 `On Error` 与日志，否则一个文件失败整批中断。
- 导出用 `SaveAs3`/`Extension.SaveAs`，格式常量按 2021 类型库取。

## 5. 模块训练执行检查表（每模块必填）

| 检查项 | 判据 |
| --- | --- |
| 三级清单完整性 | 该模块 L3 点全部登记，无「其他」兜底项 |
| 参数域可执行 | 每个数值参数给出 min/max/default，枚举给出全部取值 |
| 校验点可测量 | 至少 1 条可用「测量/检查/质量属性」验证 |
| 错误分支可触发 | 至少 1 个错误码 + 触发场景 + 修复动作 |
| 版本合规 | 路径全部命中 2021 白名单入口 |
| 用例覆盖 | 26 条用例覆盖该模块 ≥80% 的 L3 点 |
