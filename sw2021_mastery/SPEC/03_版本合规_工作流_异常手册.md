# 03 版本合规 · 工作流 · 异常处置手册

> 本手册的所有路径与参数，以**本机实测的 SOLIDWORKS 2021 SP5（29.5.0.0070，简体中文）**为准。
> 错误码为训练体系内部编码（`SW-模块-序号`），括号内为 2021 实际提示语义；**不是 SolidWorks 官方错误号**，便于台账检索与回归引用。

---

## 1. 版本基线（实测，2026-11-18）

| 项 | 实测值 | 取证方式 |
| --- | --- | --- |
| 产品名 | SOLIDWORKS 2021 | `SLDWORKS.exe` VersionInfo |
| 版本 | 29.5.0.0070（SP5.0） | 同上 |
| 安装路径 | `D:\SOLIDWORKS (2)\SLDWORKS.exe` | 注册表 Uninstall + 文件存在性 |
| ProgID | `SldWorks.Application` | `HKCR\SldWorks.Application\CLSID` |
| CLSID | `{0A5BC87B-FDBF-4A0B-BC8A-DE1271220E81}` | 同上 |
| LocalServer32 | `D:\SOLIDWORKS (2)\sldworks.exe` | 同上 |
| 界面语言 | 简体中文 | 已安装 Chinese Simplified Resources 29.150.0070 |
| 同机其他版本 | SOLIDWORKS 2026 SP03.2（34.3.2.3），注册于 `D:\Program Files\SOLIDWORKS Corp2026` | 注册表 Uninstall |

**结论**：当前 `SldWorks.Application` 绑定的是 2021，但机器上确实存在 2026 安装记录。
这是一条**必须在训练第一天就封堵**的风险，而不是「应该不会出错」。

## 2. 双版本隔离 SOP（强制）

| 步骤 | 动作 | 失败判据 |
| --- | --- | --- |
| S1 | 只用绝对路径启动：`D:\SOLIDWORKS (2)\SLDWORKS.exe` | 出现 `D:\Program Files\SOLIDWORKS Corp2026` 进程 |
| S2 | 启动后立即读 `Application.RevisionNumber` | 不以 `29.` 开头 → 立即退出并记 FAIL |
| S3 | 训练产物统一存 `sw2021_mastery/work/` | 文件出现在 2026 的最近文档列表 |
| S4 | 每张截图必须含标题栏版本字样 + 文件路径 | 截图无法证明版本 → 证据作废 |
| S5 | 禁止用 2021 打开 2026 保存过的文件 | 出现「未来版本」提示 → 重新出图 |
| S6 | 每周一次全量审计：抽查 30 条路径，逐条比对界面 | 命中 2022+ 命令 → 该批内容整体回退 |

> 关键认知：**Downgrade 不存在**。2021 无法保存为更低版本，2026 保存的文件 2021 也打不开。
> 因此「版本串味」不是文案问题，是**文件级不可逆**问题。

### 2.5 验证台资质门（VB-0，2026-11-18 新增）

在跑任何 G2 实操验证之前，先证明这台机器**能正常开到文档并操作**，否则所有「验证失败」都会变成环境噪声。

| 检查 | 判据 | 不通过的表现 |
| --- | --- | --- |
| 版本 | 版本化 ProgID 连上且 `RevisionNumber` 以 `29.` 开头 | 连到 2026 |
| 空载响应 | 主窗口 `SendMessageTimeout(WM_NULL)` 返回真，`CPU Δ/6s < 1` | 启动即卡 |
| 建件响应 | `NewDocument` ≤30s 返回，且建件后 `CPU Δ/6s < 1`、`Responding=True` | 单核 100% 空转 |
| 选择响应 | `SelectByID("前视基准面","PLANE",...)` ≤5s 返回真 | RPC 309s 超时 |
| 显卡 | 型号在 2021 认证列表内（RTX 40 系 / Intel UHD 均不在） | 文档一开就空转 |

**本机实测（2026-11-18）**：前两项通过，第三项通过但第四项失败 → **VB-0 不通过，G2 阻断**。
证据见 `out/evidence/environment_blocker.json`。判定为验证台不合格，而非被验证内容不合格。

## 3. 版本合规双校验

### 3.1 白名单（主校验）

每条步骤路径必须能拆成：`2021 存在的选项卡/菜单入口` + `2021 存在的命令名`。

白名单入口（`data/version_rules.json#allowed_ui_tabs`）：
`文件/编辑/视图/插入/工具/窗口/帮助`、`草图/特征/曲面/钣金/焊件/模具工具/装配体/工程图/注解/布局/评估`、`Routing/Simulation/PhotoView 360`、`ConfigurationManager/DimXpert/DisplayManager`。

当前机器校验：**界面步骤 16380/16380 = 100% 命中**；宏代码上下文 1201 条单列（非界面路径）。

### 3.2 黑名单（辅助校验）

| 禁止 token | 原因 | 置信度 |
| --- | --- | --- |
| `SOLIDWORKS 2022/2023/2024/2025/2026` | 版本串味 | 高 |
| `另存为旧版本` / `SaveAsPreviousVersion` | 2021 不具备降版保存 | 中（需 2021 原生确认菜单不存在） |
| `3DEXPERIENCE 平台任务` | 2021 为本地桌面工作流 | 中 |

机器校验：三套资产 **0 命中**。

### 3.3 版本边界速查

| 能力 | 2021 是否具备 | 训练处理 |
| --- | --- | --- |
| CommandManager / PropertyManager / ConfigurationManager | 具备 | 正常训练 |
| 结构系统（Structure System） | 具备（2019 引入） | 正常训练 |
| 磁性配合（Magnetic Mates） | 具备（2020 引入） | 正常训练 |
| 柔性子装配 | 具备 | 正常训练 |
| 大装配 LDR / SpeedPak / 轻化 | 具备 | 正常训练 |
| 降版保存 | **不具备** | 禁止出现在任何步骤中 |
| 后续版本新增命令 | 不具备 | 白名单直接拦截 |

> 处理原则：**宁可标「待核验」也不猜**。任何无法用 2021 界面截图证明的命令，进 `review.result=pending` 队列，不得计入已训练。

## 6. 大装配性能优化

| 手段 | 操作 | 收益 | 代价 |
| --- | --- | --- | --- |
| 轻化 | 装配体选项卡→轻化 | 加载降 50%~70% | 不能直接编辑特征 |
| SpeedPak | 子装配右键→SpeedPak | 内存降 40%+ | 仅保留配合面 |
| LDR | 文件→打开→Large Design Review | 万级零件可开 | 只读 |
| 冻结特征 | 特征树右键→冻结 | 重建时间降 | 冻结段不可改 |
| 压缩 | 压缩非关键零部件 | 立即见效 | 配合失效风险 |
| 图像质量 | 选项→图像质量→降低 | 显示流畅 | 视觉精度下降 |
| 配合简化 | 用配合参考/子装配替代逐件配合 | 求解快 | 需重构 |
| 关闭 RealView | 视图→显示 | 显卡压力降 | 观感下降 |

**判定阈值**：500 零件装配 ≤180s 加载；2000 零件用 LDR；>5000 零件必须 SpeedPak + 轻化 + 分块。
