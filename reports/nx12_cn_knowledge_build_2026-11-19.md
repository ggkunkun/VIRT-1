# NX 12.0 中文版知识体系构建报告（2026-11-19）

## 1. 结论

已建立 **NX 12.0 简体中文专属知识库**：`knowledge_base/nx12_cn/`。

- 命名基准：从本机安装介质解析出 **2454 条原生命令**，其中 **2453 条有官方中文名**（唯一无中文名的 `UG_APP_NOPART` 是应用环境切换标识，不是菜单命令），**2149 条有可重建的菜单路径**，**83 条原生快捷键**。
- 文档：工作流层 **32 篇**（基座/草图/建模/装配/工程图/曲面/钣金/模具/CAM/跨模块/故障/命令字典）；另有 2026-11-18 生成的全量训练层 `training/` **38 篇**（含 4424 条含插件命令、13272 条用例）。
- 审计：工作流层文档中 **232 处命令引用、205 处路径末级**逐条与安装介质比对，**0 处不符**。
- 实测：NXOpen 跑通“新建 mm 零件 → 4 条草图直线 → 拉伸 10 mm → 体积 60 000 mm³ → 保存 .prt”，体积相对误差 **1.2e-14**。

```json
{
  "ok": true,
  "basis": "measured",
  "bbox": [0, 0, 0, 100, 60, 10],
  "volume_mm3": 59999.99999999999,
  "volume_expected_mm3": 60000.0,
  "volume_error_pct": 1.21e-14
}
```

步骤：`uf.Part.New` → 4 条 `Curves.CreateLine`（100×60 闭合轮廓）→ `UF.Modl.CreateExtruded`（0→10 mm）→ `UF.Modeling.AskMassProps3d`（体积）→ `Save`。
说明：`AskMassProps3d` 的 `units=4` 返回 m³/kg，脚本已换算 mm³；这一点已写入代码注释，避免“体积为 0”的误判。


审计规则：

2. 紧跟的中文名必须与介质中文名/菜单名/功能区名匹配（去助记符、括号、省略号后比对）；
3. 同一行的菜单路径末级必须与命令中文名匹配；

## 6. 诚实边界（未验证/不可宣称）

1. **不是每条命令都有逐步 SOP**：2454 条是原生命令面（可检索；含插件的 4424 条见 `training/`），32 篇工作流文档覆盖的是核心工作流与高频命令；长尾命令由全量索引定位菜单，不承诺逐步教程。
2. **界面像素位置未取证**：功能区组的位置随角色/窗口变化，本库只给菜单路径与命令查找器方法，不写“第几个图标”。
3. **CAM 工序子类型中文名**来自 `libcams*_nlm.txt`（实测），但本次未在 GUI 中逐个打开“创建工序”对话框截图核对；刀轨/后处理未在本轮做真实机床试切。
4. **VERICUT/SSCNC 仿真**未在本轮运行；相关判据引自 AGENTS.md §2E 与工具链既有约定，属于“流程门”，不是本轮实测。
5. **参数推荐值**（拔模角、步距、K 因子、收缩率）为工程经验/标准推荐，不是 NX 软件限制；实际以材料、刀具、机床试切为准。
6. **本机安装夹带第三方插件**（YANGJEE/YSUG/quick_cam/KASA/MS_*），本库只收录 Siemens 原生命令；插件菜单不进入命名基准。
7. **GB 标准数值**（幅面/字高/线宽/公差/粗糙度）引自 GB/T 14689、14690、14691、4457.4、4458、1800.1、1182、131；NX 对话框的实际默认值可能随模板不同，需在“制图标准/制图首选项”中核对。

## 8. 结论边界

本知识库能保证：**在 NX 12.0 简体中文界面中，按文档给出的菜单路径能找到对应原生命令，且中文名与屏幕一致**（232 处引用、205 处路径末级已机检）。
不能保证：所有命令的加工/设计结果都经真实机床或试模验证——那需要材料、刀具、机床与试模数据，本轮只完成了 CAD 建模闭环的实测。
