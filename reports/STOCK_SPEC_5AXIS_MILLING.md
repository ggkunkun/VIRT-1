# 五轴联动铣削毛坯工艺规范

| 项目 | 内容 |
|---|---|
| 文档编号 | SPEC-STOCK-5AX-001 |
| 版本 | 1.0（2026-11-18） |
| 适用机型 | 五轴联动铣削中心（摆头+转台，X/Y/Z/B/C） |
| 适用零件 | 航空发动机封闭式叶轮 AE-CI-258 及同类带角向特征的复杂曲面件 |
| 强制等级 | 强制（毛坯定义为圆柱体即判工艺不合格，见第 6 章） |

## 1. 目的与范围

规定五轴联动铣削毛坯的几何形式、基准体系、装夹适配结构、余量与验证判据，
确保毛坯能适配多轴联动动作，避免干涉、过切与定位偏差。

适用范围：毛坯设计、工艺审查、VERICUT 工位搭建、首件试切。
不适用：纯车削工序、车铣复合的第一序车削（见 6.3 例外）。

## 2. 术语

- **包容块**：完整包住成品包络并留余量的长方体毛坯；六面经铣削，相邻面相互垂直。
- **基准面**：主基准 A（底面）、第二基准 B/C（两个相邻侧面）、对刀面（顶面）。
- **装夹适配结构**：夹持带、工艺耳座、中心孔、角向销孔、吊装孔、避让倒角等。
- **角向基准**：约束零件绕主轴回转自由度的几何要素（基准边、键槽、销孔、工艺平面）。

## 3. 圆柱体毛坯的工艺局限性、装夹稳定性与精度风险

### 3.1 工艺局限性

| 局限 | 说明 | 后果 |
|---|---|---|
| 无角向基准 | 圆柱面绕轴线无特征，C 轴零点只能靠寻边/探针确定 | 叶片相位、流道分度无硬件基准 |
| 需先车后铣 | 圆柱锻件通常要先车端面/外圆才能装夹 | 多一次装夹，基准转换，周期与成本增加 |
| 无法传递扭矩 | 三爪摩擦夹持，切向切削力靠摩擦 | 五轴摆头侧铣时易微小滑移 |
| 夹持高度受限 | 卡盘爪高通常 40–60 mm，落在 B 轴摆动包络内 | 刀柄/主轴与卡爪干涉风险 |
| 材料利用率低 | 圆柱包住方形包络需更大直径 | 钛合金材料浪费，机时增加 |

### 3.2 装夹稳定性（量化）

| 指标 | 圆柱（三爪卡盘） | 矩形包容块（虎钳/垫高座） |
|---|---|---|
| 接触形式 | 3 条线接触 | 2 个平面接触 |
| 接触面积（Φ258、夹持 25 mm） | ≈3×2×25 = **150 mm²** | 2×340×25 = **17 000 mm²** |
| 抗扭转 | 仅靠摩擦（μ≈0.15） | 摩擦 + 平面约束 |
| 抗倾覆 | 线接触，悬伸大时易微转 | 平面约束，抗倾覆高 |
| 夹持变形 | 三爪点压，薄壁易椭圆化 | 面压，变形小 |

结论：同为 25 mm 夹持高度，包容块接触面积约为圆柱的 **113 倍**，抗扭与抗倾覆能力不在同一量级。

### 3.3 加工精度风险

| 风险 | 机理 | 量化（r=129.03 mm 处） |
|---|---|---|
| 角向定位误差 | 无硬件基准，C 轴零点靠探针 | 0.05°→**0.11 mm**；0.1°→0.23 mm；0.2°→0.45 mm |
| 同轴度/壁厚偏差 | 车-铣两次装夹基准转换 | 典型 0.03–0.08 mm |
| 夹持滑移 | 切向力超过摩擦极限 | 侧铣时突发过切 |
| 振动/颤振 | 线接触刚度低、悬伸长 | 表面 Ra 恶化、刀具磨损加快 |

### 3.4 五轴特有风险

- B/C 联动摆头时，主轴/刀柄/刀杆扫掠半径大于圆柱半径，**卡爪与刀柄干涉**。
- 流道从 OD 槽口进入时，刀轴需大角度倾斜；卡爪高度限制刀轴矢量范围。
- 圆柱无法提供第二/第三基准，五轴联动中的坐标旋转误差无法通过基准面复核。

## 4. 替代毛坯结构方案（强制）

### 4.1 基本形式：矩形包容块

- 六面铣削，相邻面垂直度 ≤0.02/100；
- 尺寸 = 成品包络 + 余量（侧 3 mm、顶 3 mm、底 5 mm）；
- 本例：成品 Ø258.06×74.85 → 毛坯 **264.06×264.06×82.85**；
- 翻面工序：残余块 **264.06×264.06×25.85**（Y 向不切，保持长方体）。

### 4.2 基准定位面

| 基准 | 面 | 要求 |
|---|---|---|
| A（主） | 底面 | 平面度 0.01，Ra ≤3.2 |
| B | 左侧面 | 与 A 垂直度 0.02/100，Ra ≤3.2 |
| C | 前侧面 | 与 A、B 垂直度 0.02/100 |
| 对刀面 | 顶面 | 平面度 0.01；WCS 原点 = 顶面中心 |

### 4.3 装夹适配结构

| 结构 | 参数 | 作用 |
|---|---|---|
| 夹持带 | 高 24 mm、Ra ≤3.2、平面度 0.02 | 虎钳/软爪面接触，避开刀路（间隙 ≥1 mm） |
| 避让倒角 | 2×45°（底面四边） | 防止夹持干涉与毛刺 |
| 工艺耳座（可选） | 30×40×20，两处对称 | 压板/螺栓辅助夹紧，OP3 切除 |
| 中心孔（可选） | Ø76.2 通孔 + 角向销孔 Ø8H7 | 翻面芯轴定位 + 防转 |
| 吊装孔（可选） | 2×M12 | 钛合金块吊装安全 |

### 4.4 材料与状态

- TC11（Ti-6.5Al-3.5Mo-1.5Zr-0.3Si）或按图纸；去应力退火状态；
- 硬度与超声波探伤按材料规范执行；批次/炉号可追溯。

### 4.5 方案变体

| 变体 | 适用 | 关键参数 |
|---|---|---|
| B1 标准块 | OP1 虎钳 + 垫高座 | 264.06×264.06×82.85，夹持带 24 mm |
| B2 带耳座块 | 需要压板双保险 | 耳座 2 处，OP3 切除 |
| B3 带中心孔块 | OP3 内胀芯轴翻面 | Ø76.2 通孔 + Ø8H7 角向销孔 |

## 5. 毛坯选型验证标准

### 5.1 判据（全部可证伪）

| 门 | 判据 | 反证（必须红） |
|---|---|---|
| G-ENVELOPE | 成品表面 20000 采样点全部在毛坯内，最小余量 ≥3 mm | 掺入 1 个外包点 ⇒ FAIL |
| G-DATUM | 六面垂直度 ≤0.02/100，平面度 ≤0.01 | 磨斜 0.05 ⇒ FAIL |
| G-CLAMP-BAND | 夹持带高 ≥20 mm，平面度 0.02，Ra ≤3.2 | 夹持带 10 mm ⇒ FAIL |
| G-CLEARANCE | 最低刀路 Z − 钳口/夹具顶面 ≥1 mm | 刀路降 2 mm ⇒ FAIL |
| G-SWEEP | B/C 全行程扫掠与夹具/卡盘间隙 ≥5 mm | 卡爪加高 20 mm ⇒ FAIL |
| G-UNIQUE | 场景内毛坯组件 = 1，模型图元 = 1 | 复制一个 Stock ⇒ FAIL |
| G-WCS | 原点在毛坯上表面中心，Z0=上表面 | 原点放底面 ⇒ FAIL |
| G-MILL-ONLY | 无 G96/G97/G99/G70/G71/G72/G76/G32/G33/M19 | 插入 G96 ⇒ FAIL |

### 5.2 验证流程

1. 几何：三坐标/平台测量六面垂直度、平行度、平面度；
2. 包容性：设计模型 20000 点采样，`outside=0`；
3. 装夹：VERICUT 工位按第 8 章参数落位，跑 `verify_scene_physics.py`；
4. 五轴动作：B/C 全行程扫掠 + NC 仿真，检查干涉/过切/超程；
5. 首件：三坐标叶型 + 超声壁厚 + 动平衡。

## 6. 禁止使用圆柱体毛坯的场景

### 6.1 明确禁止

1. 封闭/半封闭叶轮、整体叶盘的 5 轴流道铣削（刀具需从 OD 槽口进入，卡爪在摆动包络内）。
2. 需要角向基准的零件（叶片相位、孔系分度、端口朝向）。
3. 摆头+转台机床，且卡盘爪高 >30 mm 落在 B 轴摆动扫掠内。
4. 薄壁件（壁厚 <3 mm）用三爪点夹持。
5. 一次装夹需加工 5 个面的零件。
6. 要求 X/Y 找正 ≤0.02 mm 的零件。

### 6.2 判定规则

出现下列任一条件即判"圆柱毛坯不合格"：
- 无硬件角向基准；
- 夹持为线接触且切向力 > 摩擦极限；
- 卡爪/卡盘进入 B/C 摆动扫掠包络；
- 需要翻面且翻面后无平面基准可贴。

### 6.3 允许的例外

| 场景 | 条件 |
|---|---|
| 纯回转体车削 | 不涉及五轴联动 |
| 车铣复合第一序 | 仅车端面/外圆，后续改用包容块或带角向销的涨套 |
| 圆柱锻件近净成形 | 必须增加铣削基准平面 + Ø8H7 角向销孔，且卡盘在摆动包络外 |

## 7. 技术参数要求（矩形包容块）

| 参数 | 要求 |
|---|---|
| 尺寸公差 | 粗坯 +0.5/0；基准面按 IT8 |
| 余量 | 侧 3 mm、顶 3 mm、底 5 mm（可按材料调整，须实测包容） |
| 平面度 | 基准面 0.01；夹持带 0.02 |
| 垂直度 | 相邻面 0.02/100 |
| 平行度 | 顶/底 0.02 |
| 表面粗糙度 | 基准面与夹持带 Ra ≤3.2；其余 Ra ≤12.5 |
| 倒角 | 底面四边 2×45°；棱边去毛刺 |
| 材料 | TC11 / TC4 / Inconel 718（按图纸），去应力状态 |
| 标识 | 炉号、毛坯编号、二维码、基准符号（A/B/C） |
