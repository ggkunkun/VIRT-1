## 3. 逐项验证方案

### U-06 FANUC 0i-MF / HNC-8：`G43.4` RTCP 标定

| 项 | 内容 |
|---|---|
| 目的 | 标定 B/C 转台枢轴偏置、刀长与 RTCP 变换，使刀尖在五轴联动中保持在编程点 |
| 器材 | Ø50 标准球（或标准圆柱）+ 千分表/触发测头；球心坐标已知；机床预热 ≥30 min |
| 方法 | 1) 球装在工作台中心，用测头测球心 `(X0,Y0,Z0)`；2) 执行标定程序：`G43.4 H1`，在 `B=0/±15/±30`、`C=0/90/180/270` 共 20 个姿态下用测头回测球心；3) 由球心偏差反算枢轴偏置与刀长补偿误差；4) 写入机床参数/刀补后复测 20 点 |
| 判据 | 刀尖位置误差 **≤0.050 mm**（全姿态）；B/C 反向间隙 **≤0.010°**；球心重复性 **≤0.010 mm** |
| 误差预算 | 0.050（RTCP）+ 0.020（热漂移）+ 0.010（刀长）+ 0.020（伺服）= **0.100 mm** < OP2 实测最小间隙 0.307 mm 的 1/2，留够安全余量 |
| 证据 | `production/reports/evidence/U-06_rtcp.csv`（20 行：B、C、ΔX、ΔY、ΔZ）+ 标定前后参数截图 |
| 失败处置 | 误差 >0.05 mm：查枢轴参数、刀长基准、测头标定；连续 2 次无收敛 → 停线，联系机床厂重标 |

参考程序骨架（FANUC/HNC，球心在 G54 原点）：

```gcode
G21 G90 G54 G49
T1 M06
G43.4 H1
B0.  C0.   G00 X0 Y0 Z50.
G01 Z0 F200            (测头/表触球顶)
(逐姿态: B±15/±30, C0/90/180/270, 记录球心偏差)
G49
M30
```

### U-07 SINUMERIK 840D sl：`TRAORI` 方向编程验证

| 项 | 内容 |
|---|---|
| 目的 | 验证三方言发射器按 `A3/B3/C3` 发出的刀轴矢量与转台 B/C 实际姿态一致（符号、基准、单位） |
| 方法 | 1) 在 `TRAOF`/`TRAORI` 下用同一 `tool_axis(B,C)` 向量做 3+2 定位，用千分表贴标准块端面测刀轴垂直度；2) 对齐 `A3/B3/C3` 与 `B/C` 的映射；3) 跑 OP2 前 3 条流道的低速空切 |
| 判据 | 刀轴方向偏差 **≤0.05°**；标准块端面跳动 ≤0.02 mm；无 840D 报警（14009/14011 等转换类） |
| 证据 | `evidence/U-07_siemens_orientation.csv` + `A3/B3/C3` 与实测姿态对照表 + 报警历史截图 |
| 失败处置 | 方向相反（符号错）：按机床实际旋转方向反转 `tool_axis()` 的 B 或 C 符号；必须回归 `tests/test_production_system.py` 的三方言用例 |

### U-08 刀长重复性与热漂移

| 项 | 内容 |
|---|---|
| 方法 | 1) T1/T2 各连续换刀 5 次，对刀仪/机内测头测刀长；2) 主轴连续运转 60 min（同转速），每 10 min 测一次标准球 Z；3) B/C 各 ±30° 往返 10 次，测反向间隙 |
| 判据 | 刀长重复性 **≤0.005 mm**；60 min 热漂移 **≤0.020 mm**；反向间隙 **≤0.010°** |
| 证据 | `evidence/U-08_tool_thermal.csv` |
| 失败处置 | 热漂移超标：增加预热循环/在线测头补偿；刀长重复性差：检查刀柄锥面与拉钉 |

### U-10 空运行与安全链

| 项 | 内容 |
|---|---|
| 方法 | 1) 机床锁住 + 图形模拟跑完 OP1/OP2/OP3；2) 单段 + 10% 进给 + 距离剩余显示，前 50 段逐段确认；3) 校验存储行程（软限位）与程序包络：本系统实算 OP1 X/Y ±138.53、OP2 机床 X 0..137.2 / Y −17.7..12.0 / Z 0..392.8、OP3 X/Y ±134.03；4) 实测急停、门锁、气压/冷却联锁 |

| 证据 | `evidence/U-10_dryrun.log`（控制器日志）+ 软限位参数截图 + 急停测试记录 |

### U-01..U-05 首件计量（真实 TC11 毛坯）

| ID | 特性 | 器材/方法 | 样本 | 判据 |
|---|---|---|---|---|
| U-01 | 叶型/流道型面 | 三坐标（MPE ≤0.005 mm，1/10 规则） | 3 个叶片 × 5 截面 × 12 点 = 180 点 | 偏差 **±0.05 mm** 内；超差点 0 |
| U-02 | 叶片/轮盖壁厚 | 超声测厚仪（±0.01 mm） | 3 条流道 × 5 点 | ≥ 图纸最小壁厚，公差 **0 / −0.10 mm** |
| U-03 | 动平衡 | 动平衡机，ISO 1940 G6.3 | 首件 1 件 | 残余不平衡量 ≤ `9549·G·M/n` 计算值；记录去重位置与量 |
| U-04 | 表面粗糙度/完整性 | 便携式粗糙度仪（ISO 4287）+ 10× 放大镜/荧光 | 叶片 5 点 + 流道 3 点 + 轮毂孔 2 点 | Ra **≤1.6 µm**；无微裂纹、无烧伤、无粘刀 |
| U-05 | 轮毂孔与基准面 | 内径千分尺/三坐标 | Ø76.2 孔 3 截面 × 2 方向；端面跳动 | Ø76.2 **H7（0/+0.03）**；端面/外圆跳动 ≤0.02 mm |
| U-14 | 毛坯几何 | 平板/三坐标/粗糙度仪 | 六面 + 夹持带 | 平面度 ≤0.01；垂直度 ≤0.02/100；夹持带 Ra ≤3.2；倒角 2×45° |

## 5. 判定与失败处置总则

1. **安全优先**：任何 U-10/U-16 的失败 → 立即停线，不得以“先跑一件看看”绕过。
2. **一次只改一个变量**：标定/刀补/参数变更必须留变更单，变更后重跑软件门与空运行。
3. **不收敛即熔断**：同一问题连续 2 次修复无收敛 → 停线，出 RCFA（根因分析）后再动。
4. **数据可追溯**：所有证据带仪器编号、校准有效期、操作者、日期；无校准的量具数据无效。
5. **让步放行**：仅限不影响安全与配合的项（如 U-13 换产时间），须有书面偏离单并由工艺/质量会签。
