**关键发现**：本机存在一条硬性分界线——**权重 ≤ 6.0 GB 可整装进显存，全速运行；> 7.5 GB 必须分层 offload，速度掉 3–10 倍**。所有适配决策都围绕这条线。

## 七、使用方式

```powershell
# 日常首选（8B，最快）
ollama run virtu-opt-8b

# 13B 精度档（慢一倍但效果更好）
ollama run virtu-opt-13b

# MoE 14B（等效参数量最大，速度接近 13B）
ollama run virtu-opt-moe14b

# API 调用
curl http://127.0.0.1:11434/api/chat -d '{"model":"virtu-opt-8b","messages":[{"role":"user","content":"你好"}],"stream":false}'
```

**重要**：不要在调用时手动传大于 Modelfile 的 num_gpu，否则 OOM。Modelfile 内的值就是本机实测上限。

重新部署或换机后可执行 `deploy.ps1` 全量重建并自动验证。
