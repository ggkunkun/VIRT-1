# M09 配置定制与多通道 — 标准化操作手册

> 对应模块：Editor Setup 全层级 + Multi Channel + Mazatrol Viewer + 正则表达式
> 事实源：`docs.cimco.com/en/docs/edit/2026/editor-setup/*` 与 `.../regex/`（D 语料）
> 诚实性基线：`CAPABILITY_BOUNDARIES.md`（Machine Simulation/Mazatrol add-on 许可边界；B-02 不触及版本管理）

---

## 1. 模块定位与适用边界

**能做什么**：Editor Setup 提供全系统配置——General（全局）、File Types（行为档案）、Global Colors、External Commands、Machine Models、Custom Machines、Mazatrol Viewer、Plugins；多通道（Multi Channel）可并排查看双/多通道 NC 程序并按 Wait codes 同步；正则表达式基于 POSIX ERE（简化）。来源：`https://docs.cimco.com/en/docs/edit/2026/editor-setup/`、`https://docs.cimco.com/en/docs/edit/2026/regex/`。

**不能做什么**：
- **add-on 许可边界**：Machine Models 仅 Machine Simulation add-on 激活时可见；Mazatrol Viewer 是单独购买 add-on，只能查看/打印 Mazatrol 二进制文件（无头信息），**不能修改或存回原二进制格式**（`.../editor-setup/machine-models/`、`.../editor-setup/mazatrol-viewer/`，参照 B-01 的 add-on 处理方式）。
- Plugins 中多项需相应许可（Backplot/advanced NC-Functions 需 Professional；CNC-Calc/DNC/NC-Base/DNC-Max/Mazatrol 需扩展或单独许可）；本机许可状态未核实，按"未验证"处理（`.../editor-setup/plugins/`）。
- 多通道配置必须先为对应 File Type 启用，否则 NC-Assistant 多通道菜单禁用（`.../editor-setup/file-types/multi-channel/`）。
- 不宣称版本管理（B-02）、几何建模（B-05）能力。

## 2. 官方菜单路径与快捷键（逐条附来源）

### 2.1 Editor Setup 入口与层级（来源：`.../editor-setup/`）

入口：Editor 选项卡 > Setup 或 File > Global setup。配置层级（左侧导航）：General / File Types / Global Colors / External Commands / Mazatrol Viewer / Machine Models / Custom Machines / Plugins。

| 通用按钮 | 功能 | 来源页 |
|---|---|---|
| Export | 导出整个配置到 .zip（备份/移植） | `.../editor-setup/` |
| Import | 导入配置（需重启生效） | 同上 |
| Help / Default / Cancel / OK | 帮助 / 恢复默认 / 取消不应用 / 应用关闭 | 同上 |
| 顶部 `?` 图标 | 点击后选任一选项查看简短说明；或在字段按 F1 | 同上 |

### 2.2 Custom Machines / Machine Models / Plugins / Mazatrol（来源：各页）

| 页 | 关键命令 | 功能 | 来源页 |
|---|---|---|---|
| Custom Machines | Advanced Edit / Edit / Delete / Add | 新建机床（类型 3-Axis / 4-Axis Head/Table / 5-Axis Head-Head/Head-Table/Table-Table） | `.../editor-setup/custom-machines/` |
| Advanced Machine Editor | Properties/Models/Axes/Tool Change Positions/NC-Commands | 自动建大部分设置，实时预览；**不支持** collinear 轴、revolver、spindle（用 Machine Configuration Editor） | `.../editor-setup/custom-machines/advanced-configuration-editor/` |
| Machine Configuration Editor | Base/Head/Table/Rotary/Linear/Collinear/Geometry/Tool Changer | 支持复杂配置；保存到 `\AppData\Roaming\...\MachineCfg\` | `.../editor-setup/custom-machines/configuration-editor/` |
| Machine Models | Update/Install/Uninstall/View Notes/Check for updates at launch | 下载安装机床（**仅 add-on 激活时可见**） | `.../editor-setup/machine-models/` |
| Plugins | Disable Backplot/DNC/File compare/advanced NC-Functions/NC-Base/DNC-Max/CNC-Calc/Mazatrol；Enable configuration password；Edit configuration paths | 启停模块/许可门控/密码/路径 | `.../editor-setup/plugins/` |
| Mazatrol Viewer | Language/Decimals/Show TPC Data/Associations | 查看/打印 Mazatrol 二进制（**不可改/存回**）；add-on | `.../editor-setup/mazatrol-viewer/` |

| 命令 | 快捷键 | 功能 | 来源页 |

### 2.4 外部命令变量（来源：`.../editor-setup/external-commands/`）

| 变量 | 含义 |
|---|---|
| `$FILE` | 不含路径的文件名 |
| `$FILENOEXT` | 不含扩展名的文件名 |
| `$PATH` | 文件路径 |
| `$FILEPATH` | 含路径的文件名 |
| `$OUTFILE` | 输出文件名（Output file 字段定义） |

> 例：参数 `-g $FILE $OUTFILE`，Output file 填 `$PATH\$FILENOEXT.NEW`；`Wait for output from program` 会锁定编辑器直到命令结束（来源同上）。

### 3.4 正则表达式语法（POSIX ERE 简化，来源：`https://docs.cimco.com/en/docs/edit/2026/regex/`）

| 元字符 | 含义 | 示例 |
|---|---|---|
| `.` | 任意字符 | `A.C` 匹配 A+任意+C |
| `^` / `$` | 行首 / 行尾 | `^G123` 仅行首匹配 |
| `[ ]` / `[^ ]` | 字符集合 / 排除 | `[A-Z]` 范围；`[4-7]` 数字范围 |
| `*` / `+` / `?` | 前元素 0+/1+/0或1 次 | `G[0-9]+` |
| `\|` | 或 | `AB\|C` 匹配 AB 或 AC |
| `{n}` / `{n,}` / `{m,n}` | 精确/最少/范围次 | `A{2,4}` |
| `( )` | 分组 | `(G[1-3])\|(M[4-7])` |
| `< >` | 捕获子表达式 | `G<[0-9]+>` 匹配 G 后数字但不含 G |

> 正则用于 Find/Replace、Tool trigger、多通道同步命令、Navigation 等；字面量用反斜杠转义（来源同上）。

## 4. 标准操作步骤

### 4.1 导出/导入配置（备份与移植）
1. Editor Setup > Export 导出整个配置到 .zip；检查点：备份文件生成（`.../editor-setup/`）。
2. 在另一 PC 上 Import；检查点：**重启 CIMCO Edit 后生效**（同上）。
3. 误配时 Default 恢复默认；配置密码遗忘时按住 Ctrl+Shift 启动编辑器（Plugins 页说明，`.../editor-setup/plugins/`）。

### 4.2 新建并配置一个 File Type
1. Editor Setup > File Types > Add，命名并选模板；检查点：新档案出现在列表（`.../editor-setup/file-types/`）。
2. 进入 Machine 子节设注释符 `(` `)`、Block skip、换刀/进给/主轴前缀 T/F/S；检查点：与机床语法一致（`.../editor-setup/file-types/setup-machine/`）。
3. 进入 Colors/Block Numbers/Load-Save/Backplot/Scanning 子节配置；检查点：对话框标题显示当前 File Type（同上各页）。
4. 打开文件后从 Editor > File Type 切换到该档案；检查点：着色/语法按新档案生效（`.../editor-setup/file-types/`）。

### 4.3 配置多通道视图
1. Editor Setup > File Types > Multi Channel 勾 Enable multi channel view；检查点：NC-Assistant 多通道菜单启用（`.../multi-channel/`）。
2. 选 multi channel mode / User Defined，设 Channel start（如 O 或 G13,G14）、Channel end（如 M30）、Channel order；检查点：Test field 测试命令可识别（`.../multi-channel/`）。
3. Configure 打开 Multi Channel Configuration，添加 Synchronization command（如 `M3<[0-9][0-9]>` 同步 M300-M399，Channel number 1,2）；检查点：同步点列表生成（`.../multi-channel/configuration/`）。
4. NC-Assistant > Multi Channel > Window/Files 查看；Ctrl+↓/↑ 跳同步点，Synchronize Scrolling 锁定；检查点：匹配 Wait codes 黄色、缺失紫色（`.../nc-assistant/menuncassistantmultichannel/`）。

### 4.4 配置外部命令与插件
1. Editor Setup > External Commands，设 Command Title/Command program/Parameters（用 $FILE 等变量）/Output file；检查点：NC Functions > Commands 菜单出现该命令（`.../editor-setup/external-commands/`）。
2. 按需设 Ribbon icon（.ico）与 Separate icon for dark theme；检查点：图标加载正常（同上）。
3. Plugins 页按需禁用模块/设配置密码/编辑配置路径；检查点：对应功能按许可启用/禁用（`.../editor-setup/plugins/`）。

## 5. 输出标准与判定准则

| 输出 | 判定准则 | 依据 |
|---|---|---|
| 配置持久化 | Export .zip 备份；Import 后重启生效 | `.../editor-setup/` |
| File Type 隔离 | 所有 File Types 子节设置仅对当前档案生效，标题显示档案名 | `.../editor-setup/file-types/` |
| 多通道前置 | 须先 Enable multi channel view，否则 NC-Assistant 菜单禁用 | `.../multi-channel/` |
| 同步配色 | 匹配 Wait codes 黄、缺失紫 | `.../multi-channel/` |
| add-on 可见性 | Machine Models 仅 Machine Simulation 激活可见；Mazatrol 需单独授权且不可存回二进制 | `.../machine-models/`、`.../mazatrol-viewer/` |

| 许可门控 | 各模块按插件许可启用；本机未核实按未验证 | `.../editor-setup/plugins/` |

## 6. 行业最佳实践 / 常见误区

1. **误区：改 Language/Import 后立即生效。** 官方明确改语言与导入配置后须重启编辑器（`.../general/`、`.../editor-setup/`）。
2. **误区：Mazatrol Viewer 可改文件并存回。** 官方明确只能查看/打印二进制（无头信息），不能修改或存回原二进制格式（`.../mazatrol-viewer/`）。
3. **误区：Advanced Machine Editor 能配所有机床。** 它无法配置 collinear 轴、revolver、spindle，须用 Machine Configuration Editor（`.../advanced-configuration-editor/`）。
4. **误区：多通道开箱即用。** 必须先在 File Type 的 Multi Channel 页启用并配通道起止/同步命令（`.../multi-channel/`）。
5. **最佳实践：同步命令用正则捕获变号。** 如 `M3<[0-9][0-9]>` 同步 M300-M399，用 `< >` 捕获数字（Macodel/DMG Mori/Star 例，`.../multi-channel/configuration/`）。
6. **最佳实践：配置密码遗忘用 Ctrl+Shift 启动。** Plugins 设密码后遗忘，按住 Ctrl+Shift 启动编辑器（`.../plugins/`）。
