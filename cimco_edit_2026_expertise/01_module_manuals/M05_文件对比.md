# M05 文件对比（File Compare） — 标准化操作手册

> 对应模块：File Compare 选项卡（Program Tabs > File Compare）
> 事实源：`docs.cimco.com/en/docs/edit/2026/program-tabs/file-compare/*`（C 语料）与 `.../editor-setup/file-types/file-compare/`（D 语料）
> 诚实性基线：`CAPABILITY_BOUNDARIES.md`（**B-02** 版本管理边界）

---

## 1. 模块定位与适用边界

**能做什么**：File Compare 对两个 NC 程序做逐行差异对比（diff），提供三种比较入口（与窗口/与文件/文件与文件）、差异导航（Go To）、差异同步（Sync 左右）、智能标记与忽略选项（块号/空白/注释/大小写/数值格式）、保存差异到 .txt、单步差异、minimap。来源：`https://docs.cimco.com/en/docs/edit/2026/program-tabs/file-compare/`、`.../editor-setup/file-types/file-compare/`。

**不能做什么**：
- **B-02（硬边界）**：`version control` 在 161 页语料 **0 命中**；File Compare **仅有 diff/Goto/Sync**，**不含版本管理**。程序与版本管理属 NCBase/MDCMax 产品域。本手册严禁把 File Compare 描述为"版本管理系统/提交历史/分支/回滚"。
- 不修改差异本身以外的程序逻辑；Sync 只是把选中差异从一侧复制到另一侧。
- 不做几何/仿真/通信（分别见 M03/M04/M07）。

## 2. 官方菜单路径与快捷键（逐条附来源）

### 2.1 File Compare 主菜单（来源：`https://docs.cimco.com/en/docs/edit/2026/program-tabs/file-compare/file/`）

| 命令 | 功能 | 来源页 |
|---|---|---|
| Compare with Window | 当前窗口文件与另一窗口文件比较；多于两个文件打开时提示选择 | `.../file-compare/file/` |
| Compare with File | 当前窗口文件与通过 Open file 对话框选择的文件比较 | `.../file-compare/file/` |
| Compare File with File | 比较尚未在窗口打开的两个文件（均经 Open file 选择） | `.../file-compare/file/` |
| End File Compare | 结束对比会话，两文件保持打开 | `.../file-compare/file/` |
| Close Left / Right Window | 关闭左/右侧对比窗口 | `.../file-compare/file/` |
| Setup | 进入 Editor Setup > File Compare 配置 | `.../file-compare/file/` |

### 2.2 Go To（来源：`.../file-compare/goto/`）

| 命令 | 快捷键 | 功能 |
|---|---|---|
| Next Difference | Ctrl+Down Arrow | 下一处差异 |
| Previous Difference | Ctrl+Up Arrow | 上一处差异 |
| Go to First Difference | — | 第一处差异 |
| Go to Last Difference | — | 最后一处差异 |

### 2.3 Sync（来源：`.../file-compare/sync/`）

| 命令 | 快捷键 | 功能 |
|---|---|---|
| Sync Left | Ctrl+Left Arrow | 当前差异从右→左同步 |
| Sync Right | Ctrl+Right Arrow | 当前差异从左→右同步 |

> 同步后该行不再高亮（两窗口文本已相同）。来源同上。

### 2.4 Other（来源：`.../file-compare/other/`）

| 命令 | 功能 | 来源页 |
|---|---|---|
| Save Compare File | 保存有差异的行到 .txt | `.../file-compare/other/` |
| Single Step Through Differences | 只同步光标所在行（默认按行块同步，如连续两三行差异） | 同上 |
| File Compare Setup | 进入 Editor Setup > File Compare 配置 | 同上 |

## 3. 参数配置规则

来源：`https://docs.cimco.com/en/docs/edit/2026/editor-setup/file-types/file-compare/`（设置仅对选中 File Type 生效）。

| 参数名 | 取值 | 默认值 | 含义 | 来源页 |
|---|---|---|---|---|
| Single line step | 开/关 | 关 | 单步遍历多个连续差异，仅高亮当前行差异 | `.../file-compare/` |
| Show all differences (No editing) | 开/关 | 关 | 显示所有至少有一处差异的行，全部同时高亮（只读） | 同上 |
| Jump to next difference after sync | 开/关 | — | 同步两处差异后总是跳到下一处 | 同上 |
| Use tab to switch window | 开/关 | 关 | 用 Tab 键在两个文件间切换（启用后无法插入制表符） | 同上 |
| Mark Changes only | 开/关 | 关 | 激活所有有差异的行，但只高亮差异部分而非整行 | 同上 |
| Use smart marking | 开/关 | — | 不仅标记命令中不同的部分，还标记包含差异的**完整命令** | 同上 |
| Show minimap | 开/关 | — | 显示文件对比 minimap | 同上 |
| Ignore Block numbers | 开/关 | 关 | 忽略块号值及有无（一个文件有、另一个无也忽略） | 同上 |
| Ignore White spaces | 开/关 | 关 | 忽略空格(ASCII 32)与制表符(ASCII 9) | 同上 |
| Ignore Comments | 开/关 | 关 | 忽略注释内内容（须在 Machine 模板设对 Comment start/end，如 `(` `)`） | 同上 |
| Ignore Case | 开/关 | 关 | 忽略字母大小写 | 同上 |
| Ignore Numeric format | 开/关 | 关 | 忽略前后导零与可选 `+`，如 `X+14.10` 匹配 `X14.1` | 同上 |
| Print only differences | 开/关 | 关 | 只打印有差异的行 | 同上 |

> 颜色侧：File compare background for different lines / different text / missing lines / difference wave 在 Colors 中配置（见 M09）。

## 4. 标准操作步骤

### 4.1 启动一次文件对比
1. Editor Setup > File Compare 预设忽略项（如块号/注释/空白）；检查点：当前 File Type 正确（标题显示）（`.../editor-setup/file-types/file-compare/`）。
2. File Compare 菜单三选一：Compare with Window / Compare with File / Compare File with File；检查点：左右两窗口出现（`.../file-compare/file/`）。
3. 用 Go To（Ctrl+↓/↑）遍历差异；检查点：定位到差异行（`.../file-compare/goto/`）。
4. 核查完成后 End File Compare（两文件保持打开）或 Close Left/Right Window（`.../file-compare/file/`）。

### 4.2 同步差异
1. 定位到目标差异（Go To First/Next Difference）；检查点：差异高亮正确（`.../file-compare/goto/`）。
2. 按方向 Sync Left（右→左）或 Sync Right（左→右）；检查点：该行不再高亮，两窗口文本相同（`.../file-compare/sync/`）。
3. 若只需单对单行同步，启用 Other > Single Step Through Differences；检查点：仅光标所在行被同步（`.../file-compare/other/`）。
4. 勾 Jump to next difference after sync 可连续同步；检查点：自动跳到下一差异（`.../editor-setup/file-types/file-compare/`）。

### 4.3 导出差异清单与打印
1. Other > Save Compare File 保存差异行到 .txt；检查点：文件内容仅含差异行（`.../file-compare/other/`）。
2. 若需打印，Editor Setup > File Compare 勾 Print only differences；检查点：打印仅含差异行（`.../file-compare/`）。

## 5. 输出标准与判定准则

| 输出 | 判定准则 | 依据 |
|---|---|---|
| 差异语义 | 仅逐行 diff/Goto/Sync；**不得表述为版本管理** | B-02 |
| 智能标记 | Use smart marking 标记完整命令；Mark Changes only 只标差异部分 | `.../editor-setup/file-types/file-compare/` |
| 忽略项 | Ignore Comments 依赖 Machine 模板 Comment start/end 正确 | 同上 |
| 同步方向 | Sync Left=右→左；Sync Right=左→右 | `.../file-compare/sync/` |
| 差异导出 | Save Compare File 仅含差异行到 .txt | `.../file-compare/other/` |
| 数值等价 | Ignore Numeric format 使 `X+14.10`≡`X14.1` | `.../editor-setup/file-types/file-compare/` |

## 6. 行业最佳实践 / 常见误区

1. **误区：把 File Compare 当版本管理。** 语料 `version control` 0 命中；版本管理在 NCBase/MDCMax（B-02）。
2. **最佳实践：批量归一化后再比较。** 用 Ignore Block numbers / White spaces / Case / Numeric format 消除非实质差异，聚焦真实改动（`.../editor-setup/file-types/file-compare/`）。
3. **最佳实践：注释依赖 Machine 模板。** 要忽略注释，须确保对应 File Type 的 Machine 模板 Comment start/end 设对，否则 Ignore Comments 无效（同上）。
4. **误区：Sync 会改程序逻辑。** Sync 仅把选中文本从一侧复制到另一侧；同步后该行因文本相同而不再高亮（`.../file-compare/sync/`）。
5. **最佳实践：连续差异用 Single Step。** 默认按行块（连续两三行）同步，单步模式可逐行聚焦（`.../file-compare/other/`）。
6. **最佳实践：Tab 换窗权衡。** Use tab to switch window 便于切换但会导致无法输入制表符（`.../editor-setup/file-types/file-compare/`）。
