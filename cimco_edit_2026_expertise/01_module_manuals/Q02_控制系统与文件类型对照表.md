> 事实源：官方 supported-controls 清单（B_backplot_sim.md，`BASE=https://docs.cimco.com/en/docs/edit/2026/`，页面 `simulation/supported-controls/`）+ 本机安装目录实测（EVIDENCE.md INS-03/INS-05）。
> 本机安装根：`E:\仿真软件\CIMCOEdit_20260102\CIMCO 2026\CIMCOEdit\`（下文简称 `ROOT`）。
> 实装文件类型：`.TYP` = File Type 机器类型模板（ROOT\Templates\）；`.eRPost` = 控制系统后处理包（ROOT\RPost\<系统>\）；`.eRPostExt` = 扩展包（ROOT\RPost\Extensions\）；`.TPL` = 传输/工具协议模板（ROOT\Templates\）；`.conv` = 会话转换器（ROOT\Converters\）。
> 官方清单共 17 个系统；铣/车类型取自语料中实际存在的子章节（Milling/Turning/Milling-with-Turning）。华中数控不在官方清单内，按 B-03 处理。

## 五、文件类型与配置的关系（来自 D_setup_controls.md）

- File Type（配置文件类型）= CIMCO Edit 的行为配置档案；File Types 管理含 Add/Copy/Rename/Delete/Up-Down/sort；新建时选预定义模板（`editor-setup/file-types/`）。
- 每个 File Type 下可独立配置：Colors、Block Numbers、Load/Save、File Compare、Machine、Backplot、Scanning、Multi Channel、Tool List、Other、CNC-Calc（同上 URL）。
- 同一控制系统（Control Type）可被多个 File Type 使用且参数各自独立：Control Settings 的改动随 File Type 保存，不覆盖控制系统本身（`editor-setup/file-types/backplot/control-settings/`）。
- Backplot 前必须先在程序选项卡 Control Type 菜单选定 Machine（Machine Setup）（`program-tabs/backplot/filetype/`）。
- 仿真引擎 Standard/Fast 在 Backplot configuration 切换，Fast 为默认（`simulation/`）。

## 六、溯源与诚实性声明

1. 官方支持系统的"铣/车类型"来自 `B_backplot_sim.md` 中实际存在的 Milling/Turning 子章节标题（如 `TITLE: Fanuc Milling` @2458、`TITLE: Fanuc Turning` @2840），未列出的子类型不臆造。
2. 本机文件名来自对 `ROOT\Templates`、`ROOT\RPost`、`ROOT\Converters` 的直接枚举，与 EVIDENCE.md INS-05 一致；若与官方手册未来版本不一致，以本机实测为准并标注"需现场确认"。
3. 本表不含功能宣称：Machine Simulation 许可、Mazatrol Viewer add-on、华中原生适配等均按 CAPABILITY_BOUNDARIES.md 处理。
4. 对照关系用于"文件类型与控制系统的溯源索引"，非"已验证可在某机床正确运行"的保证；实际程序须现场看验证。
