# M04 仿真与机床仿真（Simulation / Machine Simulation） — 标准化操作手册

> 对应模块：Simulation 域（含 Simulation 选项卡停靠窗格）
> 事实源：`docs.cimco.com/en/docs/edit/2026/simulation/*`（B 语料）
> 诚实性基线：`CAPABILITY_BOUNDARIES.md`（**B-01** Machine Simulation add-on；**B-03** 华中数控非原生支持；supported-controls 清单）

---

## 1. 模块定位与适用边界

**能做什么**：CIMCO Edit 2026 含两套仿真引擎——**Standard version** 与新版 **Fast version（现为默认引擎）**，可在 Editor Setup > Backplot configuration 切换；启动前须先为程序的 File Type 配置 backplot（选 Control Type 如 'ISO Milling'）。仿真窗口含 Ribbon 栏、NC 程序视图（左）、仿真窗口（中）、停靠窗格（右：Simulation/Navigation/Variables/Geometry Manager）。来源：`https://docs.cimco.com/en/docs/edit/2026/simulation/`。

**不能做什么**：
- **B-01**：Machine Simulation 是 add-on，**不是单独下载安装**，已随 CIMCO Edit 安装，仅在装入有效 license key 后可用；本机许可状态未核实，按"未验证"处理。碰撞/行程检测报告、Stop Conditions、Head/Table/Base 组件、Collision Settings 均属该 add-on。
- **B-03**：supported-controls 清单无 Huazhong；华中数控只能走 `ISO_G-Code` 通用模板近似适配，需实际机床验证，非官方原生支持。
- 仿真不做几何建模（**B-05**）；机床模型来自 Machine Models 下载或 Machine Configuration Editor 配置。
- G00 静态哨兵 ≠ 仿真碰撞检测（能力边界第四节）。

## 4. 标准操作步骤

### 4.1 运行一次标准/快速仿真
1. Editor Setup > File Types > Backplot：选 Control Type 与 Machine setup，Simulation Window 选 Fast（默认）或 Standard；检查点：Control Type 与程序匹配（`.../editor-setup/file-types/backplot/`）。
2. 配置 Scanning 读取工具/毛坯/偏移/导航信息；检查点：Geometry Manager 自动装载元素（`.../editor-setup/file-types/scanning/`、`.../simulation/geometry-manager/`）。
3. Ctrl+Shift+F 启动（经 Backplot Ctrl+Shift+P 进入仿真窗口）；播放 Ctrl+Shift+R；检查点：进度条随程序移动、Status 面板显示当前刀具/进给/主轴（`.../simulation/fast-version/`）。
4. 观察 Simulation Report 错误；点错误跳到对应行；检查点：错误随 NC 修改自动更新（`.../simulation/simulation/`）。

### 4.2 Geometry Manager 建立毛坯与工件
1. 右键 Geometry Manager > Add Stock，选 Dimensions/Min-Max/Cylinder/STL/DXF；检查点：Stock 出现且属性区可编辑（`.../simulation/geometry-manager/`）。
2. Add Workpiece 装载 STL 设计模型；检查点：Workpieces 列表出现（`.../simulation/geometry-manager/`）。
3. 设 Work Origin / Work Offsets（Translation/Rotation）；若程序用 G10 L2 写入偏移，核对只读 Programmed 行（`.../simulation/geometry-manager/`）。
4. Fast version 用 Stock Compare（红过加工/蓝欠加工/绿公差内）验证；检查点：Compare range 与 Stock to leave 设定正确（`.../backplot/solid/`）。

### 4.3 多通道/变量/导航窗格使用
1. Variables 窗格：查看自动检测变量初值与 Watch List 当前值；点初值改测试值；检查点：实际 NC 代码未变（`.../simulation/variables/`）。
2. Navigation 窗格：确认 Scanning 已启用 'Scan for navigation information'；点树节点跳到程序；检查点：关键字与 NC 注释中词匹配（`.../simulation/navigation/`、`.../editor-setup/file-types/scanning/navigation/`）。
3. 需在程序开始/背绘启动时自动运行的脚本，见 M02（B-01 场景不适用时跳过）。

### 4.4 Machine Simulation（仅有效许可，本机未验证）
1. **前置确认**：核实 Machine Simulation 有效 license key 已安装；检查点：Backplot 菜单出现 Machine Simulation 选项（B-01，`.../simulation/machine-simulation/`）。
2. Editor Setup > Machine Models 下载安装机床；Backplot > Control Type 选 Control 与 Machine（下载机床名带 '(Bundled)'）；检查点：仿真窗口显示机床（`.../simulation/machine-simulation/`）。
3. Geometry Manager 查看 Head/Table/Base 组件；按需显隐；检查点：STL 组件可见（`.../simulation/machine-simulation/`）。
4. Simulation Tab 启用 Collision Settings（Find One/All、Tool/Workpiece Collisions、Cutter Allowance）；Toolpath 启用 Stop Conditions；检查点：触发时 Stop Conditions Panel 显示原因（`.../simulation/machine-simulation/`、`.../simulation/simulation/`）。

## 6. 行业最佳实践 / 常见误区

1. **误区：把 Machine Simulation 当标配。** 它是 add-on，仅有效 license key 后可用；本机未核实按"未验证"（B-01）。
2. **误区：把华中数控列为官方支持。** supported-controls 无 Huazhong，只能 ISO_G-Code 近似适配并实测（B-03）。
3. **误区：Tool/Workpiece Collisions 全开最优。** 正常加工中刀具频繁接触工件会拖慢检测；官方建议多用 Stock Compare 替代（`.../simulation/simulation/`）。
4. **最佳实践：用 Cutter Allowance 降误报。** STL 三角误差会导致假碰撞，设 0.1mm 余量减少误报（`.../simulation/simulation/`）。
5. **最佳实践：大程序手动触发碰撞检测。** Check collision and limit errors 为 CPU 密集任务，不随每次修改运行，需手动决定时机（`.../simulation/simulation/`）。
6. **最佳实践：修改刀具配置后 Save Setup。** Tool Manager 的改动在背绘/仿真关闭且不保存时会丢失；须右键 Geometry Manager > Save Setup（见 M08，`.../simulation/tool-manager/`）。
