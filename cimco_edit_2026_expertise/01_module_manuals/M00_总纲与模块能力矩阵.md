## 1. 模块定位与适用边界

### 1.1 产品定位（官方原文支撑）

CIMCO Edit 2026 是"世界上流行的 CNC 程序编辑器"，定位为**编辑、仿真与通信工具**；核心能力为 NC 专用功能、数学运算、Transform 变换、拖放编辑，并包含 file compare、mill/turn simulation、Tool Manager、NC code assistant，以及 machine simulation、program management、2D CAD/CAM 等 **add-on（插件/附加模块）**。来源：`https://docs.cimco.com/en/docs/edit/2026/introduction/`。

本套手册严格限定在 **CIMCO Edit 本体（核心功能模块）**，把 add-on 与跨产品域能力按能力边界原样标注。

### 1.2 绝对不得越界的六条硬约束

| 编号 | 用户侧常见越界表述 | 官方事实 / 允许表述 | 本手册处理 |
|---|---|---|---|
| B-01 | "全维度机床模拟与碰撞检测" | Machine Simulation 是**需单独授权的 add-on**，功能仅在装入有效 license key 后可用；本机许可状态未核实，按"未验证"处理 | M03/M04 只写"条件可用"，不宣称开箱可用 |
| B-02 | "程序差异对比与版本管理" | `version control` 在 161 页语料 **0 命中**；File Compare 仅有 diff/Goto/Sync；版本管理属 NCBase/MDCMax 产品域 | M05 仅覆盖文件差异对比，明确排除版本管理 |
| B-03 | "华中数控原生适配" | `Huazhong` 在 supported-controls 清单 **0 命中** | M04 说明只能走 `ISO_G-Code` 通用模板近似适配，非官方原生支持 |
| B-04 | "通用 CAM 后处理配置与定制开发" | `Post Process` 仅出现在 CNC-Calc 与 Transform 两处；Posts/*.js 为 CNC-Calc 后处理/反向后处理；通用 CAM 后处理在 CAM 软件侧 | M06 只写 CNC-Calc 后处理与 Converters 方言转换 |
| B-05 | "全图形化 3D 实体建模 / 2D 绘图" | CIMCO Edit 是 NC 编辑器，无几何建模模块 | 全局排除；2D/3D 建模路由 AutoCAD/NX/SOLIDWORKS |
| B-06 | "自动 20 次人工实操 / 真人计时 / 外部盲评" | 属拟人化培训指标，AI 无法产生人工点击记录或外部盲评成绩 | 用可复跑的工程化等价手段替代，报告标明"自测/工程验证" |

### 1.3 校验与哨兵的诚实退路（能力边界第三节）

- `bridges/cimco_bridge.py::validate_fanuc_macro_b` 为**本地静态校验器（非 CIMCO 内核）**；哨兵不可用时桥接返回 `status=partial` + `CHECK_UNAVAILABLE`，**绝不把"未检查"读作"检查通过"**。
- 凡报告"校验通过"，必须同时给出 `status` / `syntax_checked` / `errors` 原始字段。
- **G00 碰撞哨兵（项目公理，AGENTS.md §2.E/D）**：背绘/校验必须检查 G00 快速段不得高速扎入毛坯；落入毛坯即报警。这是**静态几何哨兵**，不等同于机床仿真的真实碰撞检测，二者不得混同表述。

## 2. 官方菜单路径与快捷键（总览）

CIMCO Edit 2026 的功能通过 Ribbon 功能区的图标激活，选项按逻辑分组置于各选项卡（Tab）下；若功能可由 Ribbon 或键盘快捷键激活，命令名旁会显示图标或快捷键。来源：`https://docs.cimco.com/en/docs/edit/2026/program-tabs/`。

| 选项卡（Program Tab） | 核心菜单/子节 | 代表入口快捷键 | 来源页 |
|---|---|---|---|
| Editor | File / File Type / Edit / Find / Bookmarks / Setup / Window / Help | Ctrl+N、Ctrl+O、Ctrl+S、Ctrl+F、Ctrl+H、Ctrl+J、F2、F3、F5 | `.../program-tabs/editor/`、`.../editor/file/`、`.../editor/find/`、`.../editor/bookmarks/` |
| NC Functions | Block Numbers / Insert-Remove / Transform / Info / Scripts | Ctrl+T（Renumber）、Ctrl+M（Mark/Delete） | `.../program-tabs/nc-functions/`、`.../nc-functions/blocknumbers/` |
| NC-Assistant | Macros / Info / Setup / Multi Channel / Sidebar | Ctrl+Shift+A（隐藏侧栏）、Ctrl+↓/↑（多通道同步点） | `.../program-tabs/nc-assistant/`、`.../nc-assistant/info/`、`.../nc-assistant/menuncassistantmultichannel/` |
| Backplot | Backplot / Control Type / Toolpath / Tool / Geometries / View / Find / Other | Ctrl+Shift+P（背绘）、Ctrl+Shift+Q（关闭）、F9（Fit） | `.../program-tabs/backplot/`、`.../backplot/file/`、`.../backplot/view/` |
| File Compare | File Compare / Go To / Sync / Other | Ctrl+↓/↑（下/上一差异）、Ctrl+←/→（Sync 左/右） | `.../program-tabs/file-compare/`、`.../file-compare/goto/`、`.../file-compare/sync/` |
| Transmission | Transmission / Machine / Setup / Transmit-Receive Dialogs | 无官方固定键（经 Machine 下拉选择） | `.../program-tabs/transmission/` |

> DNC Setup 对话框独立于 Editor Setup，**不能**从 Editor Setup 访问；可从 Transmission 菜单或 Transmission 选项卡下的 Setup 菜单打开。来源：`.../program-tabs/transmission/`、`.../dnc-setup/`。

## 3. 参数配置规则（全系统配置层级）

Editor Setup 对话框由左侧导航菜单与右侧配置区构成，顶部搜索栏可筛选章节；底部按钮为 Export（导出整个配置到 .zip）、Import（导入后需重启）、Help、Default（恢复默认）、Cancel、OK（应用）。来源：`https://docs.cimco.com/en/docs/edit/2026/editor-setup/`。

| 配置层级 | 作用范围 | 关键子节 | 来源页 |
|---|---|---|---|
| General | 全局 | Editor Settings / NC-Assistant / Printing | `.../editor-setup/general/`、`.../general/editor/`、`.../general/nc-assistant/`、`.../general/printing/` |
| File Types | **仅对选中 File Type 生效** | Colors / Block Numbers / Load-Save / File Compare / Machine / Backplot / Scanning / Multi Channel / Tool List / Other / CNC-Calc | `.../editor-setup/file-types/` |
| Global Colors | 仿真与 CNC-Calc 全局颜色 | List of Colors / Select Color / Default | `.../editor-setup/global-colors/` |
| External Commands | 两条命令行调用 | $FILE / $FILENOEXT / $PATH / $FILEPATH / $OUTFILE 变量 | `.../editor-setup/external-commands/` |
| Machine Models | 下载安装机床（**仅 Machine Simulation add-on 激活时可见**） | Install / Update / Uninstall / Check for updates at launch | `.../editor-setup/machine-models/` |
| Custom Machines | 自定义机床 | Advanced Machine Editor / Machine Configuration Editor | `.../editor-setup/custom-machines/` |
| Mazatrol Viewer | Mazatrol 二进制文件查看/打印 | Language / Decimals / Associations（**add-on，需单独授权**） | `.../editor-setup/mazatrol-viewer/` |

**关键判定规则**：File Type 是"行为配置档案"，决定着色、语法、块号、扩展名、加载/保存目录、文件比较、机床专用 NC 代码识别、仿真默认控制器与机床等；打开文件时须在 Editor 选项卡的 File Type 菜单切换到对应档案。来源：`.../editor-setup/file-types/`。

## 4. 标准操作步骤（首次规范化配置通用流程）

1. **确认许可与插件状态** → 检查点：Help > About 的 "Licensed to" 显示公司名；Evaluation 显示 "Demo version"（`.../installation/`）。涉及 Backplot/advanced NC-Functions 须 Professional 许可，CNC-Calc 须扩展许可，Machine Simulation/Mazatrol 须各自 add-on 授权（B-01，`.../editor-setup/plugins/`）。
2. **选定或新建 File Type** → 检查点：Editor Setup > File Types 中确认当前档案；可用 Add 基于预定义模板新建（`.../editor-setup/file-types/`）。
3. **配置机器特殊字符与 NC 代码** → 检查点：Machine 页设置 Comment start/end（如 `(` `)`）、Block skip、Tool Change 前缀 T、Set feedrate F、Set spindle speed S（`.../editor-setup/file-types/setup-machine/`）。
4. **配置块号与颜色** → 检查点：Block Numbers 页设定 Format/Interval/Block number character（ISO 通常为 N）；Colors 页设定 Rapid/Linear/G2/G3 等语法色（`.../block-numbers/`、`.../colors/`）。
5. **配置加载/保存与备份** → 检查点：Load/Save 页设定 Default extension、路径、Auto save interval、Save with linefeed type；General > Save backup file 默认生成 .bak（`.../load-save/`、`.../general/`）。
6. **配置仿真（如需）** → 检查点：Backplot 页选择 Control Type 与 Machine setup、Simulation Window（Fast/Standard），并确认 Scanning 读取设置（`.../editor-setup/file-types/backplot/`、`.../scanning/`）。
7. **导出备份配置** → 检查点：Editor Setup > Export 生成 .zip；后续可在其他 PC 上 Import 并重启（`.../editor-setup/`）。

## 6. 行业最佳实践 / 常见误区

1. **误区：把 Machine Simulation 当成默认能力。** 它是 add-on，仅在装入有效 license key 后可用；本机未核实许可，按"未验证"处理（B-01）。
2. **误区：把 File Compare 当版本管理系统。** `version control` 语料 0 命中，版本管理属 NCBase/MDCMax（B-02）。
3. **误区：把 G00 静态哨兵等同于机床碰撞检测。** 前者是背绘/校验阶段的静态几何报警，后者是 Machine Simulation add-on 的动态碰撞检测，二者不得混同（能力边界第四节）。
4. **误区：把华中数控当官方原生支持。** supported-controls 清单无 Huazhong，仅能走 ISO_G-Code 通用模板近似适配并实测验证（B-03）。
5. **误区：把通用 CAM 后处理当成 Edit 的功能。** Edit 的"后处理"特指 CNC-Calc 后处理/反向后处理与 Converters 方言转换（B-04）。
6. **最佳实践：File Type 变更即校验。** 任何 File Type 切换后，颜色/块号/加载保存路径/仿真控制器随之改变；操作前先确认对话框标题显示的当前 File Type（`.../editor-setup/file-types/`）。
