# Q01 CIMCO Edit 2026 参数配置速查表（阶段1）

> 性质：官方语料逐条摘录的密集速查表，非臆造参数。信息密度优先。
> 语料基址 `BASE = https://docs.cimco.com/en/docs/edit/2026/`，每条"来源"列为 `BASE` 下的页面 slug。
> "默认"列：仅当官方语料明写默认值时填入；否则写"官方未明示/需现场确认"。
> 诚实性约束：Machine Simulation 为需单独授权的 add-on（本机许可未核实）；CIMCO Edit 无通用 CAM 后处理，仅有 CNC-Calc 后处理/反向后处理；华中数控非原生支持。详见 `CAPABILITY_BOUNDARIES.md`。
