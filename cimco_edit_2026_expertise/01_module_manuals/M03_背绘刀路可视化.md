# M03 背绘刀路可视化（Backplot） — 标准化操作手册

> 对应模块：Backplot 选项卡（Program Tabs > Backplot）
> 事实源：`docs.cimco.com/en/docs/edit/2026/program-tabs/backplot/*`（B 语料）
> 诚实性基线：`CAPABILITY_BOUNDARIES.md`（**B-01** Machine Simulation add-on；能力边界第四节 G00 静态哨兵项目公理）

---

## 1. 模块定位与适用边界

**能做什么**：Backplot（Ctrl+Shift+P）对当前 NC 程序进行刀路可视化，打开仿真窗口，可同时看到左侧 NC 程序、中部仿真、右侧 Geometry Manager 停靠窗格；包含 Control Type（控制类型/机床设置/支持轴）、Toolpath（刀路显示与动画模式）、Tool（刀具显示与 Tool Manager 入口）、Geometries（工件/夹具/毛坯/实体模型）、View（视角/测量/原点）、Find（查找跳转）、Other（全屏/DXF 导出/保存演示）。来源：`https://docs.cimco.com/en/docs/edit/2026/program-tabs/backplot/`。

**不能做什么**：
- **B-01**：Machine Simulation 是 add-on，仅在装入有效 license key 后可用；本机许可状态未核实，按"未验证"处理，不宣称可用。Backplot 菜单中的 Machine Simulation 选项与 Toolpath > Stop Conditions 仅在有效许可下出现/可用（`.../backplot/file/`、`.../backplot/toolpath/`）。
- **G00 哨兵（项目公理）**：背绘/校验必须检查 G00 快速段不得高速扎入毛坯，落入毛坯即报警；这是**静态几何哨兵**，不等同于机床仿真的真实碰撞检测，二者不得混同（能力边界第四节）。
- 不是几何建模工具（**B-05**）；Geometries 的 Add Stock/Workpiece/Fixture 是装载 STL/DXF/圆柱/盒体等已存在模型，非建模。
- 真正"碰撞/行程"检测报告属 Machine Simulation add-on 域（见 M04）。

## 3. 参数配置规则

### 3.1 几何/库存参数（来源：`.../backplot/solid/`）

| 参数名 | 取值 | 默认值 | 含义 | 来源页 |
|---|---|---|---|---|
| Add Stock 类型 | Dimensions / Min-Max / Cylinder / STL / DXF | 基于刀路数据的矩形 | Dimensions 用高/宽/长+原点；Min-Max 用 Lower/Upper Corner；Cylinder 用中心/直径/高/Axis/Origin | `.../backplot/solid/` |
| Stock type/dimensions 扫描 | Scanning 配置 | 关闭 | 开启后 Add Stock 可从 NC 程序或关联 Setup 文件扫描导入（见 M09） | `.../backplot/solid/` |
| Simulate（Fast version） | 开/关 | — | 播放时持续更新毛坯实体；可在 Geometry Manager 改 | `.../backplot/solid/` |
| Simulate（Standard version） | 始终更新 | — | 无法关闭；回退到早期程序点不回退毛坯（设计如此）；可 Regenerate 刷新 | `.../backplot/solid/` |
| Stock Compare 颜色 | Red/Blue/Green | — | 红=过加工（去除过多）、蓝=欠加工（去除不足）、绿=公差内；**仅 Fast version** | `.../backplot/solid/` |
| Compare range / Stock to leave | 数值 | — | 公差范围 / 预留材料（如留 1mm 设 1） | `.../backplot/solid/` |

### 3.2 View 测量差异（来源：`.../backplot/view/`）

| 模式 | 操作 | 结果位置 | 来源页 |
|---|---|---|---|
| Fast Version | 点起点→点终点；重复即新测量；导航不清除箭头 | 左侧专用 Measure Distance 面板 | `.../backplot/view/` |
| Standard Version | 点起点→移动光标到终点（不点击）；点击会重新开始 | 底部 Information Bar | `.../backplot/view/` |

> Stop Conditions 的"Rapid To Stock"（快速移动撞毛坯停止）与项目 G00 哨兵在**目的上相近但本质不同**：前者是 Machine Simulation add-on 的动态停止条件（B-01），后者是背绘/校验阶段的静态几何哨兵，不得混同（能力边界第四节）。

## 4. 标准操作步骤

### 4.1 启动一次背绘
1. 先在 Editor Setup > File Types > Backplot 选定 Control Type 与 Machine setup；检查点：Control Type 与程序控制器一致，Axes support 显示支持轴（`.../backplot/filetype/`）。
2. Editor 选项卡切换到对应 File Type（决定默认 Control/Machine）；检查点：对话框标题显示当前 File Type。
3. Ctrl+Shift+P 启动 Backplot；检查点：三窗格布局出现（NC/仿真/Geometry Manager）（`.../backplot/file/`）。
4. 在 View 选标准视角（如 Top G17/Front G18），F9 Fit To Window；检查点：全部刀路可见（`.../backplot/view/`）。

### 4.2 刀路检查与 G00 哨兵核验（项目公理）
1. Toolpath 开启 Show Rapid Moves 与 Highlight Element；检查点：快速段与切削段可区分（`.../backplot/toolpath/`）。
2. 用 Animate / Show From Last Rapid 或 Show From start 逐段播放；检查点：观察 G00 段轨迹（`.../backplot/toolpath/`）。
3. **执行 G00 静态哨兵检查**：确认每个 G00 快速段不高速扎入毛坯；落入毛坯即报警；检查点：报警项已记录待修正（能力边界第四节）。
4. 如需几何参考，Geometries > Add Stock（Dimensions/Min-Max）装载毛坯、Add Workpiece 装载设计模型；检查点：Geometry Manager 中可见（**注意：此处仅为静态几何参考，不等同于机床碰撞检测**）（`.../backplot/solid/`）。

### 4.3 DXF 导出与演示保存
1. Other > Export as DXF File 导出刀路；若接收系统不支持圆弧，可在 Editor Setup > Other 勾 Always linearize arcs（见 M09）；检查点：DXF 文件生成（`.../backplot/other/`）。
2. Other > Save Presentation，选 Simulation File（仅数据）或 Presentation Bundle（含 Presentation Viewer）；检查点：bundle 自动包含外部子程序（`.../backplot/other/`）。
3. Full Screen 演示，Escape 或右键退出；检查点：全屏切换正常（`.../backplot/other/`）。

## 6. 行业最佳实践 / 常见误区

1. **误区：把 G00 哨兵当机床碰撞检测。** 它是静态几何哨兵；真实碰撞检测属 Machine Simulation add-on（B-01），二者不得混同（能力边界第四节）。
2. **误区：未选 Machine 就启动背绘。** 官方明确 Machine（Machine Setup）必须在启动 Backplot 或 Machine Simulation 前选定（`.../backplot/filetype/`）。
3. **误区：把 Stop Conditions 当成标准版功能。** 该选项仅 Machine Simulation 可用，无许可时不出现（B-01，`.../backplot/toolpath/`）。
4. **最佳实践：用 Show From Last Rapid 聚焦快速段。** 背绘时可隐藏上一次快速移动前的刀路，便于专查 G00 段（`.../backplot/toolpath/`）。
5. **最佳实践：回退毛坯用 Regenerate。** Standard version 回退程序点不回退毛坯；改 Geometry Manager 后显示红色线框提示需 Regenerate（`.../backplot/solid/`）。
6. **最佳实践：Stock Compare 用 STL 工作件作设计模型。** 需同时设 Stock 与 Workpiece（STL 表示期望成品）才能比对过/欠加工（`.../backplot/solid/`）。
