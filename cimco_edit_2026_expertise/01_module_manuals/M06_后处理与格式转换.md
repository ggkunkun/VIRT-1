# M06 后处理与格式转换 — 标准化操作手册

> 对应模块：NC Functions > Transform（格式转换）+ CNC-Calc 后处理（Editor Setup 配置）
> 事实源：`.../program-tabs/nc-functions/transform/`（A 语料）、`.../editor-setup/file-types/setupfiletypes_cnc_calc/`（D 语料）、`.../scripts/writing-scripts/`（A 语料）、本机实测 `00_sources/EVIDENCE.md` + `E:\...\CIMCOEdit\` 目录枚举
> 诚实性基线：`CAPABILITY_BOUNDARIES.md`（**B-04** 后处理边界）

---

## 1. 模块定位与适用边界

**能做什么**：CIMCO Edit 2026 的"后处理/格式转换"能力限定在两类：
1. **CNC-Calc 后处理/反向后处理**——通过 `Posts/*.js` 指定输出格式（Mill 19 个 + Lathe 6 个 = 25 个 .js 实测，另见说明）；
2. **方言转换器（Converter）**——通过 `Converters/*.conv` 把一种 NC 方言转成另一种（实测 4 个：fanuc / heidenhain / SinumerikTurning / NumeripathTurning.conv），以及 Heidenhain ↔ ISO 互转、Convert to NCI、Use longhand cycles。来源：`.../nc-functions/transform/`、`.../editor-setup/file-types/setupfiletypes_cnc_calc/`、本机枚举。

**不能做什么（B-04 硬边界）**：
- `Post Process` 在 161 页语料中**仅出现在 CNC-Calc 与 Transform 两处**；**通用 CAM 后处理在 CAM 软件侧**，CIMCO Edit 不是通用 CAM 后处理器，不宣称可配置任意 CAM 后处理。
- 不把 `.js`（NC Function Script）与 `Posts/*.js`（CNC-Calc 后处理）混为一谈：前者是 `.../nc-functions/scripts/` 的 `.ncjs` 脚本（见 M02），后者是 CNC-Calc 后处理定义文件。
- 华中数控无原生后处理/转换模板（**B-03**：走 ISO_G-Code 通用模板近似适配，需实测验证）。
- 不做几何建模（**B-05**）；CNC-Calc 是 2D 计算/编程模块，非 CAD 建模。

## 2. 官方菜单路径与快捷键（逐条附来源）

### 2.1 NC Functions > Transform > 格式转换（来源：`https://docs.cimco.com/en/docs/edit/2026/program-tabs/nc-functions/transform/`）

| 命令 | 功能 | 来源页 |
|---|---|---|
| Heidenhain / ISO Converter | 将 Heidenhain CNC 程序转 ISO，或 ISO 转 Heidenhain CNC 程序 | `.../transform/` |
| Convert NC code | 从一种 NC 格式转换到另一种；需目标格式的 converter file（亦称 Post Processor） | `.../transform/` |
| Convert to NCI format | 转成 NCI——后处理前表示刀路的通用/中间格式 | `.../transform/` |
| Use longhand cycles | 把每个移动/循环输出为逐行代码，而非简写/固定循环 | `.../transform/` |
| Result to new window / Selection only | 结果放新文档 / 仅对选中部分 | `.../transform/` |

### 2.2 NC Converter 对话框参数（来源：`.../transform/`）

| 参数名 | 功能 | 来源页 |
|---|---|---|
| Choose original NC format | 选择源 NC 格式 | `.../transform/` |
| Choose converter | 选择目标格式的 converter/post processor 文件（`.conv`）；CIMCO Edit 在程序文件夹 `\Converters` 附带若干转换器 | `.../transform/` |

### 2.3 CNC-Calc 后处理配置（来源：`https://docs.cimco.com/en/docs/edit/2026/editor-setup/file-types/setupfiletypes_cnc_calc/`）

路径：Editor Setup > File Types > CNC-Calc（设置仅对选中 File Type 生效）。

| 命令/参数 | 功能 | 来源页 |
|---|---|---|
| Selected Post Processor | 选择输出要格式化到的 Post Processor | `.../setupfiletypes_cnc_calc/` |
| Open | 打开 Post Processor 手册（PDF） | `.../setupfiletypes_cnc_calc/` |
| Turning / Diameter programming | 车削 2D 模拟 / 直径编程 | `.../setupfiletypes_cnc_calc/` |
| Maximum arc output angle / Spline substitution tolerance | 生成 NC 中圆弧最大角 / 样条替代公差 | `.../setupfiletypes_cnc_calc/` |

### 2.4 示例脚本中的转换样例（来源：`.../scripts/writing-scripts/`）

| 示例 | 功能 | 来源页 |
|---|---|---|
| Fanuc to Heidenhain Klartext | 示例 converter，把 Fanuc 铣程序写为新 Heidenhain Klartext 程序；无法转换的块保留为注释并给警告 | `.../scripts/writing-scripts/` |

## 4. 标准操作步骤

### 4.1 用 Converters 转换 NC 方言
1. 备份原件或勾选 Result to new window；检查点：原件保留（`.../transform/`）。
2. NC Functions > Transform > Convert NC code；检查点：Convert NC code 对话框打开（`.../transform/`）。
3. Choose original NC format 选源格式；Choose converter 选目标 `.conv`（如 fanuc.conv/heidenhain.conv）；检查点：转换器路径指向 `\Converters`（`.../transform/`、本机枚举）。
4. 按需勾 Use longhand cycles（展开固定循环）或 Convert to NCI；检查点：目标格式/中间格式正确（`.../transform/`）。
5. 执行并检查新窗口结果；检查点：无法转换的块有注释/警告（如 Fanuc to Heidenhain 示例脚本行为）（`.../scripts/writing-scripts/`）。

### 4.2 Heidenhain ↔ ISO 互转
1. Transform > Heidenhain / ISO Converter；检查点：转换方向符合预期（`.../transform/`）。
2. 执行并核对圆弧/循环转换结果；检查点：Result to new window 保留源程序（`.../transform/`）。

### 4.3 配置 CNC-Calc 后处理
1. Editor Setup > File Types > CNC-Calc；检查点：当前 File Type 正确（`.../setupfiletypes_cnc_calc/`）。
2. 在 Selected Post Processor 选择目标后处理（如 Mill 用 fanuc.js / heidenhain.js，Lathe 用 Siemens Lathe.js）；检查点：后处理与机床控制系统匹配（`.../setupfiletypes_cnc_calc/`、本机枚举）。
3. 设置 Number of decimals、Maximum arc output angle、Spline substitution tolerance、Turning/Diameter programming；检查点：输出精度与机床要求一致（`.../setupfiletypes_cnc_calc/`）。
4. 点 Open 查阅所选 Post Processor 手册（PDF）；检查点：格式约定已确认（`.../setupfiletypes_cnc_calc/`）。

## 6. 行业最佳实践 / 常见误区

1. **误区：把 CIMCO Edit 当通用 CAM 后处理器。** B-04 明确通用 CAM 后处理在 CAM 软件侧；这里只有 CNC-Calc 后处理与方言转换。
2. **误区：把 `.ncjs` 脚本当成 `Posts/*.js`。** 前者是 NC Function Script（M02，需 Ultra），后者是 CNC-Calc 后处理定义（本节）；扩展名与机制不同。
3. **最佳实践：转换结果放新窗口。** Convert NC code 与脚本均支持 Result to new window，保留源程序用于核对（`.../transform/`、`.../scripts/`）。
4. **最佳实践：展开固定循环用 longhand。** 目标控制器不支持某固定循环时勾 Use longhand cycles 输出逐行（`.../transform/`）。
5. **最佳实践：后处理后查手册。** Selected Post Processor 对应有 Post Processor Manual（PDF），配置前先 Open 查阅格式约定（`.../setupfiletypes_cnc_calc/`、本机枚举）。
6. **误区：认为华中数控有官方原生模板。** 实测 converters/posts 无 Huazhong 原生项；走 ISO_G-Code 通用模板近似适配并需实测（B-03，本机 `PP_CASE2_Huazhong_ISO_Generic.js` 为派生案例而非官方原生）。
