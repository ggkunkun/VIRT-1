#### FAQ-001 双击安装程序没有任何反应，装不上 CIMCO Edit 2026
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「我双击 CIMCOEdit_2026xxxx.exe 没反应，安装向导不出现。」
- **根因**：官方安装章节要求先以具有完全管理员权限的账户登录，再运行安装程序；普通权限账户会被 UAC 拦截。
- **排查步骤**：1) 确认当前 Windows 账户属于 Administrators 组；2) 右键安装程序选「以管理员身份运行」；3) 若从下载链接获得，先把安装包复制到本机临时目录再运行（官方要求，避免网络/外接盘路径解析失败）。
- **解决方案**：换用管理员账户，右键 CIMCOEdit_2026xxxx.exe → 以管理员身份运行，按 Setup Wizard 完成安装。
- **验证**：开始菜单出现 CIMCO 2026 程序组，桌面出现 CIMCO Edit 2026 图标。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/
- **边界**：无

#### FAQ-002 安装前需要满足哪些最低系统配置
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「我的电脑能不能跑 CIMCO Edit 2026？」
- **根因**：官方 General System Requirements：客户端最低双核处理器、2 GB RAM、2 GB 可用磁盘空间；安装包内含 Microsoft Visual C++ v14 Redistributable（VS 2017-2026）与 .NET Framework 4.8。
- **排查步骤**：1) 查 CPU 核数与内存是否达双核/2 GB；2) 确认磁盘剩余 ≥2 GB；3) 确认 .NET 4.8 与 VC++ v14 运行库存在（安装器自带，缺则先装）。
- **解决方案**：按客户端最低配置准备；低于配置先升级内存或改用 64 位 Windows。服务端场景才需要 4 逻辑核/4 GB 起。
- **验证**：安装器不报「缺少运行库」类错误，首次启动不闪退。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/system-requirements/
- **边界**：无

#### FAQ-003 安装完成后找不到 CIMCO Edit 2026 的启动入口
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「装完了，桌面和开始菜单都找不到软件。」
- **根因**：官方安装说明：安装完成后会在开始菜单的 CIMCO 2026 程序组和桌面各放一个快捷方式；本机实装快捷方式解析目标为 CIMCOEdit_20260102\CIMCO 2026\CIMCOEdit。
- **排查步骤**：1) 检查开始菜单 → CIMCO 2026 程序组；2) 检查桌面快捷方式 CIMCO Edit 2026.lnk；3) 按 INS-01 直接定位 CIMCOEdit.exe 并右键发送到桌面快捷方式。
- **解决方案**：从开始菜单 CIMCO 2026 组启动，或直连 E:\仿真软件\CIMCOEdit_20260102\CIMCO 2026\CIMCOEdit\CIMCOEdit.exe。
- **验证**：能打开主窗口且标题栏显示 CIMCO Edit 2026。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/
- **边界**：无

#### FAQ-004 拿到 .CimcoLicense 许可文件后如何安装
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「供应商发来 CustomerName-license.CimcoLicense，不知道怎么装。」
- **根因**：官方安装章节：安装完成后双击该许可文件会打开 CIMCO License File Viewer，点击 Install license file 安装；如需激活会显示激活选项。
- **排查步骤**：1) 完成主程序安装；2) 双击 CustomerName-license.CimcoLicense 打开 License File Viewer；3) 点 Install license file；4) 若提示激活，按 FAQ-006/007 处理。
- **解决方案**：通过 License File Viewer 的 Install license file 装入许可，重启 CIMCO Edit。
- **验证**：启动后 Help → About 的 Licensed to 字段显示公司名称（评估版显示 Demo version）。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/
- **边界**：无

- **解决方案**：重新安装许可文件并重启；确为评估版则接受 Demo version 状态。
- **验证**：About 框 Licensed to 显示预期公司名称。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/
- **边界**：无

#### FAQ-006 在线激活失败或没有网络时如何激活许可
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「激活时点 Yes 没成功，车间电脑又不能上网。」
- **根因**：官方软件激活章节：选择需激活的许可文件后弹窗，能联网直接点 Yes 自动完成；不能联网走离线激活流程。
- **排查步骤**：1) 联网机器：在软件激活对话框点 Yes，等待自动完成；2) 离线机器：点 Create Activation Request 生成 .request 文件；3) 把 .request 拷到联网机，在 www.cimco.com/support/activate-software 上传并下载 .activation；4) 回到本机点 Use activated request 选 .activation。
- **解决方案**：联网用 Yes；离线用「.request → 官网激活 → .activation → Use activated request」闭环。
- **验证**：License File Viewer 中能看到激活信息，编辑器可正常使用全部已购功能。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/software-activation/
- **边界**：无

#### FAQ-007 更换电脑后许可报「License File already activated」
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「换新电脑，原来的许可用不了了，提示已激活。」
- **根因**：官方：许可文件可通过激活锁定到某台机器；换机需先重置激活，否则会报已激活错误。重装/升级操作系统但硬件（CPU、硬盘、MAC）未变通常不需重置。
- **排查步骤**：1) 确认是否真的更换硬件（非仅重装系统）；2) 若换机，联系经销商或 CIMCO Support 重置激活；3) 重置后在新系统按 FAQ-006 重新走激活流程。
- **解决方案**：由经销商/官方支持重置激活后再激活；仅重装系统则直接重新激活即可。
- **验证**：激活完成，About 显示正确公司名且功能可用。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/software-activation/
- **边界**：无

#### FAQ-008 Backplot 标签不见了，无法背绘
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「升级/新装后 Backplot 标签消失。」
- **根因**：官方 Plugins 章节：Disable Backplot 会移除 Backplot 标签，且 Backplot 需要 CIMCO Edit Professional 许可。
- **排查步骤**：1) Editor Setup → Plugins 查看 Disable Backplot 是否被勾选；2) 取消勾选并 OK；3) 若仍无该标签，核对许可等级是否为 Professional；4) 重启编辑器。
- **解决方案**：在 Editor Setup → Plugins 取消 Disable Backplot，并确认 Professional 许可。
- **验证**：Ribbon 出现 Backplot 标签，Ctrl+Shift+P 可启动背绘。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/editor-setup/plugins/
- **边界**：无

#### FAQ-009 Machine Simulation 菜单/机床仿真用不了
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「听说 2026 能整机仿真碰撞，我这边菜单是灰的/看不到。」
- **根因**：官方明确：Machine Simulation 是 CIMCO Edit 2026 的 add-on，只有安装有效许可后才出现；本机许可状态未核实，按未验证处理。禁止宣称「全维度机床模拟与碰撞检测」已可用。
- **排查步骤**：1) Help → About 核对许可是否含 Machine Simulation；2) 确认 Editor Setup → Machine Models 能列出并可安装机器；3) 若无该许可，退回标准背绘（Backplot）+ 静态 G00 哨兵路线，不对外宣称整机碰撞能力。
- **解决方案**：有 add-on 许可：装机器模型后从 Backplot → Machine Simulation 启动。无许可：仅用 Backplot，并按 B-01 标注边界。
- **验证**：有许可时 Simulation Report 出现碰撞/限位信息；无许可时菜单不出现且文档已标注 B-01。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/simulation/machine-simulation/
- **边界**：B-01

#### FAQ-011 DNC/串口传输菜单不可用

#### FAQ-013 多开实例编辑同一文件时弹出访问冲突警告
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「两个 CIMCO 窗口打开同一个 .nc，互相报警。」
- **根因**：官方 General：Warn about access conflicts 启用后会提示另一实例正在打开同一文件；该功能依赖隐藏文件，目录权限必须至少为 Read 或 Full，若可创建但不可删除会残留隐藏文件。
- **排查步骤**：1) General → 勾选/取消 Warn about access conflicts 按需设置；2) 检查共享目录权限是否为 Read 或 Full；3) 清理残留隐藏锁文件（确认无其他实例占用后）。
- **解决方案**：无需多开则关闭该警告；需多开则修复目录权限并保证权限可删文件。
- **验证**：打开文件时不再出现误报的访问冲突。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/editor-setup/general/
- **边界**：无

#### FAQ-014 配置、宏、刀具库应该放安装目录还是用户目录
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「多人共用一台电脑，想让大家用同一套配置。」
- **根因**：官方安装说明：勾选 Place configuration in install directory 会把配置/宏/刀具库放到安装目录供所有用户共用；不勾选则放到各用户 AppData\Roaming\CIMCO 2026\CIMCOEdit。本机 ConfigPaths.cfg 显示 ROOTDIR 指向 %APPDATA% 再派生 CFG/DATA/MACHINES/TYPES/TOOLLIBS。
- **排查步骤**：1) 决定共用还是按用户隔离；2) 安装时按需勾选 Place configuration in install directory；3) 已安装后可在 Editor Setup → Plugins → Edit configuration paths 改路径并复制现有配置。
- **解决方案**：共用安装目录方案勾选该选项；按用户隔离保持默认 AppData 方案。
- **验证**：不同账户登录后看到预期的同一套或各自独立的配置。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/installation/
- **边界**：无

#### FAQ-016 忘记了 Editor Setup 的配置密码
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「设置里加了密码保护，现在打不开设置了。」
- **根因**：官方 Plugins：Enable configuration password protection 可锁 Editor Setup；忘记密码时，启动编辑器期间按住 Ctrl+Shift 即可绕过。
- **排查步骤**：1) 完全关闭 CIMCO Edit；2) 按住 Ctrl+Shift 不放，双击图标启动；3) 进入 Editor Setup → Plugins 取消密码保护或重设密码。
- **解决方案**：启动时按住 Ctrl+Shift 进入设置，取消 Enable configuration password protection。
- **验证**：无需原密码即可进入 Editor Setup。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/editor-setup/plugins/
- **边界**：无

#### FAQ-017 如何备份和迁移整套配置到另一台电脑
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「换电脑想把颜色/宏/机床配置全搬过去。」
- **根因**：官方 Editor Setup 底部按钮：Export 把整个配置导出为 .zip（可作备份或用于另一台 PC）；Import 导入配置，且需重启生效。
- **排查步骤**：1) 原机 Editor Setup → Export 导出配置 .zip；2) 拷到新机；3) 新机 Editor Setup → Import 选该 .zip；4) 重启 CIMCO Edit 使配置生效。
- **解决方案**：用 Export/Import .zip 迁移，导入后务必重启。
- **验证**：新机的文件类型、颜色、宏、机床配置与原机一致。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/editor-setup/
- **边界**：无

#### FAQ-018 能否用命令行直接打开一个 NC 程序
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「想从脚本/批处理直接拉起程序并加载 .nc。」
- **根因**：CIMCO 无 COM 自动化（confirmed-negative），自动化通道是命令行拉起加外部 Python 桥接；官方 Pending Updates 记载 --no-bring-to-front 与 --savebundle path 等命令行开关。
- **排查步骤**：1) 直接执行 CIMCOEdit.exe <file.nc> 打开指定程序；2) 需要不抢前台时加 --no-bring-to-front；3) 需要导出仿真包时用 --savebundle path；4) 复杂校验走 cimco_bridge.py，不依赖 COM。
- **解决方案**：用 CIMCOEdit.exe <file.nc> 拉起；自动化校验用 D:\Virtu模型\bridges\cimco_bridge.py。
- **验证**：命令行执行后指定 NC 在编辑器中打开，或桥接返回校验结果。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/pending-updates/
- **边界**：无

#### FAQ-019 想让 AI 智能体帮忙编辑 NC，怎么接
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「听说 2026 能连 AI Agent，怎么配置？」
- **根因**：官方 Connect to AI Agents：Help → Connect to AI Agents... 可连接 Claude/Codex；需要 Ultra 许可，无许可时菜单不出现。AI 可执行 Ribbon 命令、背绘/仿真、读写机床类型等，但不能收发程序、不能删 NC-Base 程序。
- **排查步骤**：1) Help → Connect to AI Agents...；2) 在点名的 agent 上点 Connect（Claude 桌面版会被关闭重启）；3) 在 agent 中新开会话；4) 断开需删除 agent 配置里的 cimco-edit 条目。
- **解决方案**：有 Ultra 许可时在 Help → Connect to AI Agents... 完成连接；无许可则不宣称该功能可用。
- **验证**：agent 会话中可读取并修改当前打开的 NC 程序。
- **证据**：https://docs.cimco.com/en/docs/edit/2026/editor-helpeditor-help/connect-ai-agents/
- **边界**：B-01

#### FAQ-020 提示有新版本，但不想每次启动都提醒
- **分类**：安装与启动 ｜ **适用版本**：CIMCO Edit 2026
- **现象**：「每次开机都弹 Download Latest Version。」
