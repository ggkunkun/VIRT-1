## 3. 命令引用约定

文档中的命令统一写成：

```
[CMD:UG_MODELING_EXTRUDED_FEATURE] 拉伸
```

- `CMD:` 后是 NX 12.0 的**命令标识**（来自 `definitions_*.btn`，稳定、可审计）；
- 紧跟的中文名是 **NX 12.0 中文界面实际显示名**（来自官方对照表，已去掉助记符 `&`）；
- 审计脚本会逐条核对“命令存在 + 中文名一致 + 有菜单路径”，任一条不符即判红：
  `python tools/extract_nx12_cn_catalog.py --audit .`

## 4. 3 秒定位任意命令（版本内通用）

| 场景 | 操作 | 说明 |
| :--- | :--- | :--- |
| 知道中文名 | `帮助(H) → 命令查找器(F)...`，输入中文名或同义词，回车 | NX 12 命令查找器会给出**菜单路径 + 图标位置**；这是最快的入口 |
| 知道功能、不知道名字 | 命令查找器输入英文/拼音/近义词（如“倒角”→ 倒斜角） | 同义词库来自 `SYNONYMS` 字段 |
| 想固化快捷键 | `工具(T) → 定制(Z)...`（`Ctrl+1`）→ 键盘 → 搜索命令 → 指派 | 快捷键按用户保存，不改变安装介质 |
| 找不到某个组 | `工具(T) → 定制(Z)...` → 工具条/功能区 → 勾选对应组 | 组被隐藏是最常见的“命令消失”原因 |
| 界面被插件改乱 | `首选项(P) → 用户界面(I)...` → 角色/布局 → 重置为 `高级` 或 `基本` | 本机插件会在根菜单插入条目，原生命令仍在原路径 |

> **版本差异提醒**：NX 12 中文把回转体命令译作 **旋转**（`UG_MODELING_REVOLVED_FEATURE`），
> 不叫“回转”。本库一律使用中文版实际显示名；需求文档里的“回转”在此对应“旋转”。

## 5. 已验证的最小闭环

```text
文件(F) → 新建(N)... (Ctrl+N, 模型/mm)
  → 插入(S) → 曲线(C) → 直线(L)...                         [草图外轮廓]
  → 插入(S) → 设计特征(E) → 拉伸(X)...  距离 0→10 mm       [实体]
  → 分析(L) → 测量(S)...  体积 = 60 000 mm³                [体积守恒]
  → 文件(F) → 保存(S) (Ctrl+S)                             [落盘 .prt]
```

实测结果：体积 `59999.99999999999 mm³`，相对误差 `1.21e-14`，`.prt` 已生成。
证据：`runs/nx12_cn_verify/verify_result.json`（`ok=true`，`basis=measured`）。
