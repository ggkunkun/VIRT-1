# 版本差异对照库（严格边界）

> 本训练体系唯一适配：**NX12.0-CN**（介质版本字符串见下）。
> 原则：凡未能从本机介质或其它版本官方介质直接取证的差异，一律列入「待核对」，不臆造。

## 一、本版本可证事实（measured）

- 介质版本标识：`NX 12.0（12.0.2.9 介质，含第三方外挂菜单）`
- UI 语言：`simpl_chinese（简体中文）`
- 菜单文件头版本号：`VERSION 121`（见 `MACH/application/ug_cam.men` 等）
- 主程序：`NXBIN/ugraf.exe`（SHA256 见 catalog key_sources_sha256）
- 介质内含第三方外挂目录：`YANGJEE`（YSUG/QuickCAM/TKLTOOLS）、`KASA`、`MS_NXTOOLS`、`NX_CHINA_PACKAGE` 等；这些外挂命令 **不是 Siemens 官方功能**，已归入「15_其他与第三方外挂」，训练时禁止与官方命令混用。
- 菜单中同时存在「原/原有」标记的旧命令（如「基本曲线（原有）」「边倒圆」旧版），说明本版本保留向后兼容命令。
