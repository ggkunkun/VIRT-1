# 01-01 草图标准流程与参数

> 适用：NX 12.0 中文版。草图是参数化建模的地基：**草图不闭合/不全约束，后面所有特征都是沙上建塔**。

## 1. 两种草图模式（先选对入口）

| 模式 | 路径 | 特点 | 适用 |
| :--- | :--- | :--- | :--- |
| **直接草图** | `插入(S)` → `草图(H)...`（`UG_INSERT_DIRECT_SKETCH`） | 在当前视图直接画，草图与建模命令可交替 | 简单截面、补面、快速修改 |
| **任务环境草图**（推荐） | `插入(S)` → `在任务环境中绘制草图(V)`（`UG_TOOLBOX_SKETCH`） | 独立草图环境，菜单完整（草图曲线/草图约束/尺寸），约束工具齐全 | 参数化零件、需要全约束的正式设计 |

> 两者生成的草图本质相同；区别是可用命令与界面。**正式零件一律用任务环境草图**，避免在建模环境里找不到“草图约束”菜单。

## 2. 标准操作流程（12 步，可直接照做）

| 步 | 操作 | 路径/参数 | 判据 |
| :--- | :--- | :--- | :--- |
| 1 | 新建毫米零件 | `文件(F)` → `新建(N)...`（`Ctrl+N`）→ `模型` → 毫米 | 标题栏单位为 mm |
| 2 | 进入任务环境草图 | `插入(S)` → `在任务环境中绘制草图(V)` | 进入草图，菜单变为 `任务(K)/草图曲线(S)/草图约束(N)/尺寸(D)` |
| 3 | 选草图平面 | 选 `XY/XZ/YZ` 基准面或已有平面；必要时指定“反向” | 草图法向与建模方向一致（一般零件主轮廓放 XY） |
| 4 | 定向视图 | `任务(K)` → `定向视图到草图(K)` | 视图正对草图平面 |
| 5 | 画外轮廓 | `插入(S)` → `草图曲线(S)` → `直线(L)...` / `圆(C)...` / `矩形(R)...` | 轮廓首尾相接，无重叠、无交叉 |
| 6 | 倒圆角 | `插入(S)` → `草图曲线(S)` → `圆角(F)...`（`UG_SKETCH_FILLET`） | 圆角与两边相切 |
| 7 | 修剪多余线 | `编辑(E)` → `草图曲线(K)...` → `快速修剪(Q)...` | 轮廓只剩一条闭合环 |
| 8 | 加几何约束 | `插入(S)` → `几何约束(T)...`（`UG_SKETCH_CONSTRAINTS`） | 水平/竖直/相切/同心等符号出现 |
| 9 | 标尺寸 | `插入(S)` → `尺寸(M)` → `快速(P)...` | 关键尺寸全部标注 |
| 10 | 全约束检查 | 看状态栏“草图已完全约束”；拖拽曲线不应移动 | 自由度 = 0 |
| 11 | 评估草图 | `工具(T)` → `更新(U)` → `评估草图(V)` | 无冲突、无开放端 |
| 12 | 完成草图 | `任务(K)` → `完成草图(K)` | 回到建模，草图折叠进部件导航器 |

## 3. 草图曲线命令表（中文名/路径/参数）

| 命令 | 路径 | 关键参数 | 合法范围/建议 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_SKETCH_LINE] 直线 | `插入(S)` → `草图曲线(S)` → `直线(L)...` | 起点/终点；长度、角度 | 长度 > 0；与已有曲线端点重合时自动加“重合”约束 |
| [CMD:UG_SKETCH_ARC] 圆弧 | `插入(S)` → `草图曲线(S)` → `圆弧(A)...` | 圆心/半径/起止角；三点 | 半径 > 0；起止角不相等 |
| [CMD:UG_SKETCH_CIRCLE] 圆 | `插入(S)` → `草图曲线(S)` → `圆(C)...` | 圆心/直径 | 直径 > 0 |
| [CMD:UG_SKETCH_RECTANGLE] 矩形 | `插入(S)` → `草图曲线(S)` → `矩形(R)...` | 两对角点；宽×高 | 宽、高 > 0；矩形自带水平/竖直约束 |
| [CMD:UG_SKETCH_PROFILE] 轮廓 | `插入(S)` → `草图曲线(S)` → `轮廓(O)...` | 连续直线/圆弧 | 适合一笔画闭合外形；直线与圆弧模式用图标切换 |
| [CMD:UG_SKETCH_FILLET] 圆角 | `插入(S)` → `草图曲线(S)` → `圆角(F)...` | 半径 | 0 < R < 相邻边可容纳范围；过大时 NX 拒绝并提示 |
| [CMD:UG_SKETCH_QUICK_TRIM] 快速修剪 | `编辑(E)` → `草图曲线(K)...` → `快速修剪(Q)...` | 光标划过的线段 | 一次可划多段；剪到只剩封闭环 |
| [CMD:UG_SKETCH_QUICK_EXTEND] 快速延伸 | `编辑(E)` → `草图曲线(K)...` → `快速延伸(X)...` | 要延伸的曲线 + 边界 | 必须有可相交边界，否则报“无法延伸” |
| [CMD:UG_SKETCH_OFFSET_CURVES] 偏置曲线 | `插入(S)` → `草图曲线(S)` → `偏置曲线(V)...` | 偏置距离、方向、副本数 | 距离 ≠ 0；向内偏置不能大于最小曲率半径，否则自交 |
| [CMD:UG_SKETCH_PATTERN_CURVES] 阵列曲线 | `插入(S)` → `草图曲线(S)` → `阵列曲线(P)...` | 线性/圆形；数量、节距、角度 | 数量 ≥ 2；节距 > 0；圆形阵列角度总和不超 360° |
| [CMD:UG_SKETCH_MIRROR_PATTERN] 镜像曲线 | `插入(S)` → `草图曲线(S)` → `镜像曲线(M)...` | 镜像中心线 | 中心线必须是参考线或实线；镜像后保持约束 |
| [CMD:UG_SKETCH_ADD_EXTRACTED_CURVES] 投影曲线 | `插入(S)` → `草图曲线(S)` → `投影曲线(J)...` | 选择曲线/边、投影方向 | 投影方向不能与曲线平行；投影后可能丢失原约束 |

## 4. 参数与范围（软件合法 + 工程推荐）

| 参数 | 软件行为 | 推荐值 | 说明 |
| :--- | :--- | :--- | :--- |
| 草图平面偏置 | 可输入任意实数 | 0（贴基准面） | 偏置后尺寸链会多一层，非必要不用 |
| 尺寸值 | 必须 > 0（长度/半径/直径） | 按设计 | 负值 NX 直接拒绝；需要反向用“备选解”或改约束方向 |
| 角度 | −360°～360° 可输入 | 0°～180° 表达形状 | 大于 180° 的角度尺寸易产生歧义，改用两段标注 |
| 圆角半径 | > 0 且小于相邻边可用长度 | 按工艺 R1/R2/R3 | 过大时提示“无法创建圆角”；先加大相邻边或改约束 |
| 偏置距离 | ≠ 0 | 0.5～5 mm（板厚/壁厚相关） | 大于曲率半径会自交，NX 报“偏置失败” |
| 阵列数量 | 整数 ≥ 2 | 按孔数 | 数量过大（>1000）会显著拖慢草图 |

## 5. 「全约束」的判定与做法

**判定（三条同时满足）**：

1. 状态栏显示“草图已完全约束”（或“完全约束”）。
2. 用鼠标拖拽任意曲线，曲线不动。
3. `工具(T)` → `约束(T)` → `草图关系浏览器(B)...` 中自由度数为 0。

**做法（从大到小）**：

1. 先加“几何约束”（水平/竖直/相切/同心/对称），不要一上来标尺寸。
2. 再标“定位尺寸”（相对基准/原点），最后标“形状尺寸”（长宽半径）。
3. 每个尺寸都尽量由表达式驱动（`Ctrl+E`）；
4. 出现“过约束”时，删掉多余尺寸而不是删约束。

## 6. 工程最佳实践（机械设计通用）

- **一个草图只做一个特征**：拉伸一个截面、旋转一个截面；不要把最终零件所有轮廓画在一张草图里。
- **主轮廓放在基准面**，对称件用“对称”约束 + 中心线，后续镜像/阵列才稳定。
- **避免在草图里用样条**做规则外形；样条难以标注、难以加工、工程图无法表达。
- **轮廓闭合**：拉伸实体必须闭合；拉伸片体可以开放，但后续缝合会麻烦。
- **不要用“转换至/自参考对象”藏尺寸**来假装全约束；参考线只用于构造。
- **尺寸基准统一**：以设计基准（装配面/中心线）标注，不从任意边标起。
- **草图命名**：部件导航器里重命名为 `SK_主轮廓`、`SK_孔位`，后期改图不迷路。
