# 01-02 草图约束与尺寸（全约束方法论）

> 目标：把“看起来对”的草图变成“数学上唯一”的草图。自由度不归零，后续改一个尺寸会引发连锁变形。

## 1. 几何约束命令表（任务环境草图）

路径统一为 `插入(S)` 下的 `草图约束` 组，或直接 `草图约束(N)` 菜单。

| 约束 | 命令路径 | 用途 | 选择对象数 |
| :--- | :--- | :--- | :--- |
| 几何约束（总入口） | `插入(S)` → `几何约束(T)...`（`UG_SKETCH_CONSTRAINTS`） | 一次加多种约束 | 按类型 |
| 重合 | `草图约束(N)` → `重合(O)`（`UG_SKETCH_COINCIDENT_CONSTRAINT`） | 端点/点落在曲线或点上 | 2 |
| 点在曲线上 | `草图约束(N)` → `点在曲线上(T)` | 点约束到曲线 | 2 |
| 中点 | `草图约束(N)` → `中点(D)` | 点在线中点 | 2 |
| 相切 | `草图约束(N)` → `相切(A)` | 曲线与曲线相切 | 2 |
| 平行 | `草图约束(N)` → `平行(R)` | 两直线平行 | 2 |
| 垂直 | `草图约束(N)` → `垂直(C)` | 两直线垂直 | 2 |
| 水平 | `草图约束(N)` → `水平(H)` | 直线水平 | 1 |
| 竖直 | `草图约束(N)` → `竖直(V)` | 直线竖直 | 1 |
| 水平对齐 | `草图约束(N)` → `水平对齐(Z)` | 两点 Y 相等 | 2 |
| 竖直对齐 | `草图约束(N)` → `竖直对齐(R)` | 两点 X 相等 | 2 |
| 共线 | `草图约束(N)` → `共线(I)` | 两线共线 | 2 |
| 同心 | `草图约束(N)` → `同心(E)` | 两圆/弧同心 | 2 |
| 等长 | `草图约束(N)` → `等长(U)` | 两线等长 | 2 |
| 等半径 | `草图约束(N)` → `等半径(Q)` | 两圆等半径 | 2 |
| 固定 | `草图约束(N)` → `固定(X)` | 锁定曲线位置 | 1+ |
| 完全固定 | `草图约束(N)` → `完全固定(Y)` | 锁定全部自由度 | 1+ |
| 定角 | `草图约束(N)` → `定角(G)` | 固定两线夹角 | 2 |
| 定长 | `草图约束(N)` → `定长(L)` | 固定线长 | 1 |
| 设为对称 | `插入(S)` → `设为对称(M)...`（`UG_SKETCH_SYMMETRIC_CONSTRAINT`） | 关于中心线对称 | 2+1 |
| 曲线的斜率 | `草图约束(N)` → `曲线的斜率(P)` | 约束样条斜率 | 1+ |
| 均匀比例 / 非均匀比例 | `草图约束(N)` → `均匀比例(F)` / `非均匀比例(M)` | 样条比例约束 | 1 |

## 2. 尺寸命令表

| 尺寸 | 路径 | 适用 | 参数 |
| :--- | :--- | :--- | :--- |
| 快速尺寸 | `插入(S)` → `尺寸(M)` → `快速(P)...`（`UG_SKETCH_RAPID_DIMENSION`） | 自动判断类型（长度/半径/角度） | 选对象→放位置；值 > 0 |
| 线性尺寸 | `插入(S)` → `尺寸(M)` → `线性(L)...` | 两点/两线距离 | 水平/竖直/点到线 |
| 径向尺寸 | `插入(S)` → `尺寸(M)` → `径向(R)...` | 圆/弧半径或直径 | 半径 > 0 |
| 角度尺寸 | `插入(S)` → `尺寸(M)` → `角度(A)...` | 两线夹角 | 0°～180° 表达更清晰 |
| 周长尺寸 | `插入(S)` → `尺寸(M)` → `周长(M)...` | 闭合环总长 | 仅对闭合轮廓；值 > 0 |
| 水平/竖直尺寸 | `插入(S)` → `尺寸(M)` → `水平(H)...` / `竖直(V)...` | 强制方向 | 两对象 |
| 平行/垂直尺寸 | `插入(S)` → `尺寸(M)` → `平行(P)...` / `垂直(E)...` | 斜向距离 | 两对象 |

> NX 12 的“快速尺寸”能覆盖 80% 场景；只有需要强制方向或基准链时才用线性/水平/竖直尺寸。

## 3. 自动约束与自动尺寸（提速，但别滥用）

| 命令 | 路径 | 作用 | 风险 |
| :--- | :--- | :--- | :--- |
| 自动约束 | `工具(T)` → `约束(T)` → `自动约束(A)...`（`UG_SKETCH_AUTO_CREATE_CONSTRAINTS`） | 按当前几何关系批量加水平/竖直/相切/同心 | 会把“看起来接近”的关系也加上，造成后期改不动 |
| 自动尺寸 | `工具(T)` → `约束(T)` → `自动尺寸(U)...`（`UG_SKETCH_AUTO_CREATE_DIMENSIONS`） | 自动补齐定位/形状尺寸 | 尺寸基准可能不是你想要的，必须逐条复核 |
| 自动判断约束和尺寸 | `工具(T)` → `约束(T)` → `自动判断约束和尺寸(I)...`（`UG_SKETCH_INFER_CONSTRAINT_SETTINGS`） | 设置绘图时自动推断哪些约束 | 建议只开“端点重合/相切/水平竖直”，关掉“自动尺寸” |

**纪律**：自动约束/自动尺寸之后，必须进入 `草图关系浏览器` 逐条检查；否则会得到“全约束但改一个尺寸全乱”的草图。

## 4. 全约束的数学做法（自由度账本）

一张草图的总自由度 = 每条曲线自由度之和 − 约束消除的自由度。

| 曲线 | 自由度 |
| :--- | :--- |
| 点 | 2（X、Y） |
| 直线 | 4（两端点各 2） |
| 圆 | 3（圆心 2 + 半径 1） |
| 圆弧 | 5（圆心 2 + 半径 1 + 起止角 2） |

标准做法：
1. 固定基准：把草图原点/基准线与坐标系关系定死（通常靠“重合到原点”）。
2. 加形状约束：水平/竖直/相切/同心/等长，消掉大部分自由度。
3. 加定位尺寸：先定基准边（左/下），再定其他边。
4. 加形状尺寸：长、宽、半径、角度。
5. 看状态栏：未全约束时，拖拽曲线会动；全约束后拖不动。

## 5. 冲突与过约束的处理

| 现象 | 原因 | 处理顺序 |
| :--- | :--- | :--- |
| 曲线变红/黄，状态栏“过约束” | 同一自由度被两个约束/尺寸重复限制 | ① `工具(T)` → `约束(T)` → `显示/移除约束（即将失效）(R)...` 看重复项；② 删多余尺寸（优先删尺寸，不删几何约束）；③ 用 `草图关系浏览器` 复核 |
| 改尺寸后形状跳到另一侧 | 存在多个解（如圆弧可凸可凹） | `工具(T)` → `约束(T)` → `备选解(O)...`，点选目标解 |
| 尺寸改不动/灰显 | 被表达式锁定、或是参考尺寸 | ① 检查 `工具(T)` → `表达式(X)...` 是否有同名表达式；② 看尺寸颜色（参考尺寸不可改）；③ 需要驱动就改为普通尺寸 |
| 约束符号看不见 | 显示设置关闭 | `任务(K)` → `草图设置(K)...` → 勾选“显示约束符号/显示自由度” |
| 草图整体位置不对 | 没约束到基准 | 加“重合”把关键点锁到原点/基准线；或 `重新附着草图`（`UG_SKETCH_REATTACH`） |

## 6. 参考对象（构造线）的正确用法

- `工具(T)` → `约束(T)` → `转换至/自参考对象(V)...`（`UG_SKETCH_ACTIVE_REFERENCE_SWITCH`）：把实线变参考线。
- 参考线**不参与拉伸截面**，但可作为镜像中心线、对称轴、尺寸基准。
- 不要把“多余线”转成参考线来掩盖轮廓不闭合；拉伸仍会失败。

## 7. 证据与边界

- 约束/尺寸命令与路径：`catalog/nx12_cn_commands.json` 中 `UG_SKETCH_*_CONSTRAINT`、`UG_SKETCH_*_DIM`。
- 自由度表为几何常识；NX 实际显示的自由度箭头以状态栏为准。
- “自动约束”的具体推断规则由 NX 内部决定，本库只给使用纪律，不臆造算法。
