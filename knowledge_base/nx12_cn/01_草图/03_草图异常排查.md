# 01-03 草图异常排查手册

> 规则：每条问题给 **≥3 步可执行排查**，每步都带菜单路径；修复后必须复验（拖拽/评估/完成草图）。

## 1. 草图无法完全约束

**现象**：状态栏显示“草图欠约束”，拖拽曲线仍能动；完成草图后改尺寸模型变形。

**排查（按顺序）**：
1. `任务(K)` → `草图设置(K)...` → 勾选“显示自由度箭头”，看箭头指向哪些点/线。
2. `工具(T)` → `约束(T)` → `草图关系浏览器(B)...`（`UG_SKETCH_CONSTRAINT_NAVIGATOR`），逐条看未约束对象。
3. 检查草图原点/基准线是否与坐标系建立“重合”约束——很多欠约束是整体没定位。

**修复**：
- 先加几何约束（水平/竖直/相切/同心），再补定位尺寸（相对基准边），最后补形状尺寸。
- 对称件加中心线 + `插入(S)` → `设为对称(M)...`，一次消两个自由度。

**预防**：画图前先定“基准边/中心线”，不要从任意位置起笔。

## 2. 拉伸提示“截面不闭合”

**现象**：`插入(S)` → `设计特征(E)` → `拉伸(X)...` 选择草图后提示“截面不闭合/无法创建实体”。

**排查**：
1. 进入草图，`工具(T)` → `更新(U)` → `评估草图(V)`（`UG_SKETCH_EVALUATE_SKETCH`），看开放端位置。
2. `任务(K)` → `草图设置(K)...` 打开“显示端点”，端点未重合处会有高亮小圈。
3. 用 `编辑(E)` → `草图曲线(K)...` → `快速修剪(Q)...` 放大检查：是否有两条线重叠、或有极小缺口。

**修复**：
- 端点不重合：加“重合”约束，或拖动端点到吸附点。
- 重叠线：剪掉其中一条，保留单环。
- 自交轮廓：把交叉处剪开重连；必要时分两次拉伸再布尔。
- 轮廓确实需要开放：把拉伸“体类型”改为 `片体`，但后续缝合/加厚要单独处理。

**预防**：外轮廓一次画完；不要用两条线叠在一起“看起来闭合”。

## 3. 约束冲突、曲线变红

**现象**：加约束时提示“约束冲突”，已有曲线变红/变黄。

**排查**：
1. `工具(T)` → `约束(T)` → `显示/移除约束（即将失效）(R)...`（`UG_SKETCH_SHOW_REMOVE_CONSTRAINTS`），列出当前对象的全部约束。
2. 找重复：同一对线既有“平行”又有“定角 0°”，或同一尺寸标了两次。
3. 看是否把“参考线”当实线加了约束（参考线约束不影响轮廓，但会误导判断）。

**修复**：
- 优先删**尺寸**，保留几何约束；仍冲突再删多余几何约束。
- 用 `备选解(O)...` 切换解的象限，而不是硬加约束。
- 实在解不开：`编辑(E)` → `草图参数(A)...` 检查是否有“固定”把整条线锁死。

**预防**：自动约束后逐条复核；同一自由度只留一个约束源。

## 4. 改尺寸后形状乱跳

**现象**：改一个长度，圆弧翻到另一边，或整个轮廓旋转。

**排查**：
1. 看状态栏是否“完全约束”；欠约束时改尺寸必然乱跳。
2. `工具(T)` → `约束(T)` → `草图关系浏览器(B)...` 看哪个自由度未被限制。
3. 对圆弧/样条：检查是否有“备选解”可用（同一几何存在多解）。

**修复**：
- 补齐定位尺寸（草图相对基准的位置）。
- 对圆弧：`工具(T)` → `约束(T)` → `备选解(O)...`（`UG_SKETCH_ALTERNATE_SOLUTION`）。
- 对样条：加“曲线的斜率/均匀比例”约束，或改用圆弧+直线近似。

**预防**：先定位后形状；对称件用中心线约束，别靠坐标数值硬凑。

## 5. 草图平面选错/方向反

**现象**：草图画出后，拉伸方向朝里/朝外不对；或草图在错误基准面上。

**排查**：
1. 部件导航器展开草图，右键 → `编辑草图(K)...`（`UG_EDIT_SKETCH`），看“草图平面”字段。
2. `任务(K)` → `草图设置(K)...` 看草图坐标系方向。
3. 视图定向：`任务(K)` → `定向视图到草图(K)`，确认法向是否指向预期。

**修复**：
- 未完成草图：直接重新选平面（对话框里点“反向”切换法向）。
- 已完成草图：右键草图 → `重新附着草图(H)...`（`UG_SKETCH_REATTACH`），换平面/翻转法向；注意尺寸会重算，需复核。
- 拉伸方向反：在拉伸对话框点“反向”，不要靠负距离硬改。

**预防**：主轮廓统一放 `XY` 平面；对称件把中心线放在 `X` 或 `Y` 轴。

## 6. 投影曲线失败

**现象**：`插入(S)` → `草图曲线(S)` → `投影曲线(J)...` 选择边/曲线后无结果或报错。

**排查**：
1. 检查投影方向：方向与曲线平行时投影退化为点，NX 无法生成。
2. 检查投影对象是否在草图平面“背后”且超出范围；必要时改“投影方向”为“沿矢量/到平面”。
3. 检查源曲线是否已被其他特征消耗/隐藏；用 `信息(I)` → `对象(O)...` 确认其存在与所属部件。

**修复**：
- 换投影方向（垂直于草图平面最稳）。
- 先 `插入(S)` → `派生曲线(U)` → `投影(P)...` 在建模环境生成 3D 曲线，再投影进草图。
- 装配中跨组件投影：确认工作部件正确，必要时用 WAVE 链接。

**预防**：投影前把源曲线放到独立图层，避免被裁剪/隐藏。

## 7. 快速修剪剪不掉/剪错

**现象**：`快速修剪(Q)...` 划过的线段没反应，或把不该剪的剪了。

**排查**：
1. 看选择条过滤：是否只允许选择“曲线”；过滤到“边/面”会剪不动。
2. 放大检查是否两条线重合：快速修剪按“段”剪，重合时会剪错对象。
3. 看曲线是否被“固定/完全固定”约束锁死；锁定对象不能被修剪。

**修复**：
- 先删重合线/参考线，再修剪。
- 解除“固定”约束（`显示/移除约束` 里删）。
- 剪错立即 `Ctrl+Z`；不要连续剪多次后再撤销。

**预防**：画线时打开捕捉，避免重叠；修剪前 `Ctrl+J` 改颜色区分。

## 8. 尺寸灰显改不了

**现象**：双击尺寸没有输入框，或输入后自动跳回。

**排查**：
1. 看尺寸颜色：参考尺寸（括号显示）不可驱动。
2. `工具(T)` → `表达式(X)...`（`Ctrl+E`）搜同名表达式；表达式驱动的尺寸要在表达式里改。
3. 检查是否有“固定/完全固定”约束把对象锁死。

**修复**：
- 参考尺寸：删掉重标为普通尺寸；或 `转换至/自参考对象` 反向转回。
- 表达式驱动：在表达式对话框改值，`工具(T)` → `更新(U)` → `全部更新(U)`。
- 锁定：删“固定”约束，保留几何约束。

**预防**：标尺寸时确认不是“参考”；关键尺寸统一用表达式命名（`D_`、`L_`）。

## 9. 完成草图后模型报错

**现象**：改完草图点 `完成草图(K)`，拉伸/旋转变红，提示“无法更新”。

**排查**：
1. 部件导航器看红色特征，右键 → `信息` 看具体报错（常见：截面不闭合、自交、圆角半径过大）。
2. `工具(T)` → `更新(U)` → `全部更新(U)`，确认是草图问题还是后续特征问题。
3. 回滚到草图之前：拖动部件导航器“当前特征”到草图上方，看模型是否恢复。

**修复**：
- 截面问题：回草图修轮廓（§2）。
- 圆角/抽壳失败：先抑制后续特征，改草图，再逐段恢复。
- 父子关系丢失：`编辑(E)` → `特征(F)` → `编辑参数(P)...` 重新指定草图。

**预防**：改草图前先 `Ctrl+S`；大改前用“另存为”留版本。

## 10. 草图在部件导航器里找不到

**现象**：模型上有草图曲线，但部件导航器看不到。

**排查**：
1. 确认当前显示的是“模型”部件还是装配顶层；草图可能在组件里（装配导航器 → 双击组件设为工作部件）。
2. 部件导航器过滤器：勾选“草图”和“已抑制”；被抑制的特征不显示。
3. 看是否在“分组/设计组”里被折叠：展开 `设计组`/`特征组`。

**修复**：
- 切工作部件：装配导航器右键组件 → `设为工作部件(W)`。
- 取消抑制：右键 → `取消抑制(U)`。
- 展开组：双击组节点。

**预防**：草图命名并放入固定组；装配中明确“工作部件”再建草图。

## 证据与边界

- 所有命令 ID 与中文名取自 `catalog/nx12_cn_commands.json`，可用审计脚本复核。
- 报错文案随语言包略有差异；本手册按“提示语义”归类，不逐字复刻弹窗。
- 排查步骤均可在 NX 12.0 中文界面复现；未涉及任何其他版本命令。
