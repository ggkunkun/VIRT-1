# 00-01 界面布局与命令体系（NX 12.0 中文版）

> 适用：NX 12.0.2.9 简体中文。所有中文名取自安装介质官方对照表，可直接与屏幕逐字比对。

## 1. 启动与界面布局

### 1.1 启动前环境（本机实测）

| 项 | 值 | 说明 |
| :--- | :--- | :--- |
| 语言 | `UGII_LANG=simpl_chinese`、`UGII_COUNTRY=prc` | 缺一不可；只设 `UGII_LANG` 时部分 GB 模板页签不出现 |
| 根目录 | `UGII_BASE_DIR=<NX>\NX` | 本机为 `D:\BaiduNetdiskDownload\NX 12.0.2.9\...\NX`；旧环境变量可能指向已清理的 E 盘，**以注册表/快捷方式实际路径为准** |
| 可执行 | `<NX>\NXBIN\ugraf.exe` | 图形界面；`run_journal.exe` 跑 NXOpen 日志 |
| 许可 | Windows 服务 `Siemens PLM License Server` 运行中 | 服务停止时 NX 会在启动画面卡住后退出，不报具体错误 |

> 启动失败先做这条判据：`Get-Service | ? Name -match 'Siemens|FLEX'`。许可服务不是 Running，任何“命令灰色/模块打不开”的排查都无意义。

### 1.2 主窗口六大区域

```
┌──────────────────────────────────────────────────────────────┐
│ 标题栏：部件名 [修改标记]                                      │
├──────────────────────────────────────────────────────────────┤
│ 菜单栏：文件(F) 编辑(E) 视图(V) 插入(S) 格式(R) 工具(T)        │
│         装配(A) PMI 信息(I) 分析(L) 首选项(P) 应用模块(N)      │
│         窗口(O) 帮助(H)                                       │
├──────────────────────────────────────────────────────────────┤
│ 功能区（Ribbon）：主页 / 装配 / 曲线 / 曲面 / 分析 / 视图 ...   │
│   每个选项卡下是“组”，组内是命令按钮                           │
├───────────────┬──────────────────────────────┬───────────────┤
│ 资源条（左）   │ 图形窗口                      │ 选择条/对话框  │
│ 部件导航器     │  （工作坐标系 WCS 显示）       │               │
│ 装配导航器     │                              │               │
│ 工序导航器     │                              │               │
├───────────────┴──────────────────────────────┴───────────────┤
│ 状态栏 / 提示行：当前命令提示、选择意图、坐标系读数            │
└──────────────────────────────────────────────────────────────┘
```

- **资源条**：鼠标悬停展开，单击图钉固定。`部件导航器`看特征树，`装配导航器`看组件与约束，`工序导航器`看 CAM 程序顺序/机床/加工方法视图。
- **选择条**：控制选择过滤（体/面/边/组件）。快捷键见 `03_快捷键速查.md`。
- **提示行**：NX 12 的报错往往只在提示行出现一次（如“无法创建圆角”），不要只看弹窗。

## 2. 层级菜单结构（原生 14 个顶层菜单）

以下为 `UGII/menus/ug_main.men` 实测顶层结构，中文名逐字对照：

| 顶层菜单 | 主要用途 | 典型二级 |
| :--- | :--- | :--- |
| `文件(F)` | 新建/打开/保存/导入/导出/绘图/实用工具 | `新建(N)...`、`打开(O)...`、`保存(S)`、`导出(E)`、`实用工具(U)` |
| `编辑(E)` | 撤销/对象编辑/特征编辑/曲线编辑/曲面编辑 | `特征(F)`、`曲线(V)`、`曲面(R)`、`对象显示(J)...` |
| `视图(V)` | 视图操作/布局/可视化/截面 | `操作(O)`、`布局(L)`、`截面(S)`、`可视化(V)` |
| `插入(S)` | 所有建模/草图/装配/工程图/加工对象的创建入口 | `草图(H)...`、`设计特征(E)`、`细节特征(L)`、`曲线(C)`、`同步建模(Y)`、`视图(W)`、`尺寸(M)`、`注释(A)` |
| `格式(R)` | 图层/组/引用集/图纸页 | `图层设置(S)...`、`组(G)`、`引用集(R)` |
| `工具(T)` | 表达式/测量/定制/操作记录/宏/更新/制图标准/特定于工艺 | `表达式(X)...`、`定制(Z)...`、`制图标准(D)...`、`特定于工艺(O)` |
| `装配(A)` | 组件/约束/爆炸/WAVE/克隆/高级 | `组件(C)`、`组件位置(P)`、`爆炸图(X)`、`WAVE` |
| `PMI` | 三维标注（产品制造信息） | `尺寸(D)`、`注释(A)`、`剖视图(C)...` |
| `信息(I)` | 对象/特征/表达式/装配报表 | `对象(O)...`、`表达式(X)`、`装配(A)` |
| `分析(L)` | 测量/几何/装配间隙/形状分析 | `测量(S)...`、`装配间隙(Y)`、`形状(H)` |
| `首选项(P)` | 会话级设置（对象/用户界面/可视化/制图/草图/加工） | `对象(O)...`、`用户界面(I)...`、`制图(D)...` |
| `应用模块(N)` | 切换模块：建模/装配/制图/加工/高级仿真等 | `建模(M)`、`制图(D)`、`加工(M)` |
| `窗口(O)` | 多窗口排列与切换 | `重置布局(R)` |
| `帮助(H)` | 命令查找器/上下文帮助/关于 | `命令查找器(F)...`、`上下文帮助(C)...` |

> **只认路径，不认图标位置**：NX 12 允许用户拖动/隐藏功能区组，但菜单路径由 `.men` 文件固定。
> 文档给路径；图标位置随角色变化，不作为判据。

## 3. 3 秒定位任意命令（标准操作路径）

### 3.1 首选：命令查找器

1. 按 `帮助(H)` → `命令查找器(F)...`（命令 ID `UG_HELP_COMMAND_FINDER`）。
2. 在输入框键入中文名（如 `倒斜角`）或功能词（如 `拔模`）；支持同义词。
3. 结果列表双击条目——NX 会**直接定位并高亮**该命令在功能区/菜单中的位置；右侧显示完整路径。

判据：3 秒内未找到，说明该命令在当前应用模块不可用，先 `应用模块(N)` 切换模块，而不是继续搜。

### 3.2 次选：菜单逐级

按 `插入(S)` 起手 90% 的建模命令都在此：设计特征 → 细节特征 → 同步建模 → 曲线 → 曲面 → 组合/修剪/偏置。

### 3.3 兜底：定制对话框反查

1. `工具(T)` → `定制(Z)...`（`Ctrl+1`）。
2. 切到 `命令` 页签，选择 `所有命令（按类别）`。
3. 在“显示命令”搜索框输入中文名，可看到命令所属类别与当前是否已放置到界面。

### 3.4 界面被改乱的复位

| 现象 | 复位动作 |
| :--- | :--- |
| 功能区少了整组按钮 | `工具(T)` → `定制(Z)...` → 功能区 → 勾选对应组 |
| 根菜单多了陌生条目 | 本机第三方插件注入；原生命令仍在 `文件/插入/工具` 原路径，不要点插件项 |
| 界面变成经典工具条 | `首选项(P)` → `用户界面(I)...` → 布局 → 选择 `功能区` |
| 找不到“高级”角色 | `首选项(P)` → `用户界面(I)...` → 角色 → 选 `高级` 或 `基本`，重启 NX |

## 4. 角色（Role）与界面复杂度

NX 12 启动时可选角色：`基本`（Essentials）与 `高级`（Advanced）。

| 角色 | 适用 | 差异 |
| :--- | :--- | :--- |
| 基本 | 只看图/简单改模 | 隐藏同步建模、曲面高阶命令、部分 CAM 工序 |
| 高级 | 产品设计/编程 | 暴露完整建模、曲面、装配、制图与加工命令 |
| CAM 专用角色 | 编程员 | 功能区以 `主页/加工` 为主，弱化建模 |

> 排查“命令在别的电脑有、我这没有”时，**先比对角色**，再比对版本。角色不同会造成 20%–40% 的命令可见性差异。

## 5. 文件生命周期与单位

| 动作 | 路径 | 快捷键 | 参数/判据 |
| :--- | :--- | :--- | :--- |
| 新建 | `文件(F)` → `新建(N)...` | `Ctrl+N` | 选 `模型`；单位选 **毫米**；模板 `model-plain-1-mm-template.prt` |
| 打开 | `文件(F)` → `打开(O)...` | `Ctrl+O` | 勾选“预览”可避免开错版本；NX 12 不能直接开 NX 2306 原生件 |
| 保存 | `文件(F)` → `保存(S)` | `Ctrl+S` | 只保存工作部件；装配下不会自动保存全部组件 |
| 全部保存 | `文件(F)` → `全部保存(V)` | — | 装配交付前必须执行，否则组件丢改动 |
| 另存为 | `文件(F)` → `另存为(A)...` | `Ctrl+Shift+A` | 装配另存需用 `文件(F)` → `另存为(A)...` 的“整个装配”选项 |
| 绘图/打印 | `文件(F)` → `绘图(L)...` | `Ctrl+P` | 图纸输出走 `NXPLOT`；PDF 也可用 `文件(F)` → `导出(E)` → `导出 PDF 文件` |

**新建对话框页签（实测）**：`模型`、`装配`、`GB标准制图`、`图纸`（不同安装可能略有差异）。
GB 页签内模板名：`GB_A4`、`GB_A3`、`GB_A2`、`GB_A1`、`GB_A0`，以及 `GB_A4 - 无视图` 等无视图变体。

## 6. 模块切换（应用模块）

`应用模块(N)` → 选择：

- `建模(M)`：零件建模；
- `装配(A)`：装配导航器与约束；
- `制图(D)`：工程图；
- `加工(M)`：CAM，进入后资源条出现 `工序导航器`；
- `高级仿真`/`前/后处理`：CAE。

> 切换模块不会改变几何，只改变可用命令集。**做完模型先按 `Ctrl+S` 再切制图**，可避免制图模块下的重建等待。

## 7. 本文件的证据与边界

- 顶层菜单结构：`UGII/menus/ug_main.men`（VERSION 121）。
- 中文名：`LOCALIZATION/translations/simpl_chinese/ug_main_men_simpl_chinese.txt` 等。
- 界面布局与角色：`UGII/menus/roles/*.mtx`（Advanced/Essentials 角色定义）。
- **未取证**：功能区每组的像素位置、图标外观。这些随窗口尺寸与角色变化，本库不写死。
