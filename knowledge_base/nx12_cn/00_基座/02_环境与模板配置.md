# 00-02 环境、模板与 GB 制图标准配置

> 目标：一次配置，后续所有零件/装配/工程图自动符合本单位规范，不再每次手改。
> 本文件区分三类值：**软件路径（实测）**、**GB 标准值（标准条文）**、**推荐值（工程经验）**。

## 1. 「用户默认设置」与「首选项」的区别（先搞清再改）

| 入口 | 作用域 | 保存 | 适用 |
| :--- | :--- | :--- | :--- |
| `文件(F)` → `实用工具(U)` → `用户默认设置(D)...`（`UG_FILE_UTILITIES_CUSTOMER_DEFAULTS`） | 新建会话的**默认值** | 写入 NX 用户默认文件，重启 NX 生效 | 单位、制图标准、图层、CAM 默认、模板 |
| `首选项(P)` → 各分项 | **当前会话** | 随部件或会话，关闭即失效（部分存部件） | 临时调整，如当前图纸的箭头大小 |

**顺序纪律**：先改“用户默认设置”→ 重启 NX → 再开新部件。反过来做，会出现“模板是新的、旧部件还是老样子”的假象。

## 2. 必改的 9 项默认设置（按模块）

| # | 路径（用户默认设置内） | 建议值 | 理由 |
| :--- | :--- | :--- | :--- |
| 1 | `基本环境` → `常规` → `部件` → 单位 | 毫米 | 避免英寸模板混入 |
| 2 | `基本环境` → `常规` → `杂项` → 目录/临时目录 | 非中文、无空格路径 | 中文路径会导致 CAM 后处理与 NXPLOT 偶发失败 |
| 3 | `基本环境` → `用户界面` → 角色 | `高级` | 暴露同步建模/曲面/完整 CAM |
| 4 | `建模` → `常规` → 体类型 | 实体优先 | 避免误建片体后无法布尔 |
| 5 | `制图` → `常规/标准` → 制图标准 | `GB`（若列表无 GB，选 `GB标准` 或按第 4 节导入） | GB/T 4458 系列 |
| 6 | `制图` → `注释` → 字体 | 汉字 `仿宋_GB2312`/`长仿宋`；字母数字 `GB` 斜体 | GB/T 14691 |
| 7 | `制图` → `尺寸` → 箭头/终端 | 实心闭合箭头；箭头长度 ≈ 3.5 mm | GB/T 4458.4 |
| 8 | `加工` → `常规` → 输出/后处理 | 本单位机床后处理名 | 避免每次手工选 |
| 9 | `基本环境` → `常规` → `部件` → 图层 | 1–10 建模；11–20 草图；21–40 曲线；41–60 曲面；61–80 片体；81–100 实体；101–120 工程图；121–140 CAM | 与第 5 节图层规范一致 |

> 上述“建议值”是工程约定，不是 NX 强制。软件合法范围以对话框为准；例如字高只允许标准序列，不允许 3.7 mm。

## 3. 新建模板体系

### 3.1 三套模板，三个用途

| 模板页签 | 模板文件（安装目录） | 用途 |
| :--- | :--- | :--- |
| `模型` | `UGII/templates/model-plain-1-mm-template.prt` | 单件建模，mm |
| `装配` | `UGII/templates/assembly-mm-template.prt` | 装配顶层，mm |
| `GB标准制图` | `LOCALIZATION/prc/simpl_chinese/startup/ugs_drawing_templates_GB.pax` 指向的 `GB_A*.prt` | 工程图，国标图框与标题栏 |

GB 模板实测清单（`ugs_drawing_templates_GB.pax`）：

```
GB_A4（A4-国标,Landscape）      GB_A4_P（A4-国标,Portrait）
GB_A3（A3-国标,Landscape）      GB_A2（A2-国标,Landscape）
GB_A1（A1-国标,Landscape）      GB_A0（A0-国标,Landscape）
GB_A4 - 无视图 … GB_A0 - 无视图（无视图变体，适合先建空图纸再布视图）
```

### 3.2 自定义模板的正确做法（不破坏原生模板）

1. 打开 `model-plain-1-mm-template.prt`（只读打开）。
2. 改：单位、图层类别、默认引用集、部件属性（图号/材料/设计者）、默认制图标准。
3. `文件(F)` → `另存为(A)...` 到**本单位模板目录**，命名如 `ABC_mm_template.prt`。
4. 把新模板登记到自定义 `.pax`（复制一份原生 `.pax` 改路径，不要改安装目录原文件）。
5. 用环境变量/用户默认设置指向自定义 `.pax` 目录。

> 禁止直接覆盖 `UGII/templates` 下的原生模板：升级/修复安装会还原，且多人共用同一安装时互相污染。

## 4. GB 制图标准落地（GB/T 4458 系列）

### 4.1 两条入口

| 目的 | 路径 | 说明 |
| :--- | :--- | :--- |
| 加载/切换制图标准 | `工具(T)` → `制图标准(D)...`（`UG_DRAFTING_STANDARD`） | 把选定标准载入当前会话 |
| 修改制图首选项 | `首选项(P)` → `制图(D)...`（`UG_DRAFT_PREFERENCES_DRAFTING`） | 字号、箭头、线型、公差显示等 |

### 4.2 GB 图纸幅面（GB/T 14689）

| 幅面 | 尺寸 mm（宽×高，横放） | NX 模板 |
| :--- | :--- | :--- |
| A0 | 1189 × 841 | `GB_A0` |
| A1 | 841 × 594 | `GB_A1` |
| A2 | 594 × 420 | `GB_A2` |
| A3 | 420 × 297 | `GB_A3` |
| A4 | 297 × 210 | `GB_A4`（竖放用 `GB_A4_P`） |

### 4.3 比例（GB/T 14690）

优先序列：`1:1`、`1:2`、`1:5`、`1:10`、`1:20`、`1:50`、`1:100`；放大：`2:1`、`5:1`、`10:1`。
**禁止**在标题栏写 `1:1.5` 这类非优先比例；需要时改视图比例并在标题栏注明。

### 4.4 字体与字高（GB/T 14691）

| 用途 | 字体 | 字高 mm |
| :--- | :--- | :--- |
| 汉字 | 长仿宋 / 仿宋_GB2312 | 3.5、5、7、10（不得小于 3.5） |
| 字母与数字 | GB 斜体（或 ISO 斜体） | 2.5、3.5、5、7 |
| 标题栏栏名 | 仿宋 | 5 或 7 |
| 尺寸数字 | 与字母数字同 | 3.5（A4/A3）、5（A0–A2 可放大） |

字高只允许标准序列：1.8、2.5、3.5、5、7、10、14、20 mm。

### 4.5 图线（GB/T 4457.4）

| 线型 | 线宽 | 用途 | NX 设置位置 |
| :--- | :--- | :--- | :--- |
| 粗实线 | 0.5 / 0.7 / 1.0 | 可见轮廓 | 制图首选项 → 线型 → 可见线 |
| 细实线 | 粗线的一半 | 尺寸线、剖面线、引出线 | 尺寸/注释首选项 |
| 虚线 | 细线 | 不可见轮廓 | 隐藏线 |
| 细点画线 | 细线 | 轴线、对称中心线 | 中心线 |
| 双点画线 | 细线 | 假想投影/极限位置 | 自定义线型 |

### 4.6 尺寸标注（GB/T 4458.4）

| 项 | GB 要求 | NX 对应 |
| :--- | :--- | :--- |
| 尺寸线终端 | 实心箭头，长度≈3.5 mm | `插入(S)` → `尺寸(M)` → `快速(P)...` 的“尺寸样式” |
| 尺寸数字 | 3.5 号字，写在尺寸线上方/左方 | 尺寸样式 → 文字 → 方向 |
| 尺寸线间距 | 小尺寸≥7 mm，大尺寸按图面 | 尺寸样式 → 尺寸线 → 基线间距 |
| 半径/直径 | 半径 `R`、直径 `Ø`（GB 用 `φ` 也可，但全图统一） | 径向尺寸自动带前缀，可在样式中改符号 |
| 倒角 | `C1`、`C2` 或 `1×45°` | 倒斜角尺寸 |
| 同一尺寸只标一次 | 不重复、不矛盾 | 标注前先做“尺寸链规划” |

### 4.7 表面粗糙度（GB/T 131）与公差

| 项 | 推荐值 | 说明 |
| :--- | :--- | :--- |
| Ra 优先序列 | 0.4、0.8、1.6、3.2、6.3、12.5、25 µm | 非配合面 6.3/12.5；配合面 1.6/3.2；精密 0.8 |
| 标注方式 | 去除材料符号 + Ra 值 + 加工方法（可选） | `插入(S)` → `注释(A)` → `表面粗糙度符号(S)...`（`UG_DRAFT_CRE_SURFACE_SYMBOL`） |
| 尺寸公差 | H7/g6/h6 等 ISO 286 配合 | 尺寸样式 → 公差 → 配合 |
| 几何公差 | 按 GB/T 1182 符号 | `插入(S)` → `注释(A)` → `特征控制框(E)...`（`UG_DRAFT_CRE_GDT_SYMBOLS`） |

### 4.8 标题栏与明细栏

- GB 模板自带标题栏；若需替换，编辑图纸模板（.prt）中的标题栏块，不要在每个部件里手画。
- 标题栏必填：图号、名称、材料、比例、重量、设计/审核/批准、日期、单位名称。
- 明细栏顺序：序号、代号、名称、数量、材料、单件重量、备注。

## 5. 图层规范（建议，和 GB 无关但影响交付）

| 图层段 | 内容 | 颜色建议 |
| :--- | :--- | :--- |
| 1–10 | 实体 | 绿色 |
| 11–20 | 草图 | 青色 |
| 21–40 | 曲线 | 黄色 |
| 41–60 | 曲面 | 蓝色 |
| 61–80 | 片体/辅助面 | 灰色 |
| 81–100 | 基准/坐标系 | 棕色 |
| 101–120 | 工程图 | 白色 |
| 121–140 | CAM 辅助 | 洋红 |

操作：`格式(R)` → `图层设置(S)...`（`Ctrl+L`，`UG_LAYER_SETTINGS`）；类别用 `格式(R)` → `图层类别(C)...`（`UG_LAYER_CATEGORY`）。

## 6. 表达式与参数化基线

- 入口：`工具(T)` → `表达式(X)...`（`Ctrl+E`，`UG_INSERT_DLEXPRESSION`）。
- 命名规范：`D_` 直径、`L_` 长度、`T_` 厚度、`R_` 半径、`ANG_` 角度；单位用 mm/deg。
- 关键尺寸必须由表达式驱动，禁止只改草图数值导致特征与图纸脱节。
- 修改后执行 `工具(T)` → `更新(U)` → `全部更新(U)`，确认无红色特征。

## 7. 证据与边界

- 模板文件名与 GB 页签：`LOCALIZATION/prc/simpl_chinese/startup/ugs_drawing_templates_GB.pax` 实测。
- 图幅/字高/线宽/粗糙度序列：GB/T 14689、GB/T 14691、GB/T 4457.4、GB/T 131、GB/T 4458.4 标准条文。
- 用户默认设置的页面结构随安装语言包略有差异；若你的对话框没有“GB”标准项，说明语言包未完整安装（`UGII_LANG`/`UGII_COUNTRY` 检查）。
