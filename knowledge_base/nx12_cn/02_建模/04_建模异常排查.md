# 02-04 建模异常排查手册

> 排查纪律：先看**部件导航器红叉**与**提示行原文**，再动手。不要连续点“确定”试错。
> 每条给 ≥3 步可执行动作，全部带 NX 12.0 中文路径。

## 1. 拉伸失败、截面无实体

**排查**：
1. 双击拉伸特征，看“截面”是否变空/变红——草图中的曲线被删除或转参考。
2. 进入草图，`工具(T)` → `更新(U)` → `评估草图(V)`，看开放端/自交。
3. 检查拉伸“体类型”：要实体必须是 `实体`，不是 `片体`；布尔选 `无` 时不会自动合并。

**修复**：闭合轮廓 → 重新选截面 → 方向箭头指向材料侧 → 结束距离 > 0。
**预防**：草图完成后先“评估草图”，再退出。

---

## 2. 布尔失败

**排查**：
1. `分析(L)` → `测量(S)...` 测两体是否有体积重叠；仅面接触必失败。
2. 看体类型：目标体/工具体必须同为实体；片体先 `缝合` + `加厚`。
3. 检查单位/比例：导入件可能是英寸，与 mm 体布尔会“看不见重叠”。

**修复**：
- 移动工具体使其真正相交；
- 片体先 `插入(S)` → `组合(B)` → `缝合(W)...`，再 `加厚(T)...`；
- 导入件用 `文件(F)` → `导出(E)` → `导出 Parasolid 文件` 转一遍再导入，消除精度差。

---

## 3. 边倒圆失败

**排查**：
1. 双击圆角特征，看 R 是否大于相邻边可用长度（提示“半径过大”）。
2. 检查是否有更小圆角与它相交：先做小 R 还是大 R 顺序反了。
3. 改“溢出选项”为 `允许`，看是否能自动修剪。

**修复**：减小 R → 调整顺序（大 R 先）→ 分段倒圆（先倒一部分，再倒另一部分）。
**预防**：圆角放在主体与布尔之后；同一交线先竖后横。

---

## 4. 抽壳失败

**排查**：
1. 测最小壁厚：`分析(L)` → `测量(S)...`，厚度必须小于最薄处的一半。
2. 看要移除的面是否连着圆角；圆角 R 小于壁厚会失败。
3. 试“备选厚度”：给局部面单独设更薄厚度。

**修复**：减小壁厚 → 加大圆角 → 分割面后分段抽壳 → 先抽壳后做小特征。
**预防**：抽壳放在大特征之后、孔/筋之前。

---

## 5. 拔模失败

**排查**：
1. 检查拔模方向：`分析(L)` → `形状(H)` → `拔模分析(T)...` 看面法向。
2. 固定面是否选错（应选分型面/底面）。
3. 角度是否过大导致自交；先试 1°。

**修复**：改固定面 → 减小角度 → 用“至分型边”替代“从平面”。
**预防**：拔模在抽壳之前、圆角之后；塑料件先定分型线。

---

## 6. 阵列失败

**排查**：
1. 看数量/节距：数量 ≥ 2、节距 > 0、圆形阵列总角度 ≤ 360°。
2. 阵列对象是否跨体：阵列特征只能在同一体内。
3. 特征是否依赖被阵列后不存在的面（如阵列到体外）。

**修复**：改参数 → 先合并成一体 → 用“阵列几何体”替代“阵列特征”（整体复制）。
**预防**：先做一个完整特征（孔+圆角），再阵列。

---

## 7. 特征更新红叉

**排查**：
1. 部件导航器右键红叉特征 → `信息`，读第一条错误。
2. 看父特征是否被删除/抑制：`编辑(E)` → `特征(F)` → `编辑参数(P)...` 检查引用。
3. `工具(T)` → `更新(U)` → `全部更新(U)`，确认是否只是未更新。

**修复**：恢复父特征 → 重新指定引用面/边 → 必要时“可回滚编辑”重做。
**预防**：改父特征前 `Ctrl+S`；大改前另存版本。

---

## 8. 片体不能加厚、缝合

**排查**：
1. `分析(L)` → `测量(S)...` 测片体面积/体积；体积=0 表示未闭合。
2. 缝合公差是否过小：改 0.001–0.01 mm。
3. 检查边界是否有缝隙/重叠；用 `分析(L)` → `形状(H)` → `曲面连续性(C)...`。

**修复**：补面 → 提高缝合公差 → 修剪重叠 → 加厚厚度 < 最小曲率半径。
**预防**：曲面构建时保证边界 G0 连续（点重合），再谈 G1/G2。

---

## 9. 导入件改不动

**排查**：
1. 看部件导航器：只有 `导入的` 体、没有特征 → 正常，需用同步建模。
2. 检查体类型：facet body（小平面体）不能直接布尔/加厚。
3. 检查单位：`文件(F)` → `属性(I)` → `单位`。

**修复**：
- 同步建模：`插入(S)` → `同步建模(Y)` → `移动面/删除面/调整面大小`；
- 小平面体先转实体（`插入(S)` → `小平面建模(C)` 相关转换）；
- 单位不对：导出 Parasolid 再用正确单位导入。

---

## 10. 显示破面、锯齿

**排查**：
1. `首选项(P)` → `可视化(V)...` → 精度/曲面显示，调高“曲面细分”。
2. 更新显卡驱动；关闭“抗锯齿”对比。
3. 用 `分析(L)` → `形状(H)` → `曲面连续性(C)...` 判断是显示问题还是模型问题。

**修复**：显示精度调高 → 更新驱动 → 模型问题则修面。
**判据**：旋转视图时破面位置变化 = 显示；固定位置 = 模型。

---

## 11. 尺寸差 25.4 倍

**排查**：
1. `文件(F)` → `属性(I)` → 看部件单位（英寸/毫米）。
2. 检查导入设置：STEP/IGES 导入时单位是否被强制。
3. 测一个已知尺寸（如 100 mm 基准块）。

**修复**：新建 mm 部件 → 导出/导入 Parasolid（选 mm）→ 或在导入对话框中改单位。
**预防**：模板统一 mm；导入前确认源文件单位。

---

## 12. 特征顺序错、改不动

**排查**：
1. 部件导航器按时间顺序看：圆角是否在抽壳/布尔之前。
2. 右键特征 → `重排序(R)...` 看能否后移。
3. 若不可重排，说明有父子依赖（圆角引用了后续面）。

**修复**：抑制后续特征 → 删除圆角 → 重做 → 取消抑制。
**预防**：按“主体 → 布尔 → 大圆角 → 小圆角 → 拔模/抽壳 → 孔/阵列”的顺序建模。
