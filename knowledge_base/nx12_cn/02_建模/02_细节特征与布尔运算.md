# 02-02 细节特征、布尔与组合

> 本文件覆盖：边倒圆、倒斜角、拔模、抽壳、布尔（合并/减去/相交）、缝合、修剪、加厚、抽取、阵列/镜像。
> 这些是“主体做完后的收口工序”，顺序错会导致大量失败。

## 1. 边倒圆（圆角）

[CMD:UG_MODELING_BLEND_FEATURE] 边倒圆：`插入(S)` → `细节特征(L)` → `边倒圆(E)...`

| 参数 | 选项 | 说明 | 推荐 |
| :--- | :--- | :--- | :--- |
| 类型 | 恒定/可变/面倒圆/软倒圆 | 恒定最稳 | 先用恒定 |
| 半径 R | 任意正数 | 必须 ≤ 相邻边可用长度 | R ≥ 0.5×壁厚；外观件 R2–R5 |
| 溢出选项 | 允许/不允许 | 圆角超出边时是否自动修剪 | 先“不允许”，失败再改“允许” |
| 拐角 | 延伸/修剪 | 三边交汇处 | 默认；失败时改“修剪” |
| 限制面 | 可选 | 用面截断圆角 | 复杂交线时用 |

**SOP**：选边（可框选）→ 输入 R → 预览 → 检查是否有红边/断口 → 确定。
**顺序纪律**：大 R 先、小 R 后；先竖边后横边；相交圆角最后做。

## 2. 倒斜角

[CMD:UG_MODELING_CHAMFER_FEATURE] 倒斜角：`插入(S)` → `细节特征(L)` → `倒斜角(M)...`

| 类型 | 参数 | 用途 |
| :--- | :--- | :--- |
| 对称 | 距离 D | C1、C2 常规倒角 |
| 非对称 | 距离1、距离2 | 特殊导向 |
| 偏置和角度 | 偏置、角度 | 45° 以外角度 |

范围：距离 > 0；角度 0°～90°。距离大于相邻边长度会失败。

## 3. 拔模

[CMD:UG_MODELING_TAPER_FEATURE] 拔模：`插入(S)` → `细节特征(L)` → `拔模(T)...`

| 类型 | 适用 | 关键参数 |
| :--- | :--- | :--- |
| 从平面 | 平面分型 | 拔模方向、固定面、角度 |
| 从边 | 以边为分型 | 固定边、角度 |
| 与多个面相切 | 曲面 | 相切面、角度 |
| 至分型边 | 分型线 | 分型边、角度 |

角度：−90°～90°；塑料件常用 1°～3°，压铸 2°～5°。负角=倒扣，需滑块/斜顶。

[CMD:UG_MODELING_BODY_TAPER_FEATURE] 拔模体：`插入(S)` → `细节特征(L)` → `拔模体(O)...`，用于分型面两侧匹配拔模。

## 4. 抽壳

[CMD:UG_MODELING_HOLLOW_FEATURE] 抽壳：`插入(S)` → `偏置/缩放(O)` → `抽壳(H)...`

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 类型 | 移除面/全部面 | 壳体通常移除开口面 |
| 厚度 | 单值或备选厚度 | 1–4 mm；必须小于最小外形尺寸的一半 |
| 备选厚度 | 按面指定不同壁厚 | 局部加强 |

**常见失败**：厚度大于局部最小壁厚、圆角半径小于壁厚、面相交处无法偏置。先加大 R 或改“备选厚度”。

## 5. 布尔运算（NX 12 中文名：合并 / 减去 / 相交）

| 命令 | 路径 | 参数 | 说明 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_UNITE_FEATURE] 合并 | `插入(S)` → `组合(B)` → `合并(U)...` | 目标体、工具体、保留工具体 | 求和；装配体不可直接布尔 |
| [CMD:UG_MODELING_SUBTRACT_FEATURE] 减去 | `插入(S)` → `组合(B)` → `减去(S)...` | 目标体、工具体、保留工具体 | 求差；工具体必须与目标体相交 |
| [CMD:UG_MODELING_INTERSECT_FEATURE] 相交 | `插入(S)` → `组合(B)` → `相交(I)...` | 目标体、工具体 | 求交；常用于取公共区域 |

**判据**：
- 目标体与工具体必须有**体积重叠**；仅面接触会失败；
- 片体不能与实体直接布尔；先缝合/加厚；
- 布尔后体数应为 1（除非勾选“保留工具体”）。

## 6. 缝合与取消缝合

[CMD:UG_MODELING_SEW_FEATURE] 缝合：`插入(S)` → `组合(B)` → `缝合(W)...`

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 类型 | 片体/实体 | 片体缝合成壳体；实体缝合用于修复小平面/多体 |
| 目标 | 目标片体 | 选最大的片体 |
| 工具 | 其余片体 | 框选 |
| 公差 | 0.0001～1 mm | 0.001–0.01 mm；精度件取 0.001 |

[CMD:UG_MODELING_UNSEW_FEATURE] 取消缝合：`插入(S)` → `组合(B)` → `取消缝合(N)...`，把缝合体拆回片体。

**判据**：缝合后执行 `分析(L)` → `测量(S)...` 检查面积/体积；若体积为 0 说明仍是片体（未闭合）。

## 7. 修剪、分割、加厚

| 命令 | 路径 | 参数 | 用途 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_TRIM_FEATURE] 修剪体 | `插入(S)` → `修剪(T)` → `修剪体(T)...` | 目标体、刀具（面/基准面）、反向 | 用面切实体 |
| [CMD:UG_MODELING_FF_TRIMMED] 修剪片体 | `插入(S)` → `修剪(T)` → `修剪片体(R)...` | 目标片体、边界、投影方向 | 剪掉片体多余部分 |
| [CMD:UG_MODELING_DIVIDEFACE_FEATURE] 分割面 | `插入(S)` → `修剪(T)` → `分割面(D)...` | 面、分割对象 | 把一张面切成两张，便于局部偏置 |
| [CMD:UG_MODELING_FF_THICKEN] 加厚 | `插入(S)` → `偏置/缩放(O)` → `加厚(T)...` | 片体、厚度、两侧/单侧 | 片体转实体；厚度 < 最小曲率半径 |
| [CMD:UG_MODELING_FF_EXTEND_SHEET] 延伸片体 | `插入(S)` → `修剪(T)` → `延伸片体(X)...` | 边、距离/直至面 | 补面后延伸再缝合 |

## 8. 抽取、阵列、镜像

| 命令 | 路径 | 关键参数 | 用途 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_EXTRACT_GEOMETRY_FEATURE] 抽取几何特征 | `插入(S)` → `关联复制(A)` → `抽取几何特征(E)...` | 面/体/曲线；关联/取消关联 | 复制面做分型/偏置 |
| [CMD:UG_MODELING_PATTERNFEATURE_FEATURE] 阵列特征 | `插入(S)` → `关联复制(A)` → `阵列特征(A)...` | 线性/圆形/多边形；数量、节距、角度 | 孔/筋/凸台阵列 |
| [CMD:UG_MODELING_MIRRORFEATURE_FEATURE] 镜像特征 | `插入(S)` → `关联复制(A)` → `镜像特征(R)...` | 特征、镜像平面 | 对称件 |
| [CMD:UG_MODELING_TRANSCOPY_FEATURE] 镜像几何体 | `插入(S)` → `关联复制(A)` → `镜像几何体(G)...` | 体、平面 | 整体镜像（含全部特征） |

**阵列要点**：数量 ≥ 2；线性节距 > 0；圆形阵列“角度总跨度”≤ 360°；阵列特征比阵列面稳定。

## 9. 曲面转实体（组合/构造实体）

| 命令 | 路径 | 说明 |
| :--- | :--- | :--- |
| [CMD:UG_MODELING_FF_COMBINE_FEATURE] 组合 | `插入(S)` → `组合(B)` → `组合(B)...` | 片体组合（不缝合） |
| [CMD:UG_MODELING_MAKE_SOLID_FEATURE] 构造实体 | `插入(S)` → `组合(B)` → `构造实体(K)...` | 由封闭片体构造实体 |
| [CMD:UG_MODELING_FF_SSW] 片体到实体助理（原有） | `插入(S)` → `偏置/缩放(O)` → `片体到实体助理（原有）(A)...` | 自动缝合+加厚 |

## 10. 参数合法范围与失败边界

| 参数 | 合法范围 | 越界/失败表现 | 处理 |
| :--- | :--- | :--- | :--- |
| 圆角 R | > 0 | “无法创建圆角/半径过大” | 减小 R、改溢出选项、先倒大角 |
| 倒角距离 | > 0 且 < 边长 | 失败/只倒一部分 | 减小距离或分段倒 |
| 拔模角 | −90°～90° | 自交/无法拔模 | 改固定面/分型边 |
| 抽壳厚度 | > 0 且 < 最小壁厚 | “无法抽壳” | 减小厚度、加大圆角、备选厚度 |
| 缝合公差 | 0.0001～1 mm | 缝不上/缝隙大 | 0.001–0.01；先修面 |
| 加厚厚度 | > 0 且 < 曲率半径 | 自交/失败 | 减小厚度、分割面后分段加厚 |
| 布尔 | 必须有体积重叠 | “工具体完全在目标体外” | 移动/加大工具体；检查单位 |

## 11. 顺序最佳实践（收口清单）

1. 主体特征全部完成 → `Ctrl+S`；
2. 布尔合并（把分散体并成 1 个）；
3. 大圆角 → 小圆角 → 倒斜角；
4. 拔模（如注塑件）→ 抽壳 → 局部加强筋；
5. 孔/螺纹 → 阵列/镜像；
6. 最后做装饰性小特征；
7. `分析(L)` → `测量(S)...` 复核体积/壁厚；
8. `工具(T)` → `更新(U)` → `全部更新(U)`，确认无红叉。

## 12. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`。
- 布尔中文名“合并/减去/相交”为 NX 12 中文原文（不是“求和/求差/求交”）。
- 参数范围以 NX 对话框限制为准；推荐值为工程经验。
