# 02-03 同步建模（无历史 / 直接编辑）

> 适用：NX 12.0 中文版。同步建模的直接入口是 `插入(S)` → `同步建模(Y)`，不是独立应用模块。
> 它改的是“面/边”的几何关系，不依赖特征历史；对导入件（STEP/IGES/STL 转实体）尤其有用。

## 1. 什么时候用同步建模

| 场景 | 用同步建模 | 用历史建模 |
| :--- | :--- | :--- |
| 导入的中性格式实体（无参数） | ✔ 直接改面 | ✘ 无特征可改 |
| 客户改一处圆角/孔位 | ✔ 移动面/调整面大小 | 也可，但要回草图 |
| 需要保留完整设计意图 | 慎用 | ✔ 特征+表达式 |
| 模具分型面小修改 | ✔ 偏置区域/替换面 | 慢 |
| 结构大改（壁厚/拓扑） | ✘ | ✔ 重建特征 |

**原则**：同步建模是“外科手术”，不是“重建”。能用历史特征改的，优先改特征。

## 3. 三个高频标准流程

### 3.1 改孔径（导入件）

1. `插入(S)` → `同步建模(Y)` → `调整面大小(Z)...`；
2. 选圆柱面（一次选中整个孔壁）；
3. 输入新直径（表达式或数值）；
4. 预览：孔壁与相邻面会自动延伸/修剪；
5. 确定后 `分析(L)` → `测量(S)...` 复核直径。

### 3.2 删除导入件的圆角

1. `插入(S)` → `同步建模(Y)` → `删除面(A)...`；
2. 选圆角面（可多选）；
3. 修复选项：`自动`/`延伸面`/`修剪`；
4. 若失败，改“延伸面”并检查相邻面是否可延伸；
5. 确定后用 `分析(L)` → `形状(H)` → `曲面连续性(C)...` 检查面质量。

### 3.3 移动面改壁厚

1. `插入(S)` → `同步建模(Y)` → `移动面(M)...`；
2. 选择要移动的面；方向选面法向；
3. 输入距离（正=外移，负=内移）；
4. 勾选“关联面自动延伸/修剪”；
5. 确定后测量壁厚（`分析(L)` → `测量(S)...`）。

## 4. 参数范围与失败边界

| 参数 | 合法范围 | 失败表现 | 处理 |
| :--- | :--- | :--- | :--- |
| 移动距离 | 任意实数 | 移动后自交/面撕裂 | 减小距离；分步移动 |
| 偏置距离 | 正/负实数 | 曲面自交 | 距离 < 曲率半径；分段偏置 |
| 调整面大小 | 新直径 > 0 | 孔壁无法延伸 | 先删相邻圆角 |
| 替换面 | 两面必须有交线/可延伸 | “无法替换” | 改“偏置”或先组合面 |
| 删除面 | 面必须可被相邻面修复 | 留下破洞 | 改修复选项；手动补面 |
| 壳厚 | > 0 且小于最小壁厚 | 失败 | 减小厚度 |

## 5. 同步建模的边界（必须知道）

1. **不产生参数历史**：改完就是“一个体”，后续无法用表达式回滚；
2. **不保证设计意图**：移动面可能破坏圆角/拔模关系；
3. **对多体/装配慎用**：一次只改一个体，跨组件要先设工作部件；
4. **STL/小平面体不是实体**：同步建模命令对 facet body 多数不可用，先“小平面体 → 实体”转换；
5. **改完必须复核**：`分析(L)` → `测量(S)...` + 曲面连续性/半径分析。
