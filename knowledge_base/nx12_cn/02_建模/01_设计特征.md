# 02-01 设计特征（实体构建）

> 适用：NX 12.0 中文版。所有命令路径取自 `插入(S)` 原生菜单；命令名与屏幕逐字一致。
> 核心纪律：**每个特征只做一件事**；布尔尽量在特征内部完成；参数尽量用表达式驱动。

## 1. 基准特征（先有基准，再有实体）

| 命令 | 路径 | 关键参数 | 建议 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_DATUM_PLANE_FEATURE] 基准平面 | `插入(S)` → `基准/点(D)` → `基准平面(D)...` | 类型（自动判断/距离/角度/偏置/曲线）、偏置距离 | 偏置 0 的基准面用于草图；命名 DP_主分型 |
| [CMD:UG_MODELING_DATUM_AXIS_FEATURE] 基准轴 | `插入(S)` → `基准/点(D)` → `基准轴(A)...` | 两点/交点/面法向/曲线 | 旋转特征必须显式基准轴 |
| [CMD:UG_MODELING_DATUM_CSYS_FEATURE] 基准坐标系 | `插入(S)` → `基准/点(D)` → `基准坐标系(C)...` | 原点、轴向、参考 CSYS | 装配定位、CAM 坐标系复用 |
| [CMD:UG_MODELING_DATUM_PLANE_GRID] 基准平面栅格 | `插入(S)` → `基准/点(D)` → `基准平面栅格(G)...` | 栅格间距 | 大装配中快速定位，不参与建模 |

**顺序**：基准坐标系 → 基准面/轴 → 草图 → 实体。不要用“绝对坐标系默认面”硬画，后期改图无法整体平移。

## 2. 拉伸（最常用）

[CMD:UG_MODELING_EXTRUDED_FEATURE] 拉伸：`插入(S)` → `设计特征(E)` → `拉伸(X)...`

| 参数 | 说明 | 合法/推荐 |
| :--- | :--- | :--- |
| 截面 | 草图/曲线/面边 | 必须连续；实体要求闭合 |
| 方向 | 沿矢量/面法向/指定矢量 | 默认草图画法向；反向用对话框箭头 |
| 限制：开始/结束 | 距离/对称值/直至选定/直至延伸部分 | 实体推荐 `0 → T`（T 为板厚表达式） |
| 布尔 | 无/合并/减去/相交 | 新零件第一次选 `无`；后续在同体内选 `合并`/`减去` |
| 拔模 | 无/从起始/从结束/对称 | 角度 −90°～90°；工程常用 1°～5° |
| 偏置 | 单侧/两侧/对称 | 薄壁件可直接用偏置代替抽壳；单侧偏置值 < 截面最小曲率半径 |

**标准 SOP**：
1. 选草图 → 确认方向箭头指向材料侧；
2. 开始 `0`，结束输入 `T`（表达式）；
3. 布尔按“是否同体”选择；
4. 预览确认体积变化方向（增料/减料）；
5. `确定` 后看部件导航器特征是否带红叉。

> 拉伸切除：布尔选 `减去`，目标体自动为当前体；不要先建实体再单独“减去”，多一步且易选错。

## 3. 旋转

[CMD:UG_MODELING_REVOLVED_FEATURE] 旋转：`插入(S)` → `设计特征(E)` → `旋转(R)...`

| 参数 | 说明 | 合法/推荐 |
| :--- | :--- | :--- |
| 截面 | 草图/曲线 | 不能跨旋转轴；轴两侧都有材料时用“相交”或分两次 |
| 轴 | 基准轴/直线/边 | 必须与截面共面 |
| 角度 | 起始角、终止角 | 0°～360°；整周用 0→360 |
| 偏置 | 单侧/两侧/对称 | 同拉伸 |
| 布尔 | 无/合并/减去/相交 | 同拉伸 |

**注意**：NX 12 中文叫“旋转”，不是“回转”。搜索命令时输入“旋转”。

## 4. 基本体（长方体/圆柱/圆锥/球）

| 命令 | 路径 | 关键参数 | 推荐 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_BLOCK_FEATURE] 长方体 | `插入(S)` → `设计特征(E)` → `长方体(K)...` | 原点、长宽高；或两对角点 | 长宽高用表达式；原点对齐设计基准 |
| [CMD:UG_MODELING_CYLINDER_FEATURE] 圆柱 | `插入(S)` → `设计特征(E)` → `圆柱(C)...` | 轴、直径、高度 | 直径 > 0；高度 > 0；布尔按需 |
| [CMD:UG_MODELING_CONE_FEATURE] 圆锥 | `插入(S)` → `设计特征(E)` → `圆锥(O)...` | 底部/顶部直径、高度、半角 | 顶底直径不能同时为 0 |
| [CMD:UG_MODELING_SPHERE_FEATURE] 球 | `插入(S)` → `设计特征(E)` → `球(S)...` | 中心、直径 | 直径 > 0 |

> 基本体只用于毛坯/简化件；正式零件用草图+拉伸/旋转，便于参数化。

## 5. 孔与螺纹

### 5.1 孔

[CMD:UG_MODELING_HOLE_FEATURE] 孔：`插入(S)` → `设计特征(E)` → `孔(H)...`

| 类型 | 参数 | 工程取值 |
| :--- | :--- | :--- |
| 常规孔（简单） | 直径、深度、顶锥角 | 直径按螺纹底孔/配合；顶锥角 118°/120°/140° |
| 沉头孔 | 沉头直径、沉头深度 | 按 GB/T 152.2 内六角/沉头螺钉 |
| 埋头孔 | 埋头直径、埋头角度 | 90° 或 120° |
| 螺纹孔 | 螺纹规格、螺纹深度、攻丝深度 | M3–M20；攻丝深度 ≥ 螺纹深度 |

**SOP**：选孔类型 → 指定点（草图点/面上的点）→ 输入直径/深度 → 布尔 `减去` → 确认。
**判据**：孔必须完全穿透或按图纸深度；透孔用“直至选定”避免留薄层。

### 5.2 螺纹

[CMD:UG_MODELING_THREAD_FEATURE] 螺纹：`插入(S)` → `设计特征(E)` → `螺纹(T)...`

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 螺纹类型 | 符号/详细/燕尾 | 工程图用“符号”；渲染用“详细” |
| 规格 | M/UN/管螺纹 | 按 GB/T 196 |
| 螺距 | 粗牙/细牙 | 粗牙默认；细牙按设计 |
| 长度 | 螺纹长度 | ≤ 圆柱长度 |

> 螺纹特征只做“装饰/符号”，不影响强度计算；需要真实螺纹用于 3D 打印时选“详细”。

## 6. 筋板、凸台、腔、垫块、键槽（原有特征）

| 命令 | 路径 | 用途 | 注意 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_MODELING_RIB_FEATURE] 筋板 | `插入(S)` → `设计特征(E)` → `筋板(I)...` | 薄壁加强筋 | 筋厚 ≤ 壁厚；拔模 1°～3° |
| [CMD:UG_MODELING_BOSS_FEATURE] 凸台（原有） | `插入(S)` → `设计特征(E)` → `凸台（原有）(B)...` | 圆柱凸台 | 直径/高度/锥角；老特征，新设计可用拉伸+合并替代 |
| [CMD:UG_MODELING_POCKET_FEATURE] 腔（原有） | `插入(S)` → `设计特征(E)` → `腔（原有）(P)...` | 矩形/圆柱形腔 | 圆角半径不能大于腔深/2 |
| [CMD:UG_MODELING_PAD_FEATURE] 垫块（原有） | `插入(S)` → `设计特征(E)` → `垫块（原有）(A)...` | 矩形凸台 | 同腔 |
| [CMD:UG_MODELING_SLOT_FEATURE] 键槽（原有） | `插入(S)` → `设计特征(E)` → `键槽（原有）(L)...` | 轴键槽 | 宽度/深度按 GB/T 1095 |

> “（原有）”是 NX 12 中文原文，表示 legacy 特征；新设计优先用草图+拉伸+布尔，参数链更清晰。

## 7. 特征参数与合法范围总表

| 参数 | 合法范围（软件） | 工程推荐 | 越界后果 |
| :--- | :--- | :--- | :--- |
| 拉伸距离 | 任意实数 | 0～板厚/长度表达式 | 负值会反向，易与布尔方向冲突 |
| 拉伸拔模角 | −90°～90° | 1°～5°（塑料件 1°～3°） | 过大导致顶部自交 |
| 旋转角度 | 0°～360° | 整周 0→360 | 跨 0° 起始角易出现接缝 |
| 圆角半径 R | > 0 | R ≥ 0.5×壁厚 | 大于相邻边可用长度 → 失败 |
| 倒斜角距离 | > 0 | C0.5～C2 | 大于边长度 → 失败 |
| 抽壳厚度 | > 0 | 1～4 mm（按材料） | 大于最小壁厚 → 失败 |
| 拔模角（拔模特征） | −90°～90° | 1°～7° | 负角形成倒扣 |
| 孔直径 | > 0 | 按螺纹底孔/配合 | 小于 0 直接拒绝 |
| 螺纹长度 | ≤ 圆柱长度 | 按图纸 | 超出会提示失败 |
| 阵列数量 | 整数 ≥ 2 | 按孔数 | 过大拖慢重建 |

## 8. 建模顺序最佳实践

1. **基准 → 主体 → 次要特征 → 细节 → 阵列/镜像**；
2. 先大后小：大轮廓、大切除先做；圆角/倒角最后做；
3. 圆角顺序：大 R 先、小 R 后；同一交线先竖后横；
4. 对称件：做一半 → `插入(S)` → `关联复制(A)` → `镜像特征(R)...`；
5. 阵列件：先做一个完整特征（含孔/圆角），再阵列特征，不要阵列面；
6. 每个特征命名：`EX_主体`、`HOLE_M8x4`、`BLEND_R3`；
7. 关键尺寸表达式化，避免“只改草图不改图纸”。

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_MODELING_*_FEATURE`）。
- 实测：拉伸 100×60×10，体积 60 000 mm³（`runs/nx12_cn_verify/verify_result.json`）。
- 参数范围中的“软件范围”以对话框输入限制为准；工程推荐值为行业经验，非 NX 强制。
