# 04-03 尺寸、公差、GD&T 与技术要求

> 目标：图纸上的每个数字都能被加工者直接使用。尺寸不是“标上去”，而是“设计基准 + 公差 + 工艺”的统一表达。

## 1. 尺寸命令表

| 命令 | 路径 | 适用 | 关键参数 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_DRAFT_DIMENSION_RAPID] 快速尺寸 | `插入(S)` → `尺寸(M)` → `快速(P)...` | 自动判断长度/半径/角度 | 选对象→放位置 |
| [CMD:UG_DRAFT_DIMENSION_LINEAR] 线性尺寸 | `插入(S)` → `尺寸(M)` → `线性(L)...` | 两点/两线距离 | 水平/竖直/点到线 |
| [CMD:UG_DRAFT_DIMENSION_RADIAL] 径向尺寸 | `插入(S)` → `尺寸(M)` → `径向(R)...` | 半径/直径 | R/Ø 前缀 |
| [CMD:UG_DRAFT_DIMENSION_ANGULAR] 角度尺寸 | `插入(S)` → `尺寸(M)` → `角度(A)...` | 两线夹角 | 0°～180° |
| [CMD:UG_DRAFT_DIMENSION_CHAMFER] 倒斜角尺寸 | `插入(S)` → `尺寸(M)` → `倒斜角(C)...` | C1/C2 | 距离/角度 |
| [CMD:UG_DRAFT_DIMENSION_THICKNESS] 厚度尺寸 | `插入(S)` → `尺寸(M)` → `厚度(T)...` | 板厚/壁厚 | 两平行面 |
| [CMD:UG_DRAFT_DIMENSION_CURVE_LENGTH] 弧长尺寸 | `插入(S)` → `尺寸(M)` → `弧长(G)...` | 圆弧长度 | 弧长 |
| [CMD:UG_DRAFT_DIMENSION_ORDINATE] 坐标尺寸 | `插入(S)` → `尺寸(M)` → `坐标(O)...` | 孔位坐标 | 基准原点 |

**标注顺序**：定基准 → 标定位尺寸（孔位/中心距）→ 标形状尺寸（长宽/半径）→ 标公差 → 标表面质量。

## 2. 尺寸样式与 GB 设置

双击尺寸 → `设置`（或 `编辑(E)` → `样式(S)...`）：

| 项 | GB 要求 | NX 设置 |
| :--- | :--- | :--- |
| 箭头 | 实心闭合，长度≈3.5 mm | 尺寸样式 → 箭头 → 类型/大小 |
| 文字高度 | 3.5（A4/A3）、5（A0–A2） | 文字 → 高度 |
| 文字位置 | 尺寸线上方/左方 | 文字 → 方向/位置 |
| 小数位数 | 线性 0 或 0.0；角度 0° | 文字 → 格式 |
| 尺寸线间距 | ≥7 mm | 尺寸线 → 基线间距 |
| 零公差显示 | 按企业规范 | 公差 → 显示 |

## 3. 尺寸公差（GB/T 1800.1）

### 3.1 四种标注方式

| 方式 | 显示 | 用途 |
| :--- | :--- | :--- |
| 无公差 | `Ø20` | 未注公差（由技术要求统一） |
| 双向 | `Ø20 ±0.1` | 对称公差 |
| 单向 | `Ø20 +0.2/0` | 孔/轴配合 |
| 极限 | `Ø20.2 / 20.0` | 极限尺寸 |
| 配合 | `Ø20 H7/g6` | 孔轴配合 |

### 3.2 常用配合（工程推荐）

| 配合 | 用途 | 示例 |
| :--- | :--- | :--- |
| H7/g6 | 间隙配合（滑动） | 轴 Ø20 g6，孔 Ø20 H7 |
| H7/h6 | 过渡/定位 | 定位销 |
| H7/k6 | 过渡（轻压） | 齿轮/带轮 |
| H7/p6 | 过盈（轻） | 轴承内圈 |
| H7/r6 | 过盈（重） | 联轴器 |

> 具体数值查 GB/T 1801；NX 尺寸样式 → 公差 → 配合可直接显示 H7/g6 的上下偏差。

## 4. GD&T（几何公差）

[CMD:UG_DRAFT_CRE_GDT_SYMBOLS] 特征控制框：`插入(S)` → `注释(A)` → `特征控制框(E)...`

> **命名注意**：NX 12 中文叫“特征控制框”，不叫“形位公差”。命令查找器搜“形位公差”可能无结果，搜“特征控制框”即可。

| 公差类型 | 符号 | 用途 | 典型值 |
| :--- | :--- | :--- | :--- |
| 直线度 | — | 轴线/素线 | 0.02 |
| 平面度 | ▱ | 平面 | 0.05 |
| 圆度 | ○ | 圆柱/孔 | 0.01 |
| 圆柱度 | ⌭ | 圆柱面 | 0.02 |
| 线轮廓度 | ⌒ | 曲线轮廓 | 0.05 |
| 面轮廓度 | ⌓ | 曲面轮廓 | 0.1 |
| 平行度 | ∥ | 面/线相对基准 | 0.02 |
| 垂直度 | ⊥ | 面/线相对基准 | 0.02 |
| 倾斜度 | ∠ | 角度面 | 0.05 |
| 位置度 | ⌖ | 孔位（带 Ø） | Ø0.1 |
| 同轴度 | ◎ | 回转体 | Ø0.02 |
| 对称度 | ⌯ | 键槽/对称面 | 0.05 |
| 圆跳动 | ↗ | 回转面 | 0.03 |
| 全跳动 | ⌰ | 整个表面 | 0.05 |

**基准**：
- [CMD:UG_DRAFT_DATUM_SYMBOL] 基准特征符号：`插入(S)` → `注释(A)` → `基准特征符号(R)...`
- [CMD:UG_DRAFT_DATUM_TARGET_SYMBOL] 基准目标：`插入(S)` → `注释(A)` → `基准目标(D)...`

**SOP**：先定基准（A/B/C）→ 标位置度/轮廓度 → 标方向公差 → 标形状公差。基准顺序按装配/加工定位顺序，不要随意。

## 5. 表面粗糙度（GB/T 131）

[CMD:UG_DRAFT_CRE_SURFACE_SYMBOL] 表面粗糙度符号：`插入(S)` → `注释(A)` → `表面粗糙度符号(S)...`

| 项 | 取值 |
| :--- | :--- |
| 符号 | 去除材料（基本符号+横线）/ 不去除材料 / 任意方法 |
| Ra 值 | 0.4、0.8、1.6、3.2、6.3、12.5、25 µm |
| 加工方法 | 车/铣/磨/钻（可省略） |
| 附加 | 纹理方向、加工余量 |

**默认值**：未注表面粗糙度写在技术要求里（如“未注表面 Ra6.3”），不要每个面都标。

## 7. 技术要求模板（可直接抄改）

```
技术要求
1. 未注尺寸公差按 GB/T 1804-m 执行。
2. 未注几何公差按 GB/T 1184-K 执行。
3. 未注表面粗糙度 Ra6.3。
4. 去除毛刺、飞边，锐边倒钝 C0.5。
5. 材料：45 钢，调质处理 HB220–250。
6. 表面处理：发黑（或按图样注明）。
7. 未注圆角 R2。
8. 未注倒角 C1。
9. 铸件不得有砂眼、气孔、裂纹等缺陷。
10. 未注公差尺寸按 IT14 级。
```

> 以上条目按企业标准替换；关键是“未注公差/未注粗糙度/材料热处理/表面处理”四项必须写。

## 8. 标注校核清单（GB/T 4458.4）

| # | 检查项 | 合格判据 |
| :--- | :--- | :--- |
| 1 | 每个尺寸只标一次 | 无重复、无矛盾 |
| 2 | 尺寸链闭合 | 总长 = 分段之和（或留一个自由尺寸） |
| 3 | 尺寸线不交叉 | 交叉处断开或错层 |
| 4 | 尺寸不标在虚线上 | 必要时用剖视/局部放大 |
| 5 | 直径用 Ø、半径用 R | 全图统一 |
| 6 | 螺纹标注 | M20-6g、M20×1.5-6H |
| 7 | 公差与配合 | H7/g6 与尺寸线对齐 |
| 8 | 基准符号 | A/B/C 与公差框对应 |
| 9 | 粗糙度 | 每个加工面有要求；未注写在技术要求 |
| 10 | 件号/明细栏 | 与装配图一致 |

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_DRAFT_DIMENSION_*`、`UG_DRAFT_CRE_*`）。
- 公差/配合/粗糙度数值：GB/T 1800.1、GB/T 1801、GB/T 131、GB/T 1182。
- “特征控制框”为 NX 12 中文原文；不要写成“形位公差”去搜。
