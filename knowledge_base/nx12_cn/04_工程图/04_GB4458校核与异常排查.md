## 2. 异常排查（每条 ≥3 步）

### 2.1 图纸比例与标题栏不一致

1. `编辑(E)` → `图纸页(H)...` 看“比例”字段；
2. 双击标题栏，看“比例”文字是手填还是关联字段；
3. 若标题栏是手填：改为关联图纸比例（编辑标题栏 → 属性 → 链接），或按图纸页比例重填。

**修复**：统一以图纸页比例为准；不要用“视图缩放”改比例。

### 2.2 投影方向反（第一角/第三角）

1. `编辑(E)` → `图纸页(H)...` 看“投影”选项；
2. 若为“第三角”，改为“第一角”；
3. 重新放置投影视图（已有视图可能需删除重建）。

**判据**：GB 第一角——俯视图在主视图下方，左视图在主视图右方。

### 2.3 剖视图剖面线方向/间距不对

1. 双击剖视图 → `设置` → 剖面线；
2. 角度改 45°；间距改 2–4 mm；
3. 检查相邻零件剖面线方向是否相反（装配剖视必须相反）。

**修复**：不同零件用不同角度/间距；同一零件保持一致。

### 2.4 尺寸文字乱码/字体不对

1. `首选项(P)` → `制图(D)...` → 注释 → 字体，改为 `仿宋_GB2312`/长仿宋；
2. 检查 Windows 是否安装该字体；缺失时 NX 会回退成方框；
3. 打开 `文件(F)` → `属性(I)` → 字体替换，查看替换记录。

**修复**：安装国标字体；或在制图首选项统一替换为企业可用字体。

### 2.5 箭头显示成点/过大

1. 双击尺寸 → `设置` → 箭头 → 类型（实心闭合）；
2. 箭头大小改 3.5 mm；
3. 检查“尺寸线延伸线”是否过长/过短。

**修复**：在制图首选项里改默认，而不是逐个改。

### 2.6 隐藏线不显示

1. `编辑(E)` → `视图(W)` → `设置(S)...` → 隐藏线 → 显示；
2. 检查视图样式是否被设为“仅可见”；
3. 若是装配视图，检查组件引用集是否只含实体（无内部结构）。

**修复**：按 GB 显示虚线；过于密集时用剖视代替。

### 2.7 中心线不显示/太长

1. `插入(S)` → `中心线(E)` → `中心标记(M)...` 重新生成；
2. 双击中心线改“延伸长度”（超出轮廓 2–5 mm）；
3. 检查视图是否被“视图相关编辑”擦除。

**修复**：用自动中心线命令，不要手画。

### 2.8 标题栏信息不更新

1. 检查标题栏文字是否链接到部件属性（`文件(F)` → `属性(I)`）；
2. 改属性后 `工具(T)` → `更新(U)` → `全部更新(U)`；
3. 若是模板字段，编辑 `GB_A*.prt` 模板并保存。

**修复**：属性驱动标题栏；不要手改每个部件。

### 2.9 打印比例不对/线宽不对

1. `文件(F)` → `绘图(L)...`（`Ctrl+P`）→ 检查“比例”=1:1；
2. 检查“线宽”是否按颜色映射（NXPLOT 配置文件）；
3. 打印 PDF 对比：`文件(F)` → `导出(E)` → `导出 PDF 文件`。

**修复**：统一 NXPLOT 配置；PDF 与纸质一致后再批量打印。

### 2.10 视图与模型不关联/不更新

1. 看视图是否“打散”（`编辑(E)` → `视图(W)` → `打散视图(W)...` 后失去关联）；
2. 检查主模型是否被替换/改名；
3. `工具(T)` → `更新(U)` → `全部更新(U)`。

**修复**：不要打散视图；用“视图相关编辑”代替；主模型用主模型结构。

### 2.11 尺寸公差显示为方框/问号

1. 字体缺符号：换 `仿宋_GB2312` 或在制图首选项设置符号字体；
2. 检查公差类型是否设为“无”；
3. 检查尺寸是否被“参考”化（不可显示公差）。

**修复**：统一符号字体；重新设公差类型。

### 2.12 GB 模板缺失（新建页签没有 GB标准制图）

1. 检查 `UGII_LANG=simpl_chinese`、`UGII_COUNTRY=prc` 是否都设置；
2. 检查 `LOCALIZATION/prc/simpl_chinese/startup/ugs_drawing_templates_GB.pax` 是否存在；
3. 用 `文件(F)` → `实用工具(U)` → `用户默认设置(D)...` → 制图 → 标准，确认 GB 可选。

**修复**：补装中文语言包/修复安装；不要从其他版本拷贝模板。

## 3. 出图交付检查（最后 60 秒）

1. `Ctrl+S` 保存 3D 与图纸；
2. 检查 3D 无红叉、无未更新；
3. 检查所有视图有边界、无空白；
4. 检查尺寸无遗漏（对照 3D 测量）；
5. 输出 PDF，按 100% 比例打印一张白纸核对线宽/字高。

## 4. 证据与边界

- 命令/路径：`catalog/nx12_cn_commands.json`。
- 标准条文：GB/T 4458 系列、GB/T 14689、GB/T 14690、GB/T 14691、GB/T 1800.1、GB/T 1182、GB/T 131。
- 模板实测：`ugs_drawing_templates_GB.pax`（页签 `GB标准制图`，模板 `GB_A0`–`GB_A4`）。
