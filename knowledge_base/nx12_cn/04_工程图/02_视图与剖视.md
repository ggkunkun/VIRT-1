# 04-02 视图、剖视与视图编辑

> 适用：NX 12.0 中文版制图。所有视图命令在 `插入(S)` → `视图(W)` 下。

## 1. 视图类型总表

| 视图 | 命令路径 | 用途 | 关键参数 |
| :--- | :--- | :--- | :--- |
| [CMD:UG_DRAFT_DRW_IMPORT_VIEW] 基本视图 | `插入(S)` → `视图(W)` → `基本(B)...` | 主视图/第一个视图 | 方向、比例、视图样式 |
| [CMD:UG_DRAFT_DRW_PROJECT_VIEW] 投影视图 | `插入(S)` → `视图(W)` → `投影(J)...` | 俯/左/右/仰视图 | 父视图、铰链线方向 |
| [CMD:UG_DRAFT_DRW_SECTION_VIEW] 剖视图 | `插入(S)` → `视图(W)` → `剖视图(S)...` | 简单/阶梯/旋转/半剖 | 剖切线、方向、剖切位置 |
| [CMD:UG_DRAFT_DRW_DETAIL_VIEW] 局部放大图 | `插入(S)` → `视图(W)` → `局部放大图(D)...` | 细节放大 | 边界类型、放大比例 |
| [CMD:UG_DRAFT_DRW_BREAKOUT] 局部剖视图 | `插入(S)` → `视图(W)` → `局部剖(O)...` | 在现有视图上局部剖开 | 边界曲线、深度 |
| [CMD:UG_DRAFT_DRW_UNFOLDED_ANGLE_SECTION_VIEW] 展开的点和角度剖视图 | `插入(S)` → `视图(W)` → `展开的点和角度剖(N)...` | 复杂折线剖 | 点、角度 |
| [CMD:UG_DRAFT_DRW_SIMPLE_3D_SECTION_VIEW] 定向剖视图 | `插入(S)` → `视图(W)` → `定向剖(T)...` | 指定方向剖切 | 方向矢量 |
| [CMD:UG_DRAFT_DRW_PICTORIAL_SECTION_VIEW] 轴测剖视图 | `插入(S)` → `视图(W)` → `轴测剖(P)...` | 轴测方向剖 | 剖切面 |
| [CMD:UG_DRAFT_DRW_PICTORIAL_HALF_SECTION_VIEW] 半轴测剖视图 | `插入(S)` → `视图(W)` → `半轴测剖(I)...` | 轴测半剖 | 剖切面 |
| [CMD:UG_DRAFT_DRW_DRAWING_VIEW] 图纸视图 | `插入(S)` → `视图(W)` → `图纸(W)...` | 空视图（放草图/注释） | 视图边界 |

## 2. 基本视图（第一个视图）

**SOP**：
1. `插入(S)` → `视图(W)` → `基本(B)...`；
2. 在“要使用的模型视图”里选方向：`俯视图`/`前视图`/`右视图`/`正等测图`（或自定义）；
3. 设置比例（默认跟随图纸页）；
4. 选择视图样式（隐藏线/光顺边）；
5. 在图纸上放置；
6. 用 `编辑(E)` → `视图(W)` → `设置(S)...` 微调。

**方向选择原则**：主视图表达最多形状特征；一般选“前视图”或零件主要加工面法向。

## 3. 投影视图

**SOP**：
1. 先有基本视图；
2. `插入(S)` → `视图(W)` → `投影(J)...`；
3. 选父视图；
4. 拖到父视图的上/下/左/右，NX 自动按第一角投影生成；
5. 放置后视图与父视图保持对齐。

**第一角投影规则（GB）**：俯视图在主视图**下方**，左视图在主视图**右方**。
若发现方向相反，说明图纸页投影角被设成第三角：`编辑(E)` → `图纸页(H)...` 改回第一角。

## 4. 剖视图

### 4.1 简单剖

1. `插入(S)` → `视图(W)` → `剖视图(S)...`；
2. 选父视图；
3. 定义剖切位置：点两点画剖切线（可捕捉圆心/端点）；
4. 指定剖切方向（箭头指向观察方向）；
5. 放置剖视图；
6. 双击剖视图可改“剖切线样式/箭头/标签”。

### 4.2 阶梯剖 / 旋转剖 / 半剖

| 类型 | 做法 | 注意 |
| :--- | :--- | :--- |
| 阶梯剖 | 剖切线画成折线，每段经过不同孔/槽中心 | 转折处必须是 90°；转折点不要落在实体内部 |
| 旋转剖 | 用“展开的点和角度剖视图”或旋转剖选项 | 两剖切面夹角按实际；展开后长度会变化 |
| 半剖 | 剖切线只画一半，另一半保留外形 | 对称件用；分界线用细点画线 |

**GB 要求**：
- 剖切平面通过机件对称面且剖视图按投影关系配置时，可省略标注；
- 剖切位置用粗短画（长约 5 mm）表示，箭头表示投射方向；
- 剖面符号（剖面线）按 GB/T 4457.5，金属材料用 45° 细实线，间距 2–4 mm。

## 5. 局部放大图

1. `插入(S)` → `视图(W)` → `局部放大图(D)...`；
2. 选父视图；
3. 画边界（圆/矩形/样条）；
4. 指定放大比例（如 2:1、5:1）；
5. 放置到图纸空白处；
6. 标注“局部放大图 I/II”和比例。

## 6. 局部剖视图（Break-out）

1. `插入(S)` → `视图(W)` → `局部剖(O)...`；
2. 选要剖的视图；
3. 画闭合边界曲线（在视图上）；
4. 指定深度（选择父视图中的点/面）；
5. 确定后局部区域显示剖面。

## 7. 视图编辑

| 操作 | 路径 | 说明 |
| :--- | :--- | :--- |
| 移动/复制视图 | `编辑(E)` → `视图(W)` → `移动/复制(Y)...` | 复制可做局部详图 |
| 对齐视图 | `编辑(E)` → `视图(W)` → `对齐(I)...` | 水平/竖直对齐 |
| 视图边界 | `编辑(E)` → `视图(W)` → `边界(B)...` | 手工裁剪视图范围 |
| 视图设置 | `编辑(E)` → `视图(W)` → `设置(S)...` | 隐藏线/光顺边/剖面线 |
| 视图相关编辑 | `编辑(E)` → `视图(W)` → `视图相关编辑(E)...` | 擦除/修改视图内对象 |
| 打散视图 | `编辑(E)` → `视图(W)` → `打散视图(W)...` | 分解为曲线（慎用，失去关联） |
| 移至新视图 | `编辑(E)` → `视图(W)` → `移至新视图(N)...` | 把对象移到另一个视图 |
| 复制到 3D | `工具(T)` → `复制到 3D...` | 图纸曲线反投影到模型 |

## 9. 视图质量与性能

| 问题 | 设置 | 说明 |
| :--- | :--- | :--- |
| 圆显示成多边形 | `首选项(P)` → `可视化(V)...` → 精度 | 提高“曲面细分”/“圆平滑度” |
| 隐藏线太多看不清 | 视图设置 → 隐藏线 → 虚线/不可见 | GB 要求虚线表达不可见轮廓 |
| 视图更新慢 | 减少“视图相关编辑”；关闭“光顺边” | 大装配出图先轻量化 |
| 剖面线太密 | 视图设置 → 剖面线 → 间距 | 2–4 mm 符合 GB |

## 10. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_DRAFT_DRW_*`）。
- 投影角/剖面符号/中心线要求：GB/T 4458 系列与 GB/T 4457.5。
- 视图对话框的选项名以 NX 12 中文界面为准；不同图纸模板可能略有差异。
