# 04-01 GB 模板与图纸页（工程图起点）

> 适用：NX 12.0 中文版 + GB/T 4458 系列。目标：从第一张图纸页开始就符合国标，而不是画完再改。

## 1. 制图的两个前置概念

| 概念 | 含义 | 实践 |
| :--- | :--- | :--- |
| 主模型（Master Model） | 3D 零件/装配是唯一数据源，图纸是它的引用 | 图纸部件单独存 `.prt`，引用 3D 模型 |
| 图纸页（Sheet） | 一张图框，可有多张 | 一个部件可含多张图纸页（A0/A4…） |

**推荐结构**：
```
ABC-001.prt            ← 3D 主模型（零件或装配）
ABC-001-dwg.prt        ← 图纸部件（引用主模型）
```
改 3D → 图纸自动更新；不要把图纸画在建模部件里（版本混乱）。

## 2. 新建图纸页（GB 模板）

### 2.1 方式 A：从 GB 模板新建（推荐）

1. `文件(F)` → `新建(N)...`（`Ctrl+N`）；
2. 选页签 `GB标准制图`（实测页签名）；
3. 选模板：`GB_A4`/`GB_A3`/`GB_A2`/`GB_A1`/`GB_A0`，或 `GB_A4 - 无视图` 等无视图变体；
4. 在“要引用的部件”里选主模型；
5. 确定后进入制图模块，图纸页与标题栏已就位。

### 2.2 方式 B：在现有部件里插入图纸页

[CMD:UG_DRAFT_DRW_NEW] 图纸页：`插入(S)` → `图纸页(H)...`

| 参数 | 合法值/建议 | 说明 |
| :--- | :--- | :--- |
| 大小 | A0/A1/A2/A3/A4（标准）或自定义 | GB 用标准幅面 |
| 比例 | 1:1、1:2、1:5、1:10…（优先序列） | 标题栏必须与图纸比例一致 |
| 单位 | 毫米 | 与主模型一致 |
| 投影 | 第一角投影（GB） | 中国标准；不要选第三角 |
| 模板 | `GB_A4` 等 | 带国标图框/标题栏 |

> **投影角是第一号坑**：GB 用第一角，ISO 也第一角，但美国用第三角。选错会导致视图位置左右颠倒。

## 3. 图纸页参数与规范

| 项 | GB 要求 | NX 设置位置 |
| :--- | :--- | :--- |
| 幅面 | A0–A4（GB/T 14689） | 图纸页对话框 → 大小 |
| 比例 | 优先比例序列（GB/T 14690） | 图纸页 → 比例；标题栏同步 |
| 图框 | 装订边 25 mm，其余 5/10 mm | GB 模板自带；自定义时按 GB |
| 标题栏 | 右下角，含图号/名称/材料/比例/重量 | GB 模板自带；编辑模板而非手画 |
| 投影 | 第一角 | 图纸页 → 投影 |
| 字体 | 长仿宋 3.5/5/7 | 制图首选项 → 注释 → 字体 |
| 线宽 | 粗 0.5/0.7，细为一半 | 制图首选项 → 线型 |

## 4. 制图标准与首选项

| 命令 | 路径 | 作用 |
| :--- | :--- | :--- |
| [CMD:UG_DRAFTING_STANDARD] 制图标准 | `工具(T)` → `制图标准(D)...` | 载入 GB 标准设置 |
| [CMD:UG_DRAFT_PREFERENCES_DRAFTING] 制图首选项 | `首选项(P)` → `制图(D)...` | 箭头/字体/线型/公差显示 |
| [CMD:UG_DRAFT_DRW_MODIFY] 编辑图纸页 | `编辑(E)` → `图纸页(H)...` | 改幅面/比例/投影 |
| [CMD:UG_DRAFT_DRW_OPEN] 打开图纸页 | `格式(R)` → `打开图纸页(T)...` | 切换图纸页 |

**判据**：图纸页建立后，先检查三件事——幅面、比例、投影角。这三项错了，后面全白画。

## 5. 视图创建的基本顺序

1. `插入(S)` → `视图(W)` → `基本(B)...`（`UG_DRAFT_DRW_IMPORT_VIEW`）放主视图；
2. `插入(S)` → `视图(W)` → `投影(J)...`（`UG_DRAFT_DRW_PROJECT_VIEW`）放俯视/左视；
3. `插入(S)` → `视图(W)` → `剖视图(S)...`（`UG_DRAFT_DRW_SECTION_VIEW`）表达内部；
4. `插入(S)` → `视图(W)` → `局部放大图(D)...`（`UG_DRAFT_DRW_DETAIL_VIEW`）表达细节；
5. 视图调整：`编辑(E)` → `视图(W)` → `移动/复制(Y)...` / `对齐(I)...`；
6. 标注：`插入(S)` → `尺寸(M)` / `注释(A)`；
7. 中心线：`插入(S)` → `中心线(E)`；
8. 校核：按 04-04 的 GB 清单逐项过。

## 6. 视图显示设置（国标化）

| 项 | 建议 | 路径 |
| :--- | :--- | :--- |
| 隐藏线 | 虚线（细线） | `编辑(E)` → `视图(W)` → `设置(S)...` → 隐藏线 |
| 光顺边 | 不显示 | 同上 → 光顺边 |
| 延长线/剖面线 | 按 GB | 同上 |
| 视图边界 | 自动/手工 | `编辑(E)` → `视图(W)` → `边界(B)...` |
| 视图相关编辑 | 局部擦除/修改 | `编辑(E)` → `视图(W)` → `视图相关编辑(E)...` |

## 7. 标题栏填写（GB）

| 字段 | 必填 | 说明 |
| :--- | :--- | :--- |
| 图号 | ✔ | 与文件名一致 |
| 名称 | ✔ | 零件/装配名称 |
| 材料 | ✔ | 牌号（如 45、Q235、6061-T6） |
| 比例 | ✔ | 与图纸页比例一致 |
| 重量 | ✔ | 由 3D 质量属性计算 |
| 设计/审核/批准 | ✔ | 责任签署 |
| 日期 | ✔ | 出图日期 |
| 单位名称 | ✔ | 企业名称 |

## 8. 最佳实践

1. 一张图纸只表达一个零件/一个装配；多件用多张图纸页。
2. 主视图选择：表达形状特征最多、加工/装配基准最清楚的方向。
3. 视图数量“够用就好”：每个视图必须有存在的理由（表达孔/槽/内部）。
4. 比例优先 1:1；装不下再缩小；不要用“视图缩放”代替图纸比例。
5. 出图前 `Ctrl+S`，并检查 3D 模型已全部更新（无红叉）。
