# 10-01 通用故障诊断树（NX 12.0 中文版）

> 用途：任何“命令不可用/报错/结果不对”先走这棵树，避免盲目重装或改参数。
> 纪律：一次只改一个变量；每步留证据（截图/日志/测量值）。

## 1. 五层诊断树

```
T0 环境层：许可服务 / 语言 / 安装完整性
  ↓ 正常
T1 模块层：当前应用模块 / 角色 / 许可模块
  ↓ 正常
T2 命令层：命令是否存在 / 是否灰显 / 是否被插件覆盖
  ↓ 正常
T3 选择层：选择过滤器 / 工作部件 / 对象类型
  ↓ 正常
T4 参数层：范围 / 单位 / 父子关系
  ↓ 正常
T5 数据层：模型精度 / 导入件 / 装配引用
```

## 2. T0 环境层（先排除 30% 的“假故障”）

| 检查 | 命令 | 判据 |
| :--- | :--- | :--- |
| 许可服务 | `Get-Service | ? Name -match 'Siemens|FLEX'` | `Siemens PLM License Server` = Running |
| 语言 | 环境变量 `UGII_LANG=simpl_chinese`、`UGII_COUNTRY=prc` | 界面为中文；GB 模板页签存在 |
| 安装完整性 | `帮助(H)` → `关于 NX(A)...` | 版本 12.0.x；模块列表含 Modeling/Drafting/CAM |
| 磁盘/权限 | 输出目录可写 | 非中文/空格路径；有写权限 |
| 显卡 | `首选项(P)` → `可视化(V)...` | 破面随视角变化=显示问题 |

**处置**：服务未启动 → 启动服务/联系管理员；语言不对 → 改环境变量重启；安装缺模块 → 修复安装。

## 3. T1 模块层

| 现象 | 检查 | 处置 |
| :--- | :--- | :--- |
| 制图命令全灰 | 当前是否在建模模块 | `应用模块(N)` → `制图(D)` |
| CAM 菜单没有 | 是否进入加工 | `应用模块(N)` → `加工(M)` |
| 同步建模没有 | 角色是“基本” | `首选项(P)` → `用户界面(I)...` → 角色改“高级” |
| 装配命令灰 | 当前部件不是装配 | 打开装配 .prt；或 `装配(A)` 建装配 |

## 4. T2 命令层

### 4.1 命令找不到

1. `帮助(H)` → `命令查找器(F)...` 搜中文名（如“特征控制框”，不是“形位公差”）；
2. `工具(T)` → `定制(Z)...`（`Ctrl+1`）→ 命令页签搜命令，看是否被隐藏；
3. 看是否被第三方插件菜单覆盖：原生命令仍在 `文件/插入/工具` 原路径。

### 4.2 命令灰显

| 原因 | 判据 | 处置 |
| :--- | :--- | :--- |
| 当前模块不对 | 菜单组整体灰 | 切模块 |
| 没有选择对象 | 选对象后变亮 | 先选对象 |
| 选择类型不符 | 选了片体要布尔 | 换实体/改选择过滤 |
| 参数前置未满足 | 对话框内灰 | 按提示补前置 |
| 许可模块缺失 | 提示“无许可证” | 联系管理员 |

## 5. T3 选择层

| 检查 | 操作 | 说明 |
| :--- | :--- | :--- |
| 选择过滤器 | 选择条 → 过滤到“体/面/边/组件” | 过滤错是最常见“选不中” |
| 工作部件 | 装配导航器看粗体部件 | 装配中改错部件 |
| 对象类型 | `信息(I)` → `对象(O)...` | 片体/实体/小平面体 |
| 图层/隐藏 | `格式(R)` → `图层设置(S)...`（`Ctrl+L`） | 对象在隐藏层 |
| 引用集 | 装配组件引用集 | 只显示部分对象 |

## 6. T4 参数层

| 检查 | 操作 | 说明 |
| :--- | :--- | :--- |
| 范围 | 看对话框输入限制/提示 | 负值/0/超长 |
| 单位 | `文件(F)` → `属性(I)` | 英寸混入 |
| 父子关系 | 部件导航器顺序 | 圆角在抽壳前 |
| 表达式 | `工具(T)` → `表达式(X)...`（`Ctrl+E`） | 尺寸被表达式锁定 |
| 公差 | 缝合/交点/距离公差 | 过小失败、过大误合 |

## 7. T5 数据层

| 检查 | 操作 | 说明 |
| :--- | :--- | :--- |
| 模型精度 | `分析(L)` → `形状(H)` → `曲面连续性(C)...` | 破面/缝隙 |
| 导入件 | `文件(F)` → `属性(I)` → 单位 | STEP/IGES 单位 |
| 装配引用 | `文件(F)` → `选项(T)` → `装配加载选项(Y)...` | 组件丢失 |
| 更新状态 | `工具(T)` → `更新(U)` → `全部更新(U)` | 未更新 |
| 对象信息 | `Ctrl+I` | 看体类型/所属部件/图层 |

## 8. 熔断与回滚（连续 3 次失败必须停）

按 AGENTS.md §6：

1. **停止修改**：不再连续试参数；
2. **原子回滚**：`git restore .`（代码/脚本）或撤销 CAD 事务（`Ctrl+Z` 到稳定点）；
3. **RCFA**：记录
   - 现象（原文报错/截图）
   - 复现步骤（最小）
   - 已排除项（T0–T5 哪层正常）
   - 根因假设 + 验证方法
   - 建议（人工介入/升级/换方案）

## 9. 证据留存清单

| 故障类型 | 必留证据 |
| :--- | :--- |
| 命令灰 | 截图（菜单+选择状态）+ 当前模块/角色 |
| 报错 | 提示行原文 + 部件导航器红叉位置 |
| 结果不对 | 测量值 + 理论值 + 误差 |
| 装配 | 装配导航器截图 + 约束列表 |
| CAM | 工序导航器截图 + 刀轨确认截图 + NC 头尾 |
| 显示 | 同一模型两个视角截图（判断显示/模型） |

## 10. 证据与边界

- 诊断项均为 NX 12.0 中文界面可执行动作。
- 命令/路径：`catalog/nx12_cn_commands.json`。
- 熔断规则引自 AGENTS.md §6（极速极限单步自查与熔断公理）。
