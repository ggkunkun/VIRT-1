## 1. 添加组件找不到文件

**排查**：
1. `文件(F)` → `选项(T)` → `装配加载选项(Y)...`（`UG_FILE_LOAD_OPTIONS`）看搜索目录。
2. 确认组件 .prt 是否被移动/改名（NX 按文件名+内部 ID 查找）。
3. 看“加载”方式是否为 `从文件夹`/`按保存的`；换 `搜索目录` 再试。

**修复**：把组件放回原目录 → 在加载选项中加搜索路径 → 用 `文件(F)` → `实用工具(U)` → `装配加载选项` 重设。
**预防**：装配与组件同目录；交付时整目录打包。

---

## 2. 组件位置乱、跑到很远

**排查**：
1. 看组件是否用“绝对原点”放置但零件坐标系不在设计位置。
2. 装配导航器看约束是否被抑制/删除。
3. `装配(A)` → `组件位置(P)` → `重定位组件(R)...` 看当前变换。

**修复**：删除错误约束 → 用“接触+同轴”重新定位 → 或 `重定位组件` 手动移到大致位置再约束。
**预防**：第一个零件用绝对原点，后续一律约束；不要用“移动对象”代替约束。

---

## 3. 约束冲突、过约束

**排查**：
1. 装配导航器展开约束节点，看哪条约束带红叉/黄色警告。
2. 逐条抑制约束（右键 → `抑制`），看冲突是否消失，定位重复项。
3. 检查是否同时对同一自由度加了“距离”和“接触”。

**修复**：删重复约束 → 保留一个主约束 → `工具(T)` → `更新(U)` → `更新装配约束(O)`。
**预防**：一个自由度只留一个约束源；先定位后防转。

---

## 4. 组件显示成方框

**排查**：
1. 装配导航器看组件图标是否为“轻量化”/“部分加载”。
2. 右键组件 → `表示`/`显示精确`，或 `装配(A)` → `关联控制(O)` → `显示精确(E)`。
3. 检查引用集是否为空/只含基准。

**修复**：`显示精确` → 换引用集为 `MODEL`/`BODY` → 重新加载组件。
**预防**：大装配默认轻量化，出图/检查前切精确。

---

## 5. 装配打开慢、内存不足

**排查**：
1. `文件(F)` → `选项(T)` → `装配加载选项(Y)...` 看是否“加载全部组件”。
2. 看组件数量与单件复杂度（大面数/小平面体）。
3. 任务管理器看内存峰值；NX 32 位限制已不适用，但仍受物理内存限制。

**修复**：改“按需加载” → 用引用集 `BODY` → 小平面体降面 → 关闭不必要组件。
**预防**：标准件轻量化；大装配分总成。

---

## 6. 组件改不了、灰显

**排查**：
1. 看当前“工作部件”是谁：装配导航器粗体/带笔图标。
2. `装配(A)` → `关联控制(O)` → `设置工作部件(W)` 切到目标组件。
3. 检查文件是否只读（Windows 属性）或许可证模块是否缺失。

**修复**：设工作部件 → 取消只读 → 用 `装配(A)` → `关联控制(O)` → `打开组件(O)` 单独打开编辑。
**预防**：改组件前先确认工作部件；团队协作时避免同时改同一组件。

---

## 7. WAVE 链接断开

**排查**：
1. `工具(T)` → `更新(U)` → `全部更新(U)`，看提示哪些链接失效。
2. `装配(A)` → `WAVE` → `部件间链接浏览器(B)...` 查看断链。
3. 检查源组件是否被改名/移动/删除。

**修复**：恢复源文件 → 重新链接（`WAVE 几何链接器`）→ 或断开链接改为独立几何。
**预防**：WAVE 源文件只读保护；交付前跑一次全部更新。

---

## 8. 间隙分析无结果

**排查**：
1. 看是否选了间隙集：`分析(L)` → `装配间隙(Y)` → `间隙集(C)` → `设置(S)...`。
2. 检查间隙集里是否包含组件对/组；空集不出结果。
3. 确认组件已加载为精确显示（轻量化可能不参与）。

**修复**：新建间隙集 → 加入组件对 → 设阈值 → `执行分析(P)`。
**预防**：分析前 `显示精确` + 全部加载。

---

## 9. 干涉检查误报/漏报

**排查**：
1. 确认选择的是实体而非片体/小平面体（片体不产生体积干涉）。
2. 检查单位与比例是否一致（英寸件混入 mm 装配）。
3. 看干涉体积值：面接触体积≈0 属正常，不应判为干涉。

**修复**：统一单位 → 片体先加厚 → 只对关键组件对做干涉。
**预防**：干涉检查前 `显示精确`，并记录判定阈值（体积 > 0）。

---

## 10. 另存后组件丢失

**排查**：
1. 另存时是否选“仅装配”而非“整个装配”。
2. 看新目录下是否有组件 .prt；装配加载选项是否还指向旧目录。
3. 打开新装配时看“加载”提示，确认哪些组件未找到。

**修复**：重新“另存为整个装配”到新目录 → 或手工复制组件并改加载路径。
**预防**：交付前用 `文件(F)` → `全部保存(V)`；整目录打包，不单独拷 .prt。
