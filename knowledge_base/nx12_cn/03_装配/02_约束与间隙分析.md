# 03-02 装配约束、间隙与干涉分析

> 目标：装配不是“摆好看”，而是可计算的约束系统。本文件给出约束参数、间隙分析、干涉检查、爆炸与报表的完整闭环。

## 1. 约束类型与参数（按优先级使用）

| 优先级 | 约束 | 路径 | 参数/合法范围 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 固定 | `装配(A)` → `组件位置(P)` → `装配约束(N)...` → 固定 | 选组件 | 基座必须固定；其余慎用 |
| 2 | 接触/对齐 | 同上 | 偏置距离（默认 0，可正负） | 面贴合最稳 |
| 3 | 中心/同轴 | 同上 | 选两圆柱面 | 孔轴配合 |
| 4 | 距离 | 同上 | 距离值；可输表达式 | 需要间隙时用 |
| 5 | 平行/垂直 | 同上 | 选两面/两轴 | 防转 |
| 6 | 角度 | 同上 | 0°～360° | 角度定位 |
| 7 | 胶合 | 同上 | 两组件 | 完全固定相对关系，慎用 |

> 约束不是越多越好：过约束会导致“更新失败/约束冲突”。一个自由度只留一个约束源。

## 2. 装配约束的标准操作

1. `装配(A)` → `组件位置(P)` → `装配约束(N)...`（`UG_NXPOS_ASSEMBLY_CONSTRAINTS`）。
2. 选类型（接触/中心/距离…）。
3. 依次选两个对象；注意方向箭头，必要时点“反向”。
4. 输入偏置/距离（无间隙填 0）。
5. `应用` 后看装配导航器：约束节点出现；组件名前出现“完全约束”图标。
6. 全部装完：`工具(T)` → `更新(U)` → `全部更新(U)`。

**判据**：拖动组件不动 = 全约束；能拖 = 欠约束；拖一下就报错 = 过约束。

## 3. 更新与延迟更新

| 命令 | 路径 | 用途 |
| :--- | :--- | :--- |
| 更新装配约束 | `工具(T)` → `更新(U)` → `部件间更新(I)` → `更新装配约束(O)`（`UG_ASSY_UPDATE_ASSEMBLY_CONSTRAINTS`） | 约束改动后统一更新 |
| 延迟装配约束更新 | `装配(A)` → `组件位置(P)` → 延迟装配约束更新 | 大装配改约束时先关自动更新，最后统一更新 |
| 记住装配约束 | `装配(A)` → `组件位置(P)` → `记住装配约束(B)...` | 保存约束方案 |
| 转换配对条件 | `装配(A)` → `组件位置(P)` → `转换配对条件(S)...` | 老版本配对条件迁移 |

## 4. 装配间隙分析（Clearance Analysis）

### 4.1 入口

`分析(L)` → `装配间隙(Y)` → 子菜单。

| 命令 | 路径 | 作用 |
| :--- | :--- | :--- |
| [CMD:UG_ASSY_CLEAR_PERFORM_ANALYSIS] 执行分析 | `分析(L)` → `装配间隙(Y)` → `执行分析(P)` | 按当前间隙集计算 |
| [CMD:UG_ASSY_CLEAR_RECORD_LINES] 研究间隙违例 | `分析(L)` → `装配间隙(Y)` → `研究间隙违例(V)...` | 逐条查看违例 |
| [CMD:UG_ASSY_CLEAR_SET_DATASET] 设置间隙集 | `分析(L)` → `装配间隙(Y)` → `间隙集(C)` → `设置(S)...` | 选当前间隙集 |
| [CMD:UG_ASSY_CLEAR_NEW_DATASET] 新建间隙集 | `分析(L)` → `装配间隙(Y)` → `间隙集(C)` → `新建(N)...` | 新建规则集 |
| [CMD:UG_ASSY_CLEAR_DATASET_PROPERTIES] 编辑间隙集 | `分析(L)` → `装配间隙(Y)` → `间隙集(C)` → `编辑(E)...` | 改间隙阈值 |
| [CMD:UG_ASSY_CLEAR_DATASET_SUMMARY] 间隙集汇总 | `分析(L)` → `装配间隙(Y)` → `分析(A)` → `汇总(M)` | 汇总结果 |
| [CMD:UG_ASSY_CLEAR_DATASET_REPORT] 间隙分析报告 | `分析(L)` → `装配间隙(Y)` → `分析(A)` → `报告(R)` | 生成报告 |
| [CMD:UG_ASSY_CLEAR_BATCH] 批处理间隙分析 | `分析(L)` → `装配间隙(Y)` → `分析(A)` → `批处理(H)...` | 多方案批算 |

### 4.2 标准 SOP

1. **新建间隙集**：定义要检查的组件对/组、最小间隙值（如 0.5 mm）。
2. **设置间隙集**为当前。
3. `执行分析(P)`。
4. `研究间隙违例(V)...` 逐条定位；违例组件会高亮。
5. 修模型/约束 → 重新执行。
6. `报告(R)` 输出；`保存报告(S)...` 归档。
7. 交付前用 `批处理(H)...` 做全装配复核。

**参数建议**：运动件最小间隙 ≥ 0.5 mm；固定件贴合面 0；电气安全间隙按行业标准（如 3 mm/8 mm）。

## 5. 干涉检查（Interference）

| 命令 | 路径 | 用途 |
| :--- | :--- | :--- |
| [CMD:UG_INFO_ANALYSIS_INTERFERENCE] 简单干涉 | `分析(L)` → `简单干涉(I)...` | 两体/两组组件干涉 |
| [CMD:MW_INTERFERENCE] 静态干涉检查 | `工具(T)` → `特定于工艺(O)` → `注塑模向导(M)` → `注塑模工具(T)` → `静态干涉检查(I)...` | 模具标准件干涉 |

**SOP**：`简单干涉` → 选两组组件 → `检查干涉` → 看结果体/高亮 → `信息(I)` 查看干涉体积。

**判据**：干涉体积 > 0 即不合格；面接触（体积=0）不算干涉。

## 7. 参数与容差建议

| 项 | 建议值 | 说明 |
| :--- | :--- | :--- |
| 贴合面偏置 | 0 mm | 接触约束默认 |
| 运动间隙 | ≥ 0.5 mm | 按运动副精度 |
| 螺栓通孔间隙 | 0.2–0.5 mm | 按 GB/T 5277 中等装配 |
| 干涉判定体积 | > 0 mm³ | 面接触不计 |
| 间隙分析批处理 | 全装配 | 交付前必跑 |

## 8. 最佳实践

1. 约束“先定位后防转”：接触/同轴 → 距离/角度。
2. 大装配先“延迟更新”，改完统一更新。
3. 标准件用引用集 `BODY`，间隙分析只算关键件，避免组合爆炸。
4. 间隙报告与爆炸图一起归档：报告证明“不干涉”，爆炸图证明“装得进去”。
5. 交付前 `文件(F)` → `全部保存(V)`，并确认所有组件已保存。

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_ASSY_CLEAR_*` 共 12 条）。
- 间隙/干涉参数为工程建议；NX 只负责计算，不替你定标准。
