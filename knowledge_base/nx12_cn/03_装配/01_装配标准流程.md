# 03-01 装配标准流程

> 适用：NX 12.0 中文版。装配的本质是“引用组件 + 约束定位”，不是把零件复制进来。
> 本文件覆盖：新建装配、添加组件、装配约束、工作部件、引用集、自顶向下（WAVE）、装配报表。

## 1. 新建装配（三种起手式）

| 方式 | 路径 | 适用 | 注意 |
| :--- | :--- | :--- | :--- |
| 空装配 | `文件(F)` → `新建(N)...` → `装配` → `assembly-mm-template.prt` | 自底向上 | 单位 mm；模板已带装配导航器 |
| 从零件建装配 | 打开零件 → `文件(F)` → `新建(N)...` → `装配` | 单件为主 | 把零件作为第一个组件加入 |
| 自顶向下 | 新建装配 → `装配(A)` → `组件(C)` → `新建组件(C)...` | 先定结构后设计 | 组件在装配上下文中建模，尺寸可关联 |

**目录纪律**：装配 .prt 与所有组件 .prt 放在同一项目目录；用“装配加载选项”指定搜索路径，避免打开时找不到组件。

## 2. 添加组件

[CMD:UG_ASSY_INSERT_COMPONENT] 添加组件：`装配(A)` → `组件(C)` → `添加组件(A)...`

| 定位方式 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 绝对原点 | 组件坐标系与装配坐标系重合 | 第一个组件（基座） |
| 选择原点 | 点选放置点 | 快速摆位 |
| 配对 | 放置时直接加约束 | 有明确配合面时 |
| 移动 | 放置后手动拖拽 | 粗定位 |

**SOP**：
1. 选 `添加组件` → 浏览 .prt；
2. 定位选 `绝对原点`（第一个组件）；
3. 后续组件选 `配对` 或 `选择原点`；
4. 勾选“预览”确认方向；
5. 确定后组件出现在装配导航器。

> 添加组件时勾选“显示组件”可避免“加了但看不见”（被引用集/图层隐藏）。

## 3. 装配约束（核心）

[CMD:UG_NXPOS_ASSEMBLY_CONSTRAINTS] 装配约束：`装配(A)` → `组件位置(P)` → `装配约束(N)...`

| 约束类型 | 作用 | 选择对象 | 参数 |
| :--- | :--- | :--- | :--- |
| 接触/对齐 | 两面重合（法向相反/相同） | 两面 | 偏置距离（默认 0） |
| 距离 | 两面保持距离 | 两面 | 距离值（可正负） |
| 平行 | 两面/两轴平行 | 两对象 | — |
| 垂直 | 两面/两轴垂直 | 两对象 | — |
| 中心/同轴 | 两圆柱同轴 | 两圆柱面 | — |
| 角度 | 两面夹角 | 两面 | 角度值 |
| 固定 | 锁定组件 | 组件 | — |
| 胶合 | 完全固定相对关系 | 两组件 | — |

**SOP（标准件装配）**：
1. 基座 `固定`；
2. 第一个零件：`接触`（底面贴基座面）+ `中心/同轴`（孔轴对齐）；
3. 第二个零件：重复；
4. 每加一个约束看装配导航器约束节点是否有红叉；
5. 全部约束后拖动组件：拖不动 = 全约束；能拖 = 欠约束。

**判据**：装配导航器组件名前出现“完全约束”图标；状态栏无“欠约束”提示。

## 4. 工作部件与显示部件（最容易搞错）

| 概念 | 含义 | 切换路径 |
| :--- | :--- | :--- |
| 显示部件 | 当前窗口显示的顶层 | 装配导航器双击顶层 |
| 工作部件 | 当前可编辑的部件 | `装配(A)` → `关联控制(O)` → `设置工作部件(W)` |
| 组件 | 装配中的引用 | 装配导航器节点 |

**规则**：在装配里画草图/建特征，必须先设工作部件为要改的组件，否则特征建到装配顶层（错误）。

## 5. 引用集（控制组件显示内容）

[CMD:UG_ASSY_REFERENCE_SETS] 引用集：`格式(R)` → `引用集(R)...`

| 引用集 | 内容 | 用途 |
| :--- | :--- | :--- |
| `MODEL` | 实体+基准 | 设计装配 |
| `BODY` | 仅实体 | 轻量化 |
| `空` | 不显示 | 隐藏组件内容 |
| 自定义 | 指定对象 | 只显示关键结构 |

**替换引用集**：`装配(A)` → `替换引用集(R)...`；或在装配导航器右键组件 → `替换引用集`。

## 6. 自顶向下设计（WAVE）

[CMD:UG_ASSY_WAVE_LINKER] WAVE 几何链接器：`插入(S)` → `关联复制(A)` → `WAVE 几何链接器(W)...`

| 步骤 | 操作 | 说明 |
| :--- | :--- | :--- |
| 1 | 设工作部件为目标组件 | 在目标组件内建特征 |
| 2 | `WAVE 几何链接器` 选源组件的面/体/曲线 | 建立关联副本 |
| 3 | 在目标组件内基于链接几何建模 | 源改则目标更新 |
| 4 | 检查 `工具(T)` → `更新(U)` → `全部更新(U)` | 确认关联链 |

**边界**：WAVE 链接会产生跨部件依赖；交付前用 `装配(A)` → `WAVE` → `部件间链接浏览器(B)...` 检查，避免断链。

## 7. 装配爆炸图

| 命令 | 路径 | 用途 |
| :--- | :--- | :--- |
| [CMD:UG_ASSY_CREATE_EXPLOSION] 新建爆炸 | `装配(A)` → `爆炸图(X)` → `新建爆炸(N)...` | 建立爆炸视图 |
| [CMD:UG_ASSY_EXPLODE_COMPONENT] 编辑爆炸 | `装配(A)` → `爆炸图(X)` → `编辑爆炸(E)...` | 手动拖组件 |
| [CMD:UG_ASSY_AUTO_EXPLODE_COMPONENT] 自动爆炸组件 | `装配(A)` → `爆炸图(X)` → `自动爆炸组件(A)...` | 按约束自动散开 |
| [CMD:UG_ASSY_CREATE_TRACELINES] 追踪线 | `装配(A)` → `爆炸图(X)` → `追踪线(T)...` | 装配关系线 |

**SOP**：新建爆炸 → 自动爆炸 → 手动微调 → 加追踪线 → 保存视图 → 出工程图（爆炸视图可作为图纸视图）。

## 8. 装配报表与重量

| 功能 | 路径 | 输出 |
| :--- | :--- | :--- |
| 组件列表 | `信息(I)` → `装配(A)` → `列出组件(L)` | 组件清单 |
| 组件何处使用 | `信息(I)` → `装配(A)` → `何处使用(W)...` | 反查引用 |
| 装配重量 | `分析(L)` → `高级质量属性(E)` → `高级重量管理(W)...` | 总重量/质心 |
| 装配间隙 | `分析(L)` → `装配间隙(Y)` → `执行分析(P)` | 间隙报告（详见 03-02） |

## 9. 最佳实践

1. **先固定基座，再装零件**；不要所有组件都“固定”，否则无法调整。
2. 约束“从大到小”：先主定位面，再次要面，最后防转。
3. 标准件用引用集 `BODY` 轻量化；大装配用“轻量级显示”。
4. 组件命名与图号一致；装配导航器按图号排序。
5. 交付前：`文件(F)` → `全部保存(V)`；检查所有组件已保存（组件名无 `*`）。
6. 不要用“移动对象”代替装配约束；移动对象不产生约束，改图后位置会丢。

## 10. 证据与边界

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_ASSY_*`、`UG_NXPOS_*`，共 85 条装配命令）。
- 约束类型名称取自 NX 12 中文装配约束对话框与菜单。
- 自顶向下/WAVE 的更新行为依赖装配加载选项，交付前必须实测更新。
