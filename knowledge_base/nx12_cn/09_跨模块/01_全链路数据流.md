# 09-01 全链路数据流（零件 → 装配 → 工程图 → 加工）

> 本文件回答“跨模块怎么传、传什么、在哪里断”。所有入口均为 NX 12.0 中文版原生命令。

## 1. 全链路总览

```
需求/图纸
  ↓ 意图解析（尺寸链、基准、材料、批量）
3D 主模型（.prt, mm）
  ├─ 装配（.prt, 引用组件 + 约束）
  ├─ 工程图（-dwg.prt, 主模型引用, GB 模板）
  └─ 加工（cam.prt 或主模型内 CAM, MCS/WORKPIECE）
        ↓ 刀轨 → 后处理
      NC 程序（.nc/.mpf/.h）
        ↓ 仿真
  VERICUT / SSCNC / CIMCO（红蓝绿门）
        ↓ 反馈
  修模型/修刀路/修后处理 → 回到 3D 或 CAM
```

## 2. 五个交接点（最容易断的地方）

| # | 交接 | 传递什么 | 规则 | 断链表现 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 需求 → 3D | 尺寸、公差、材料、基准 | 单位 mm；基准统一；关键尺寸表达式化 | 模型与图纸不符 |
| 2 | 3D → 装配 | 组件 .prt、引用集、坐标系 | 装配与组件同目录；第一个组件绝对原点 | 打开缺组件 |
| 3 | 3D → 工程图 | 主模型、属性（图号/材料/重量） | 主模型结构；标题栏属性驱动 | 图纸不更新 |
| 4 | 3D/装配 → CAM | 实体、MCS、毛坯、夹具 | MCS Z=主轴；WORKPIECE 三件套 | 加工偏/撞夹具 |
| 5 | CAM → 机床 | NC 程序、后处理、刀具表 | 一台机床一个后处理；单位/坐标系核对 | 机床报警/撞机 |

## 3. 文件与目录规范（建议）

```
项目号/
├── 3D/
│   ├── PRT-001.prt              # 零件主模型
│   ├── ASM-001.prt              # 装配
│   └── ASM-001-dwg.prt          # 装配工程图
├── 2D/
│   ├── PRT-001-dwg.prt          # 零件工程图
│   └── PRT-001.pdf
├── CAM/
│   ├── PRT-001-cam.prt          # 加工部件
│   ├── PRT-001-O1001.nc         # NC 程序
│   └── post/                    # 后处理（受控）
├── SIM/
│   ├── PRT-001.vcproject        # VERICUT 项目
│   └── autodiff_*.png
└── DOC/
    └── 工艺卡/检验卡
```

**规则**：
- 路径不含中文/空格（CAM/后处理/NXPLOT 对中文路径敏感）；
- 3D 与 2D 同名不同后缀；NC 文件名含图号+工序号；
- 后处理与仿真项目纳入版本控制（Git/PDM）。

## 4. 关联关系（改一处，哪里会变）

| 源头改动 | 自动更新 | 需手动更新 | 检查命令 |
| :--- | :--- | :--- | :--- |
| 草图尺寸 | 拉伸/旋转等子特征 | 后续圆角/抽壳可能失败 | `工具(T)` → `更新(U)` → `全部更新(U)` |
| 3D 特征 | 工程图视图 | 尺寸可能需重标 | 制图 → 更新视图 |
| 组件位置 | 装配约束 | 工程图装配视图 | 更新全部 |
| WAVE 链接 | 目标组件 | 下游特征 | `部件间链接浏览器` |
| 3D 模型 | CAM 工序几何 | 刀轨需重新生成 | 工序导航器 → 生成 |
| 后处理 | — | 全部 NC 重出 | 后处理 |

## 5. 三条数据传递通道

| 通道 | 方式 | 关联性 | 适用 |
| :--- | :--- | :--- | :--- |
| 主模型引用 | 图纸部件引用 3D | 强关联（改 3D 图更新） | 正式出图 |
| WAVE | 跨组件链接几何 | 强关联（可断） | 自顶向下 |
| 中性格式 | STEP/Parasolid/IGES | 无关联（快照） | 外协/跨软件 |

**选择**：内部协作用主模型/WAVE；外协用 STEP AP214（带颜色/图层）；仿真用 STL/STEP。

## 6. 数据交换命令（NX 12 中文）

| 格式 | 导入 | 导出 |
| :--- | :--- | :--- |
| STEP | `文件(F)` → `导入(M)` → `导入 STEP214 文件` | `文件(F)` → `导出(E)` → `导出 STEP 文件` |
| Parasolid | `导入(M)` → `导入 Parasolid 文件` | `导出(E)` → `导出 Parasolid 文件` |
| IGES | `导入(M)` → `导入 IGES 文件` | `导出(E)` → `导出 IGES 文件` |
| DXF/DWG | `导入(M)` → `导入 AutoCAD DXF/DWG 文件` | `导出(E)` → `导出 AutoCAD DXF/DWG 文件` |
| STL | `导入(M)` → `导入 STL 文件` | `导出(E)` → `导出 STL 文件` |
| JT | — | `导出(E)` → `导出 JT 文件` |
| PDF | — | `导出(E)` → `导出 PDF 文件` |

## 7. 端到端验收门（每道门必须实测）

| 门 | 判据 | 证据 |
| :--- | :--- | :--- |
| G1 模型 | 体积 > 0；关键尺寸与需求一致；无红叉 | 测量报告/截图 |
| G2 装配 | 全约束；间隙 ≥ 0.5；干涉 = 0 | 间隙报告/干涉报告 |
| G3 工程图 | GB 校核 18 项通过；PDF 1:1 | 图纸 PDF |
| G4 CAM | 刀轨生成；无过切；最小刀长满足 | 确认刀轨截图/日志 |
| G5 后处理 | NC 头尾完整；单位/坐标系正确 | NC 文件 |
| G6 仿真 | Auto-Diff 绿；无红/蓝超差 | 仿真报告+图 |
| G7 交付 | 3D/2D/NC/仿真/BOM 齐套 | 交付清单 |

> **诚实边界**：G4–G6 依赖机床/刀具/材料真实参数；没有实测就只能标“理论通过”，不能写“已加工验证”。

## 8. 跨模块排错顺序

1. **先看 3D**：模型红叉 → 后面全错；
2. **再看装配**：约束/引用集/工作部件；
3. **再看图纸**：主模型引用/投影角/比例；
4. **再看 CAM**：MCS/WORKPIECE/刀具；
5. **最后看后处理**：系统/单位/坐标系；
6. 每步用“单变量”法：一次只改一处，改完立即验证。
