# 06-01 钣金特征与展开

> 适用：NX 12.0 中文版。NX 12 同时提供**经典钣金特征**（`插入(S)` → `钣金特征(H)`）与 **NX 钣金**（`插入(S)` → `突出块` / `拐角` / `冲孔`）。
> 本文件以经典钣金特征为主线，NX 钣金命令作为补充；两者不要在同一零件里混用同一特征链。

## 1. 两条命令线（先认清）

| 线 | 入口 | 代表命令 | 适用 |
| :--- | :--- | :--- | :--- |
| 经典钣金特征 | `插入(S)` → `钣金特征(H)` | 弯边、折弯、伸直/重新折弯、钣金成形 | 传统钣金件、展开图 |
| NX 钣金（SBSM） | `插入(S)` → `突出块`；`插入(S)` → `拐角(O)`；`插入(S)` → `冲孔(H)` | 突出块、封闭拐角、筋、撕边 | 新式钣金、NX 高级钣金 |

> 判据：菜单里出现 `钣金特征(H)` 说明经典模块可用；出现 `突出块` 说明 NX 钣金可用。两者都原生，但特征树不同，**一个零件只用一条线**。

## 2. 基体（第一块板）

| 方式 | 路径 | 参数 | 说明 |
| :--- | :--- | :--- | :--- |
| 突出块（NX 钣金） | `插入(S)` → `突出块`（`UG_SBSM_TAB_FEATURE`） | 厚度、草图轮廓 | 自动带钣金属性 |
| 拉伸薄壁（经典） | `插入(S)` → `设计特征(E)` → `拉伸(X)...` + 偏置 | 厚度 T、长度 | 需手工设钣金首选项 |
| 平板（如有） | `插入(S)` → `钣金特征(H)` → 平板 | 厚度、尺寸 | 视安装模块而定 |

**推荐**：正式钣金件用 `突出块`（NX 钣金）或经典 `弯边` 的基体；厚度用表达式 `T=2` 驱动。

## 3. 弯边（Flange）

[CMD:UG_MODELING_SMD_FLANGE] 弯边：`插入(S)` → `钣金特征(H)` → `弯边(F)...`

| 参数 | 说明 | 合法/推荐 |
| :--- | :--- | :--- |
| 选择边 | 基体边缘 | 必须是直边/可展开边 |
| 长度 | 弯边伸出长度 | > 0；按图纸 |
| 角度 | 弯边角 | 0°～180°；常用 90° |
| 半径 | 折弯内半径 | ≥ 板厚 T（工程推荐 R≥T） |
| 方向 | 材料侧/折弯方向 | 用箭头切换 |
| 止裂口 | 无/矩形/圆形/长圆形 | 弯边两端必须止裂，防止撕裂 |
| 折弯展开 | 展开公式/K 因子 | 见 06-02 |

**SOP**：选边 → 输入长度/角度/R → 定方向 → 设止裂口 → 预览 → 确定。

## 5. 首选项与标准

| 命令 | 路径 | 作用 |
| :--- | :--- | :--- |
| [CMD:UG_MODELING_SHEETMTL_PRF] 钣金 | `首选项(P)` → `钣金(H)...` | 经典钣金默认（厚度/半径/止裂） |
| [CMD:UG_SMD_GENERAL_PREFERENCES] 通用钣金设计 | `首选项(P)` → `通用钣金设计(G)...` | NX 钣金全局 |
| [CMD:UG_SMD_FLAT_PATTERN_PREFS] 钣金设计展平图样 | `首选项(P)` → `钣金设计展平图样(F)...` | 展平图样设置 |
| [CMD:UG_SMD_FPA_PREFS] 展平图样注释 | `首选项(P)` → `展平图样注释(L)...` | 展平图注释 |

**必设项**：材料厚度、默认折弯半径（R=T 或 R=1.5T）、K 因子/折弯表、止裂口默认形状。

## 6. 参数合法范围（工程）

| 参数 | 建议 | 越界后果 |
| :--- | :--- | :--- |
| 板厚 T | 0.5–6 mm（常见 1–3） | 过厚无法折弯 |
| 折弯内半径 R | ≥ T（低碳钢 R≈T；不锈钢 1.5T） | R 过小开裂 |
| 折弯角 | 0°–180° | 超过 180° 需特殊工艺 |
| 弯边长度 | ≥ 2T + R | 过短无法成形 |
| 止裂口宽度 | ≥ T | 过窄仍撕裂 |
| 孔边距 | ≥ T（一般 ≥ 2T） | 过近孔变形 |
| 展开 K 因子 | 0.33–0.5（软钢 0.44） | 与模具/材料有关，需实测 |

> K 因子不是 NX 的“软件参数”，是材料/工艺参数。批量生产前用试折件标定。

## 7. 最佳实践

1. 先设 `首选项(P)` → `钣金(H)...` 的厚度/半径/止裂，再建模。
2. 一个零件只用一条钣金命令线（经典或 NX 钣金）。
3. 弯边顺序：先外后内、先大后小；相邻弯边用“拐角”处理。
4. 所有折弯半径用同一值（除非图纸特别要求），便于展开。
5. 孔/槽距折弯线 ≥ 2T+R，避免变形。
6. 展开前 `工具(T)` → `展平图样(T)...` 生成独立展平图样，不要手工“伸直”全部弯边。
7. 展平后校核外形尺寸与孔位；展开图另存 PDF 交付。

## 8. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_MODELING_SMD_*` 22 条、`UG_SBSM_*`、`UG_SMD_*`）。
- 双模块共存为 NX 12 安装实测（`ug_smd.men` 与 `ug_sbsm.men` 同时存在）。
- K 因子/最小弯曲半径数值为钣金工艺经验，需按材料标准与企业试折标定。
