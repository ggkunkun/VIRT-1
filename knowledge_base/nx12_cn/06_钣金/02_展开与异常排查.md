# 06-02 展平图样、折弯计算与异常排查

> 目标：展开尺寸可被激光/折弯机直接使用。NX 只负责几何展开，**K 因子/折弯表必须由工艺标定**。

## 1. 展平图样（Flat Pattern）

[CMD:UG_SMD_CREATE_FLAT_PATTERN] 展平图样：`工具(T)` → `展平图样(T)...`

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 要展平的实体 | 钣金件 | 选实体 |
| 折弯展开方式 | K 因子/折弯表/中性层 | 批量生产用折弯表 |
| 输出 | 新部件/当前部件 | 新部件（保留 3D） |
| 注释 | 折弯线/方向/角度 | 勾选，便于折弯 |
| 展平图样注释 | [CMD:UG_SMD_CREATE_FPA] 展平图样注释(N) | 标注折弯信息 |

**SOP**：
1. 确认 3D 钣金件所有弯边/折弯都是钣金特征（不是普通实体）；
2. `工具(T)` → `展平图样(T)...`；
3. 选实体 → 设 K 因子/折弯表；
4. 生成到新部件；
5. 在展平图样上标注外形/孔位/折弯线；
6. 检查 `信息(I)` → `展平图样(L)...` 的尺寸。

## 2. 折弯展开计算（可手算复核）

### 2.1 公式

- 弯曲半径 R（内半径）、板厚 T、弯曲角 θ（度）、中性层系数 K。
- 弯曲 allowance：`BA = π · (R + K·T) · θ / 180`
- 弯曲 deduction：`BD = 2 · (R + T) · tan(θ/2) − BA`
- 展开长度：`L_flat = Σ 外形容边长度 − Σ BD`

### 2.2 示例（T=2，R=2，θ=90°，K=0.44）

```
BA = π × (2 + 0.44×2) × 90/180 = π × 2.88 / 2 = 4.524 mm
BD = 2 × (2+2) × tan45° − 4.524 = 8 − 4.524 = 3.476 mm
若两边各 30 mm：L_flat = 30 + 30 − 3.476 = 56.524 mm
```

### 2.3 K 因子参考（必须试折标定）

| 材料 | 推荐 K | 说明 |
| :--- | :--- | :--- |
| 低碳钢（Q235/SPCC） | 0.40–0.45 | 常用 0.44 |
| 不锈钢（304） | 0.45–0.50 | 回弹大 |
| 铝（5052/6061） | 0.38–0.45 | 6061 易裂，R 取大 |
| 镀锌板 | 0.42–0.46 | 镀层影响 |

> NX 的“折弯表”可导入企业实测数据；没有实测就用 K=0.44 起步，首件试折后修正。

## 3. 钣金标准检查

| 命令 | 路径 | 作用 |
| :--- | :--- | :--- |
| [CMD:UG_SMD_INFO_FEAT_STDS] 检查特征的标准 | `信息(I)` → `检查特征的标准(K)...` | 单特征是否符合钣金标准 |
| [CMD:UG_SMD_INFO_PART_STDS] 检查整个零件的标准 | `信息(I)` → `检查整个零件的标准(N)...` | 全零件检查 |
| [CMD:UG_SMD_INFO_FLAT_PATTERN] 展平图样 | `信息(I)` → `展平图样(L)...` | 展开尺寸信息 |
| [CMD:UG_SMD_PIP] 过程部件 | `工具(T)` → `过程部件(O)...` | 工序件管理 |

## 4. 展平图出图（GB）

1. 展平图样在新部件中生成后，`应用模块(N)` → `制图(D)`；
2. 用 `GB_A3`/`GB_A4` 模板建图纸页；
3. 放展平视图（基本视图 → 展平图样部件）；
4. 标注外形、孔位、折弯线（用中心线/注释）；
5. 技术要求写：材料、板厚、K 因子/折弯表、去毛刺、表面处理；
6. 输出 PDF/DXF 给激光切割。

## 5. 异常排查（每条 ≥3 步）

### 5.1 无法展开

1. 检查弯边/折弯是否为钣金特征：普通拉伸的折弯无法展开；
2. `信息(I)` → `检查特征的标准(K)...` 看哪个特征不合格；
3. 检查是否有非可展曲面（冲压成形面需用“成形/展开”单独处理）。

**修复**：把普通实体折弯改为钣金折弯特征；成形面用 `成形/展开(U)...`。

### 5.2 展开尺寸与手算不符

1. `首选项(P)` → `钣金设计展平图样(F)...` 看 K 因子/折弯表；
2. 用 §2 公式手算一个 90° 弯对比；
3. 检查是否有多个折弯叠加（BD 要逐弯累减）。

**修复**：统一 K 因子/折弯表 → 重新展平 → 首件试折验证。
**预防**：K 因子由工艺文件规定，不由设计随手改。

### 5.3 弯边失败

1. 检查所选边是否连续直边；
2. 检查相邻弯边是否干涉（先做拐角/止裂）；
3. 检查弯边长度是否 ≥ 2T+R。

**修复**：换边 → 加止裂口 → 缩短/加长弯边 → 用“轮廓弯边”替代。

### 5.4 止裂口缺失、折弯撕裂

1. 双击弯边特征，看“止裂口”是否为“无”；
2. `插入(S)` → `钣金特征(H)` → `止裂口(L)...` 补加；
3. 检查止裂口宽度是否 ≥ T。

**修复**：设矩形/圆形止裂口 → 重新展平。

### 5.5 展平图样为空

1. 检查是否选对实体（装配中可能选了顶层）；
2. 检查是否有钣金特征（普通实体无展开）；
3. 看“过程部件/工序件”是否抑制了展开。

**修复**：设工作部件为钣金件 → 选实体 → 重新展平。

### 5.6 展开图与 3D 不一致

1. `工具(T)` → `更新(U)` → `全部更新(U)`；
2. 检查 3D 是否被修改但展平图样未重建；
3. 删除旧展平图样，重新生成。

**修复**：展平图样是“快照”，3D 改了必须重生成。

### 5.7 拐角处理失败

1. 看两弯边是否相交/重叠；
2. `插入(S)` → `钣金特征(H)` → `拐角(O)...` 选两弯边；
3. 试“封闭/止裂/重叠”三种处理。

**修复**：改止裂形状 → 调整弯边长度 → 用“桥接”过渡。

### 5.8 冲压/成形无法展开

1. 成形特征本身不是折弯，不能用普通展平；
2. `插入(S)` → `钣金特征(H)` → `成形/展开(U)...` 单独展开；
3. 若仍失败，检查成形工具面是否可展。

**修复**：用成形/展开 → 或把成形区域简化为折弯。

### 5.9 导入钣金件无法展开

1. 导入件多为普通实体，没有钣金特征；
2. 用 `插入(S)` → `钣金特征(H)` 的“折弯”重新识别折弯；
3. 或按中性层手工计算展开。

**修复**：重建钣金特征 → 或按 §2 手算展开。

## 6. 最佳实践

1. 3D 与展平图样同名不同后缀：`-3D.prt` / `-FLAT.prt`。
2. 展平图样只用于下料，不用于折弯定位；折弯定位用折弯线/挡指线。
3. 每批首件试折，实测回弹后修 K 因子。
4. 折弯半径统一，减少模具换型。
5. 展开图输出 DXF 时检查图层/单位（mm）。

## 7. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_SMD_*`、`UG_MODELING_SMD_*`）。
- 公式为钣金通用计算；K 因子为材料/工艺参数，必须实测标定。
- 展平图样命令路径实测：`工具(T)` → `展平图样(T)...`。
