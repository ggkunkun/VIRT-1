# 08-02 工序创建与刀轨生成

> 适用：NX 12.0 中文版 CAM。工序子类型中文名取自官方 NLM 语言包实测：
> 型腔铣、平面铣、面铣、深度轮廓铣、固定轮廓铣、可变轮廓铣、钻孔、定心钻、孔铣、螺纹铣、轮廓铣、自适应铣削。

## 1. 创建工序的标准路径

1. `插入(S)` → `工序(E)...`（`UG_CAM_INSERT_OPERATION`）；
2. 选工序子类型（按加工阶段）；
3. 指定程序/刀具/几何体/方法；
4. 设切削参数；
5. `生成` 刀轨；
6. `确认刀轨` 仿真；
7. 检查 `!` 清零。

## 2. 常用工序子类型与适用

| 工序（中文） | 适用 | 关键参数 |
| :--- | :--- | :--- |
| 型腔铣（Cavity Mill） | 粗加工型腔/台阶 | 切削模式、步距、每刀深度、余量 |
| 平面铣（Planar Mill） | 2.5 轴轮廓/平面 | 边界、底平面、步距 |
| 面铣（Face Milling） | 铣平面/顶面 | 面区域、切削模式、步距 |
| 深度轮廓铣（Zlevel Profile） | 陡峭侧壁半精/精 | 每刀深度、陡峭角、合并距离 |
| 固定轮廓铣（Fixed Contour） | 曲面精加工（3 轴） | 驱动方法、投影矢量、步距 |
| 可变轮廓铣（Variable Contour） | 5 轴曲面 | 刀轴、驱动方法 |
| 钻孔（Drilling） | 钻孔/铰孔/攻丝 | 循环类型、深度、R 平面 |
| 定心钻（Spot Drilling） | 定心 | 深度、直径 |
| 孔铣（Hole Milling） | 大孔/螺旋铣 | 直径、螺距 |
| 螺纹铣（Thread Milling） | 螺纹 | 螺距、直径 |
| 轮廓铣（Contour Milling） | 外形轮廓 | 边界、刀补 |
| 自适应铣削（Adaptive Milling） | 高效粗加工 | 步距、切削深度、保持恒定切削载荷 |

## 3. 型腔铣（最常用粗加工）

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 切削模式 | 跟随部件/跟随周边/配置文件/往复 | 跟随部件（少空刀） |
| 步距 | 刀具直径百分比或常数 | 粗加工 50%–75% D |
| 每刀切削深度 | 分层深度 | ≤ 刀具直径的 50%（钢）；铝可 100% |
| 余量 | 侧/底余量 | 粗 0.3–0.8 mm |
| 进刀方式 | 螺旋/斜线/垂直 | 螺旋（封闭型腔） |
| 退刀 | 抬刀 | 安全高度 |
| 切削顺序 | 深度优先/层优先 | 深腔“深度优先” |
| 检查体 | 夹具/压板 | 必选，防撞 |

**SOP**：选工序 → 指定 WORKPIECE → 选切削区域 → 设模式/步距/深度/余量 → 生成 → 确认。

## 4. 平面铣与面铣

### 4.1 平面铣

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 边界 | 部件边界/毛坯边界 | 选封闭轮廓 |
| 底平面 | 加工深度 | 选面或输入 Z |
| 切削模式 | 往复/单向/轮廓 | 往复（效率） |
| 步距 | 常数/百分比 | 60%–75% D |
| 刀补 | 开/关 | 精加工开（G41/G42） |

### 4.2 面铣

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 面区域 | 要铣的面 | 框选平面 |
| 切削模式 | 往复/单向/跟随 | 往复 |
| 步距 | 75% D | 大直径面铣刀 |
| 余量 | 0（精） | — |

## 5. 深度轮廓铣与固定轮廓铣

### 5.1 深度轮廓铣

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 每刀深度 | 层高 | 0.2–0.5 mm（精） |
| 陡峭角 | 只加工陡峭区 | 65° |
| 合并距离 | 小平面合并 | 0.1–0.5 mm |
| 余量 | 侧/底 | 0（精） |

### 5.2 固定轮廓铣

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 驱动方法 | 曲线/点、曲面区域、区域铣削 | 区域铣削（常用） |
| 投影矢量 | 刀轴/指定矢量 | 刀轴 |
| 步距 | 残余高度/常数 | 残余高度 0.01 mm |
| 切削方向 | 顺铣/逆铣 | 顺铣（精） |

## 6. 钻孔

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 循环类型 | 标准钻/啄钻/断屑/攻丝 | 深孔啄钻 |
| 深度 | 通孔/盲孔 | 通孔 = 板厚 + 2–3 mm |
| R 平面 | 退刀平面 | 工件上方 2–5 mm |
| 安全高度 | 初始平面 | 工件上方 10–20 mm |
| 进给 | mm/min | 按材料/钻头 |

**SOP**：选钻孔工序 → 选孔（特征/点）→ 设循环/深度 → 生成 → 确认。

## 7. 刀轨生成与确认

| 操作 | 路径 | 判据 |
| :--- | :--- | :--- |
| 生成 | `工具(T)` → `工序导航器(O)` → `刀轨(L)` → `生成(G)` | 刀轨出现，无报错 |
| 确认 | `刀轨(L)` → `确认(V)...` | 无过切/无碰撞 |
| 重播 | `刀轨(L)` → `重播` | 刀路连续 |
| 列出 | `刀轨(L)` → `列出` | 文本坐标合理 |
| 最小刀具长度 | `刀轨(L)` → `最小刀具长度(M)...` | 夹持不撞 |
| 优化进给率 | `刀轨(L)` → `优化进给率(Z)...` | 负载均匀 |

## 8. 参数合法范围与失败边界

| 参数 | 合法范围 | 失败表现 | 处理 |
| :--- | :--- | :--- | :--- |
| 步距 | > 0 | 空刀/漏切 | 50%–75% D |
| 每刀深度 | > 0 且 ≤ 刃长 | 断刀/让刀 | 按刀具样本 |
| 余量 | ≥ 0 | 过切 | 粗 0.3–0.8 |
| 进给 | > 0 | 报警 | 按公式计算 |
| 主轴转速 | > 0 | 报警 | 按 Vc 计算 |
| R 平面 | 高于工件 | 撞刀 | 2–5 mm |
| 安全高度 | 高于夹具 | 撞夹具 | 10–20 mm |

## 9. 最佳实践

1. 粗加工用“型腔铣/自适应铣削”；精加工用“深度轮廓铣/固定轮廓铣”。
2. 顺铣用于精加工，逆铣用于粗加工（有硬皮时）。
3. 每道工序单独建程序组，方便重排。
4. 刀轨生成后必须 `确认刀轨`，重点看快速移动（G00）是否撞件。
5. 余量分层：粗 0.5 → 半精 0.2 → 精 0。
6. 刀具编号与机床刀库一致（T01/T02…）。

## 10. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_CAM_*`）。
- 工序中文名：`libcams_simpl_chinese_nlm.txt` 等实测（Cavity Mill=型腔铣、Planar Mill=平面铣、Face Milling=面铣、Zlevel Profile=深度轮廓铣、Fixed Contour=固定轮廓铣、Drilling=钻孔）。
- 切削参数为工程推荐值，需按刀具样本与试切修正。
