# 08-03 后处理、NC 输出与仿真验证

> 适用：NX 12.0 中文版 CAM。后处理 = 把刀轨（CLS）翻译成机床能执行的 G 代码。
> 核心纪律：后处理不是“点一下”，必须核对**机床/系统/单位/坐标系/刀补**五项。

## 1. 后处理入口

| 操作 | 路径 | 命令 |
| :--- | :--- | :--- |
| 后处理 | `工具(T)` → `工序导航器(O)` → `输出(U)` → `后处理(P)...` | `UG_CAM_ONT_OUT_MACHINE_DATA` |
| 安装 NC 后处理器 | `工具(T)` → `安装 NC 后处理器(P)...` | `UG_CAM_INSTALL_POST` |
| 后处理配置器 | `工具(T)` → `后处理配置器(R)...` | `UG_CAM_START_POST_CONFIGURATOR` |
| 机床库 | `工具(T)` → `机床库(M)...` | `UG_CAM_DIALOG_MACHINE_LIB` |

**SOP**：
1. 在工序导航器选中要输出的工序/程序组；
2. `后处理(P)...`；
3. 选后处理器（如 `fanuc_0i`、`siemens_840d`、`heidenhain_iTNC`）；
4. 设输出文件路径/文件名（`.nc`/`.mpf`/`.h`）；
5. 勾选“列出输出”先看文本；
6. 确定生成 NC。

## 2. 后处理五核对（缺一不可）

| # | 核对项 | 判据 | 错误后果 |
| :--- | :--- | :--- | :--- |
| 1 | 机床/系统 | 后处理器与机床一致（FANUC/Siemens/Heidenhain） | 代码不识别 |
| 2 | 单位 | mm（G21）或 inch（G20） | 尺寸差 25.4 倍 |
| 3 | 坐标系 | G54/G55 与机床一致 | 撞件/偏移 |
| 4 | 刀具号/刀补 | Txx / G41/G42 / Dxx | 撞刀/过切 |
| 5 | 程序头/尾 | 安全启动/回零/M30 | 无法开机/撞机 |

**判据**：NC 文件头必须有单位、坐标系、刀具号、主轴/进给模式（G90/G94）；尾必须有 M30/M02。

## 3. 后处理器结构与定制

| 文件 | 位置 | 作用 |
| :--- | :--- | :--- |
| `template_post.dat` | `MACH/resource/postprocessor/` | 后处理器注册表（NX 下拉列表） |
| `*.def` | `MACH/resource/postprocessor/def/` | 事件处理定义（G 代码映射） |
| `*.tcl` | `MACH/resource/postprocessor/` | 输出逻辑（Tcl 脚本） |
| Post Builder | `开始菜单` → `Post Builder` | 图形化定制后处理 |

**定制纪律**：
1. 复制一份原生后处理再改，不覆盖安装文件；
2. 改 `.def/.tcl` 后必须在 `template_post.dat` 注册；
3. 每次改完用一段已知程序回归（直线/圆弧/钻孔/攻丝）；
4. 版本升级后重新验证（后处理不跨版本通用）。

## 4. 刀轨仿真与碰撞检查

| 检查 | 路径 | 判据 |
| :--- | :--- | :--- |
| 确认刀轨 | `工具(T)` → `工序导航器(O)` → `刀轨(L)` → `确认(V)...` | 无过切/无撞刀 |
| 3D 动态 | 确认刀轨 → `3D 动态` | 看材料去除 |
| 2D 动态 | 确认刀轨 → `2D 动态` | 看刀路轨迹 |
| 最小刀具长度 | `刀轨(L)` → `最小刀具长度(M)...` | 夹持不撞 |
| 机床仿真 | 加工模块内 `机床仿真` | 整机（含夹具）碰撞 |
| 过切检查 | 工序 → `过切检查` | 过切量 = 0 |

## 5. 导出到外部仿真（VERICUT）

| 步 | 操作 | 输出 |
| :--- | :--- | :--- |
| 1 | 后处理生成 `.nc` | G 代码 |
| 2 | 导出毛坯/模型（STEP/STL） | 仿真用几何 |
| 3 | VERICUT 新建项目 → 配机床/刀具/毛坯 | 仿真环境 |
| 4 | 运行 → Auto-Diff | 颜色偏差图 |
| 5 | 判定 | 红=过切（致命）；蓝=残料（补半精）；绿=合格 |

> Auto-Diff 判据（AGENTS.md §2E）：红=过切必须停机修刀路；蓝=残料加半精；空白/未渲染图不得判合格。

## 6. NC 程序结构检查清单

| 段 | 必含 | 示例 |
| :--- | :--- | :--- |
| 程序头 | 单位、绝对/增量、坐标系、刀具、主轴、冷却 | `G21 G90 G54 T01 M06 S3000 M03 M08` |
| 加工段 | 快速定位、进刀、切削、退刀 | `G00 Z50; G01 Z-2 F200` |
| 圆弧 | G2/G3 + I/J/K 或 R | `G03 X.. Y.. I.. J..` |
| 刀补 | G41/G42 + D | `G41 D01` |
| 程序尾 | 抬刀、关主轴/冷却、回零、M30 | `G00 Z100; M05; M09; M30` |

## 7. 参数与格式

| 项 | 建议 | 说明 |
| :--- | :--- | :--- |
| 单位 | G21（mm） | 与模型一致 |
| 坐标 | G90 绝对 | 少用 G91 |
| 进给模式 | G94（mm/min） | 铣削常用 |
| 圆弧 | G2/G3 + IJK | 避免小线段 |
| 程序号 | O0001 起 | 与机床习惯一致 |
| 行号 | 可选 N10 递增 | 便于查错 |
| 冷却 | M08/M09 | 按工艺 |

## 8. 最佳实践

1. 一台机床一个后处理器，命名 `厂家_系统_行程`。
2. 后处理前先 `确认刀轨`；不要用后处理代替仿真。
3. 首件必须空运行（机床锁住/抬高 Z）验证。
4. NC 文件与 3D/图纸同项目目录，文件名含图号+工序号。
5. 后处理改动留版本记录；每次改动跑回归。
6. 外部仿真（VERICUT）报告与 NC 一起归档。

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_CAM_ONT_OUT_MACHINE_DATA` 等）。
- 后处理器目录：`MACH/resource/postprocessor/`（实测存在 `template_post.dat`）。
- VERICUT 判据引自 AGENTS.md §2E（红/蓝/绿门）。
