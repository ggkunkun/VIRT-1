# 08-01 加工环境与工序导航器

> 适用：NX 12.0 中文版 CAM。进入 `应用模块(N)` → `加工(M)` 后，资源条出现 `工序导航器`。
> 本文件覆盖：加工环境、工序导航器四视图、程序/刀具/几何体/方法、MCS 与 WORKPIECE。

## 1. 进入加工与初始化

1. 打开零件/装配；
2. `应用模块(N)` → `加工(M)`；
3. 首次进入弹出“加工环境”对话框：选 `cam_general`（通用）或 `mill_planar`/`mill_contour`（铣削模板）；
4. 确定后进入加工模块，资源条显示 `工序导航器`。

> 模板选错会导致“创建工序”里没有你要的工序子类型；换模板可重新进入加工环境。

## 2. 工序导航器（四视图）

| 视图 | 命令/图标 | 作用 |
| :--- | :--- | :--- |
| 程序顺序视图 | `工具(T)` → `工序导航器(O)` → `视图(V)` → `程序顺序视图(P)` | 按加工顺序看工序 |
| 机床视图 | 同上 → `机床视图(O)` | 看刀具/机床 |
| 几何体视图 | 同上 → `几何体视图(G)` | 看 MCS/WORKPIECE/切削区域 |
| 加工方法视图 | 同上 → `加工方法视图(M)` | 看粗/半精/精加工方法 |

**判据**：工序导航器节点前有 `!` 感叹号 = 参数不完整/未生成刀轨；导出前必须清零（AGENTS.md §2.C 公理）。

## 3. 创建加工对象（五大件）

| 对象 | 命令 | 路径 | 说明 |
| :--- | :--- | :--- | :--- |
| 程序 | [CMD:UG_CAM_INSERT_PROGRAM] 程序 | `插入(S)` → `程序(P)...` | 工序分组（如 PROG_ROUGH） |
| 刀具 | [CMD:UG_CAM_INSERT_TOOL] 刀具 | `插入(S)` → `刀具(T)...` | 铣刀/钻头/丝锥 |
| 几何体 | [CMD:UG_CAM_INSERT_GEOMETRY] 几何体 | `插入(S)` → `几何体(G)...` | MCS/WORKPIECE/切削区域 |
| 方法 | [CMD:UG_CAM_INSERT_METHOD] 方法 | `插入(S)` → `方法(M)...` | 粗/半精/精加工余量与进给 |
| 工序 | [CMD:UG_CAM_INSERT_OPERATION] 工序 | `插入(S)` → `工序(E)...` | 具体刀轨 |

**顺序**：程序 → 刀具 → 几何体 → 方法 → 工序。

## 4. 加工坐标系（MCS）与工件（WORKPIECE）

### 4.1 MCS

- 路径：`插入(S)` → `几何体(G)...` → 类型 `MCS`；
- 参数：原点、Z 轴（刀轴）、安全高度；
- **规则**：MCS 的 Z 轴 = 机床主轴方向；原点通常放工件顶面中心或角点。

### 4.2 WORKPIECE

- 路径：`插入(S)` → `几何体(G)...` → 类型 `WORKPIECE`；
- 指定：部件（成品）、毛坯（Stock）、检查体（夹具）；
- 毛坯来源：`包容块`/`圆柱`/`偏置`/`实体`。

### 4.3 切削区域

- 在工序内指定：切削区域（面/体）、修剪边界、检查边界；
- 判据：切削区域必须完全在毛坯内，否则空刀。

## 5. 刀具参数（铣刀）

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 刀具类型 | 端铣刀/球头刀/圆鼻刀/钻头/丝锥 | 按工序 |
| 直径 D | 刀具直径 | 粗加工大直径，精加工小直径 |
| 下半径 R | 圆鼻刀刀尖圆角 | 0（平刀）/D/2（球刀） |
| 长度/刃长 | 刀具总长/切削刃长 | 刃长 ≥ 切深 |
| 刀刃数 z | 齿数 | 钢 4–6，铝 2–3 |
| 材料 | 高速钢/硬质合金/涂层 | 按工件材料 |

## 6. 切削参数计算（可复核）

### 6.1 主轴转速

```
n = 1000 · Vc / (π · D)
```
- n：rpm；Vc：切削速度 m/min；D：刀具直径 mm。

### 6.2 进给速度

```
F = n · fz · z
```
- F：mm/min；fz：每齿进给 mm/z；z：齿数。

### 6.3 参考切削速度（工程值）

| 工件材料 | 高速钢 Vc | 硬质合金 Vc |
| :--- | :--- | :--- |
| 45 钢 | 20–30 | 80–150 |
| 铝合金 | 60–100 | 200–500 |
| 不锈钢 | 15–25 | 50–90 |
| 铸铁 | 15–25 | 60–120 |

**示例**：Ø10 硬质合金立铣刀铣 45 钢，Vc=100 → n=1000×100/(π×10)=3183 rpm；z=4，fz=0.05 → F=3183×0.05×4=637 mm/min。

> 以上为起点值；实际以刀具样本/机床刚性/冷却为准。

## 7. 加工方法（粗/半精/精）

| 方法 | 余量 | 进给 | 用途 |
| :--- | :--- | :--- | :--- |
| 粗加工 | 0.3–1.0 mm | 大 | 去大部分材料 |
| 半精加工 | 0.1–0.3 mm | 中 | 均匀余量 |
| 精加工 | 0 | 小 | 达到尺寸/表面 |

路径：`插入(S)` → `方法(M)...`；工序里继承方法参数，可单独覆盖。

## 8. 工序导航器操作

| 操作 | 路径 | 说明 |
| :--- | :--- | :--- |
| 生成刀轨 | `工具(T)` → `工序导航器(O)` → `刀轨(L)` → `生成(G)`（`UG_CAM_ONT_TP_GENERATE`） | 选工序后生成 |
| 确认刀轨 | `刀轨(L)` → `确认(V)...`（`UG_CAM_ONT_TP_VERIFY`） | 2D/3D 仿真 |
| 重播刀轨 | `刀轨(L)` → `重播` | 看刀路 |
| 列出刀轨 | `刀轨(L)` → `列出` | 文本刀轨 |
| 进给率 | `对象(J)` → `进给率(F)...`（`UG_CAM_ONT_FEEDRATES`） | 改 F/S |
| 后处理 | `输出(U)` → `后处理(P)...`（`UG_CAM_ONT_OUT_MACHINE_DATA`） | 输出 NC |
| 机床仿真 | `应用模块` 内 `机床仿真`（`UG_APPCAM_SIMULATE_TASK_ENV`） | 整机仿真 |

## 9. 最佳实践

1. 先建 MCS/WORKPIECE，再建工序；顺序反了要重挂几何体。
2. 刀具库用企业标准刀柄/刀具，避免每次手输。
3. 粗加工用大直径圆鼻刀，精加工用小直径球刀。
4. 每道工序生成后立即 `确认刀轨`，不要等全部编完再查。
5. 工序命名：`OP010_粗铣顶面`、`OP020_精铣轮廓`。
6. 导出前检查工序导航器 `!` 清零。

## 10. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_CAM_*`、`UG_APPCAM_*`）。
- 切削公式为机械加工通用公式；Vc/fz 为工程推荐值。
- 工序子类型中文名（型腔铣/平面铣/深度轮廓铣等）来自 `LOCALIZATION/translations/simpl_chinese/libcams*_nlm.txt` 实测。
