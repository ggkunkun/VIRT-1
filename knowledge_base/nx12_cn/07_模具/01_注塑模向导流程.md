# 07-01 注塑模向导（Mold Wizard）标准流程

> 适用：NX 12.0 中文版，`工具(T)` → `特定于工艺(O)` → `注塑模向导(M)`。
> 本机安装含 `MOLDWIZARD` 模块与 GB 标准件库；命令路径全部实测。

## 1. 完整流程（13 步）

| 步 | 操作 | 命令路径 | 关键参数 |
| :--- | :--- | :--- | :--- |
| 1 | 初始化项目 | `工具(T)` → `特定于工艺(O)` → `注塑模向导(M)` → `初始化项目(Z)...`（`UGMOLD_LOAD`） | 项目路径、材料、收缩率 |
| 2 | 模具坐标系 | 同上 → `模具坐标系(Y)...`（`UGMOLD_WCS`） | Z 轴 = 开模方向；原点在分型面 |
| 3 | 收缩 | 同上 → `收缩(H)...`（`UGMOLD_SCALE`） | 收缩率（见 §2） |
| 4 | 工件 | 同上 → `工件(C)...`（`UGMOLD_INSERT_BOX`） | 产品+余量（20–50 mm） |
| 5 | 型腔布局 | 同上 → `型腔布局(L)...`（`UGMOLD_CENTER`） | 1×1/1×2/2×2；间距 |
| 6 | 分型 | 同上 → `分型工具(R)` → `检查区域/定义区域/设计分型面/定义型腔和型芯` | 详见 07-02 |
| 7 | 模架库 | 同上 → `模架库(S)...`（`UGMOLD_MOLDBASE`） | 龙记/GB 标准；A/B 板厚 |
| 8 | 标准件 | 同上 → `标准件库(A)...`（`UGMOLD_STANDARD_PART`） | 螺钉/销/弹簧 |
| 9 | 浇注系统 | 同上 → `设计填充(G)...` / `流道(U)...` | 浇口位置/流道直径 |
| 10 | 冷却系统 | 同上 → `冷却工具(O)` → `直接水路/定义水路/连接水路/冷却标准件库` | 水路直径/间距 |
| 11 | 顶出系统 | 同上 → `设计顶杆(E)...` / `顶杆后处理(J)...` | 顶杆直径/位置 |
| 12 | 滑块/斜顶 | 同上 → `滑块和浮升销库(D)...` | 侧抽芯 |
| 13 | 校核/出图/BOM | `模具设计验证(V)`、`模具图纸工具(W)`、`物料清单(B)...` | 干涉/图纸/清单 |

## 2. 关键参数与取值

### 2.1 收缩率（工程推荐）

| 材料 | 收缩率 % | 说明 |
| :--- | :--- | :--- |
| ABS | 0.4–0.7 | 常用 0.5 |
| PP | 1.0–2.5 | 常用 1.5–2.0 |
| PE | 1.5–3.0 | 高密度取大 |
| PC | 0.5–0.8 | 常用 0.6 |
| PA6/PA66 | 1.0–2.5 | 吸湿，需干燥 |
| POM | 1.8–2.5 | 常用 2.0 |
| PMMA | 0.3–0.8 | 常用 0.5 |

> 收缩率是材料+工艺参数，必须按材料供应商数据与试模修正；NX 只按输入值放大。

### 2.2 工件与布局

| 参数 | 推荐 | 说明 |
| :--- | :--- | :--- |
| 工件余量 | 产品每侧 +20～50 mm | 给模架/冷却/顶出留空间 |
| 型腔间距 | ≥ 30–50 mm | 按模架与冷却 |
| 布局 | 1×1（试模）/1×2/2×2 | 按产量与锁模力 |
| 分型面公差 | 0.01–0.05 mm | 分型面缝合精度 |

### 2.3 浇注/冷却/顶出

| 项 | 推荐 | 说明 |
| :--- | :--- | :--- |
| 浇口直径 | 0.8–2.0 mm（点浇口） | 按产品壁厚 |
| 主流道锥度 | 2°–4° | 便于脱模 |
| 冷却水路直径 | Ø8–Ø12 | 常用 Ø10 |
| 水路距型腔 | 15–25 mm | 均匀冷却 |
| 顶杆直径 | Ø2–Ø12 | 按顶出力 |
| 顶杆距型芯边 | ≥ 2 mm | 防裂 |

## 3. 初始化项目（第 1 步细节）

[CMD:UGMOLD_LOAD] 初始化项目：`工具(T)` → `特定于工艺(O)` → `注塑模向导(M)` → `初始化项目(Z)...`

| 参数 | 说明 |
| :--- | :--- |
| 项目路径 | 非中文、无空格；独立目录 |
| 产品模型 | 已拔模的 .prt |
| 材料 | 从库选（影响收缩默认） |
| 收缩率 | 可改；后续 `收缩(H)` 可再调 |
| 项目名 | 英文/拼音，避免中文路径问题 |

> 初始化会在项目目录生成一整套模具装配文件；**不要手工改名/移动**，否则装配引用断裂。

## 4. 模具坐标系（第 2 步细节）

[CMD:UGMOLD_WCS] 模具坐标系：同菜单 → `模具坐标系(Y)...`

**规则**：
- **Z 轴 = 开模方向**（+Z 为动模/定模分离方向）；
- 原点放在**分型面**上（通常产品底面）；
- XY 与产品主方向对齐。

判据：`视图(V)` → `操作(O)` → `旋转(R)...` 从侧面看，产品应在 Z 轴两侧合理分布。

## 5. 分型前检查（省 80% 返工）

1. 产品**拔模**：所有侧面 1°–3°，无倒扣（倒扣需滑块/斜顶）；
2. **厚度均匀**：壁厚差 < 20%，避免缩痕；
3. **无破面/开放边**：`分析(L)` → `形状(H)` → `曲面连续性(C)...`；
4. **孔/槽已补**：小孔用“实体补片/曲面补片”；
5. **坐标系正确**：Z 开模，原点分型面。

## 6. 模架与标准件

| 项 | 路径 | 说明 |
| :--- | :--- | :--- |
| 模架库 | `模架库(S)...`（`UGMOLD_MOLDBASE`） | 选龙记/GB；A/B/C 板厚按型腔深度 |
| 标准件库 | `标准件库(A)...`（`UGMOLD_STANDARD_PART`） | 螺钉/销/弹簧/定位圈 |
| 滑块和浮升销库 | `滑块和浮升销库(D)...`（`UGMOLD_SLIDER`） | 侧抽芯 |
| 子镶块库 | `子镶块库(I)...`（`UGMOLD_SUBINSERT`） | 局部镶块 |
| 电极库 | `电极库(E)...`（`UGMOLD_ELECTRODE`） | 放电加工电极 |

**判据**：模架板厚 ≥ 型腔深度 + 冷却 + 顶出 + 安全余量（≥ 20 mm）。

## 8. 校核与出图

| 项 | 命令 | 判据 |
| :--- | :--- | :--- |
| 模具设计验证 | `模具设计验证(V)`（`MW_MOLD_DESIGN_VALIDATION`） | 无干涉/无漏补 |
| 静态干涉检查 | `注塑模工具(T)` → `静态干涉检查(I)...`（`MW_INTERFERENCE`） | 干涉体积 = 0 |
| 分型检查 | `注塑模工具(T)` → `分型检查(K)`（`MW_TOOLS_COLOR_CHECK`） | 分型面着色无遗漏 |
| 装配图纸 | `模具图纸工具(W)` → `装配图纸(A)...`（`MW_DR_DRAWING`） | GB 图框 |
| 组件图纸 | `模具图纸工具(W)` → `组件图纸(C)...` | 型腔/型芯图 |
| 物料清单 | `物料清单(B)...`（`UGMOLD_BOM`） | BOM 完整 |

## 9. 最佳实践

1. 产品先做**拔模分析**（`分析(L)` → `形状(H)` → `拔模分析(T)...`）再进 Mold Wizard。
2. 坐标系/收缩定死后再分型；中途改会全链重算。
3. 分型面尽量用“设计分型面”自动生成，再手工修补。
4. 模架/标准件参数化，改产品后重新生成而不是手工改板。
5. 冷却/顶出与模架干涉必须在校核阶段解决，不要留到试模。
6. 项目目录整体打包；不要只拷 .prt。

## 10. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UGMOLD_*`、`MW_*`，共 200+ 条）。

- 收缩率/水路/顶杆数值为工程推荐，需按材料与试模修正。
