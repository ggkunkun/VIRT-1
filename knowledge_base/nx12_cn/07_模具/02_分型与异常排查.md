# 07-02 分型、补片与模具异常排查

> 分型是注塑模设计的核心：把产品表面分成“型腔侧/型芯侧”，再生成分型面与型芯型腔。
> 本文件给分型标准流程、参数与 9 类异常排查。

## 1. 分型标准流程（7 步）

| 步 | 操作 | 命令路径 | 判据 |
| :--- | :--- | :--- | :--- |
| 1 | 检查区域 | `工具(T)` → `特定于工艺(O)` → `注塑模向导(M)` → `分型工具(R)` → `检查区域(R)...`（`MW_PM_TOOLS_REGION_ANALYSIS`） | 产品面着色区分型腔/型芯/未定义 |
| 2 | 定义区域 | `分型工具(R)` → `定义区域(D)...`（`MW_PM_TOOLS_DEFINE_REGIONS`） | 所有面归属明确，无“未定义” |
| 3 | 补片 | `分型工具(R)` → `曲面补片(P)...`（`MW_PM_TOOLS_PATCH_SURFACES`） | 孔/槽/开口全部封闭 |
| 4 | 设计分型面 | `分型工具(R)` → `设计分型面(S)...`（`MW_PM_TOOLS_PARTING_SURFACES`） | 分型面围绕产品一圈，无缺口 |
| 5 | 编辑/修补 | `分型工具(R)` → `编辑分型面和曲面补片(H)...`（`MW_TOOLS_EDIT_PATCH`） | 分型面连续、无自交 |
| 6 | 定义型腔和型芯 | `分型工具(R)` → `定义型腔和型芯(C)...`（`MW_PM_TOOLS_DEFINE_SHEETS`） | 生成型腔体/型芯体 |
| 7 | 分型导航器复核 | `分型工具(R)` → `分型导航器(N)`（`MW_PM_TOOLS_PARTING_NAVIGATOR`） | 节点齐全、无红叉 |

## 2. 检查区域与定义区域

### 2.1 检查区域参数

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 产品体 | 要分型的实体 | 已拔模、已收缩 |
| 脱模方向 | 通常 +Z | 与模具坐标系一致 |
| 计算 | 自动分析面归属 | 先自动，再手工修 |
| 颜色 | 型腔/型芯/未定义 | 默认色即可 |

### 2.2 定义区域

- 自动定义：按脱模方向把面分到型腔/型芯；
- 手工指定：把误判的面（如侧向小面）拖到正确侧；
- **未定义面必须清零**，否则分型面无法闭合。

## 3. 补片（封闭开口）

| 命令 | 路径 | 适用 |
| :--- | :--- | :--- |
| [CMD:MW_TOOLS_SOLID_PATCH] 实体补片 | `注塑模工具(T)` → `实体补片(S)...` | 用实体填开口（简单可靠） |
| [CMD:MW_TOOLS_EDGE_PATCH] 曲面补片 | `注塑模工具(T)` → `曲面补片(F)...` | 用曲面补 |
| [CMD:MW_PM_TOOLS_PATCH_SURFACES] 曲面补片（分型工具） | `分型工具(R)` → `曲面补片(P)...` | 分型流程内补片 |
| [CMD:MW_TOOLS_TRIM_REGION_PATCH] 修剪区域补片 | `注塑模工具(T)` → `修剪区域补片(M)...` | 复杂开口 |
| [CMD:MW_TOOLS_ENLARGE_SURF] 扩大曲面补片 | `注塑模工具(T)` → `扩大曲面补片(N)...` | 扩大现有面补 |
| [CMD:MW_TOOLS_GUIDED_EXTEND] 引导式延伸 | `注塑模工具(T)` → `引导式延伸(G)...` | 延伸面到边界 |
| [CMD:MW_TOOLS_FACE_SPLIT] 拆分面 | `注塑模工具(T)` → `拆分面(A)...` | 把面拆开便于补 |

**判据**：补片后产品应是“封闭实体”；`分析(L)` → `测量(S)...` 体积应为正。

## 4. 设计分型面

[CMD:MW_PM_TOOLS_PARTING_SURFACES] 设计分型面：`分型工具(R)` → `设计分型面(S)...`

| 参数 | 说明 | 推荐 |
| :--- | :--- | :--- |
| 分型线 | 自动/手工 | 先自动，再补 |
| 分型面类型 | 拉伸/扫掠/有界平面/扩大面 | 优先“有界平面/拉伸” |
| 方向 | 垂直于开模方向 | +Z |
| 距离 | 超出工件 | ≥ 工件余量 |
| 缝合公差 | 0.01–0.05 mm | 与产品边缝合 |

**SOP**：选分型线 → 选类型 → 设方向/距离 → 预览 → 修补缺口 → 确定。

## 5. 定义型腔和型芯

[CMD:MW_PM_TOOLS_DEFINE_SHEETS] 定义型腔和型芯：`分型工具(R)` → `定义型腔和型芯(C)...`

| 参数 | 说明 |
| :--- | :--- |
| 区域 | 型腔区域/型芯区域 |
| 工件 | 已建工件体 |
| 补片 | 已补的片体 |
| 分型面 | 已设计分型面 |
| 结果 | 生成型腔体/型芯体 |

**判据**：型腔+型芯体积之和 ≈ 工件体积（允许小误差）；两者无重叠。

## 7. 分型异常排查（每条 ≥3 步）

### 7.1 分型线不闭合

1. `分型导航器(N)` 看红色/断开的边；
2. `检查区域(R)` 看是否有“未定义”面；
3. 用 `拆分面(A)` 把跨界面拆开，再补片。

**修复**：补片 → 重新设计分型面 → 缝合。
**预防**：产品先拔模、去倒扣，再做分型。

### 7.2 分型面生成失败

1. 检查分型线是否完整闭合；
2. 改分型面类型（拉伸→有界平面→扫掠）；
3. 放大缝合公差 0.01→0.05。

**修复**：手工补分型面（`编辑分型面和曲面补片`）。
**预防**：分型线尽量在同一平面/规则曲面上。

### 7.3 型腔/型芯未分出

1. 检查工件是否包住产品；
2. 检查补片是否封闭所有开口；
3. 看分型面是否超出工件边界。

**修复**：加大工件 → 补片 → 重新定义型腔和型芯。

### 7.4 补片失败

1. 检查开口边界是否闭合、是否同一平面；
2. 改用“实体补片”（更稳）；
3. 放大曲面补片公差。

**修复**：实体补片 → 修剪 → 合并。

### 7.5 分型面有破面/缺口

1. `分析(L)` → `形状(H)` → `曲面连续性(C)...` 找缝；
2. `编辑分型面和曲面补片(H)...` 修补；
3. 缝合公差 0.01–0.05。

**修复**：补面 → 缝合 → 检查体积。

### 7.6 检查区域颜色异常（面归属错）

1. 看脱模方向是否设错（应为 +Z）；
2. 手工把面拖到正确区域；
3. 对侧向面/倒扣，标记为“滑块区域”。

**修复**：重设脱模方向 → 手工定义区域。

### 7.7 倒扣/滑块处理

1. `分析(L)` → `形状(H)` → `拔模分析(T)...` 找负角面；
2. 用 `滑块和浮升销库(D)...` 建侧抽芯；
3. 分型时把倒扣面分到滑块区域。

**修复**：滑块/斜顶 → 重新分型。

### 7.8 模架与型腔干涉

1. `模具设计验证(V)`；
2. `注塑模工具(T)` → `静态干涉检查(I)...`；
3. 检查 A/B 板厚、冷却水路、顶杆位置。

**修复**：加厚模板 → 移动水路/顶杆 → 重新装配。

### 7.9 分型后体积不守恒

1. `分析(L)` → `测量(S)...` 测型腔+型芯+产品体积；
2. 检查分型面是否漏面/多面；
3. 检查补片是否重复。

**修复**：删重复补片 → 重新缝合 → 重新定义型腔型芯。

## 8. 最佳实践

1. 分型前把产品做成“可脱模”状态：拔模、倒扣处理、补孔。
2. 分型面优先“平面/规则面”，少用自由曲面。
3. 每次分型后跑 `模具设计验证` + `静态干涉检查`。
4. 分型文件与产品文件分离，产品改版后重新初始化。
5. 保存分型片备份（`备份分型片/补片(B)...`）。

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`MW_PM_TOOLS_*`、`MW_TOOLS_*`）。
- 分型流程与参数为 Mold Wizard 标准做法；具体对话框项以 NX 12 中文界面为准。
