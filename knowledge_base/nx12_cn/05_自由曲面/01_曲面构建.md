# 05-01 自由曲面构建

> 适用：NX 12.0 中文版。曲面命令集中在 `插入(S)` → `曲面(R)` / `网格曲面(M)` / `扫掠(W)`。
> 核心判据：曲面质量看**连续性（G0/G1/G2）**与**边界匹配**，不是“看起来顺”。

## 1. 先理解三个连续性

| 级别 | 含义 | 判据 | 用途 |
| :--- | :--- | :--- | :--- |
| G0 | 位置连续（边重合） | 两端点重合 | 最低要求；缝合后仍可能有棱 |
| G1 | 相切连续 | 接缝处切线方向一致 | 外观件一般要求 |
| G2 | 曲率连续 | 接缝处曲率一致 | 汽车/家电 A 级面 |

检查：`分析(L)` → `形状(H)` → `曲面连续性(C)...`（`UG_INFO_SURFACE_CONTINUITY_ANALYSIS`）。

## 2. 构建曲面的五类方法

| 方法 | 命令 | 路径 | 适用 |
| :--- | :--- | :--- | :--- |
| 扫掠类 | [CMD:UG_MODELING_FF_SWEPT] 扫掠 | `插入(S)` → `扫掠(W)` → `扫掠(S)...` | 截面沿引导线 |
| 网格类 | [CMD:UG_MODELING_FF_CURVE_MESH] 通过曲线网格 | `插入(S)` → `网格曲面(M)` → `通过曲线网格(M)...` | 两组曲线（U/V） |
| 直纹 | [CMD:UG_MODELING_FF_RULED] 直纹 | `插入(S)` → `网格曲面(M)` → `直纹(R)...` | 规则过渡 |
| 艺术曲面 | [CMD:UG_MODELING_FF_STUSRF_NXN] 艺术曲面 | `插入(S)` → `网格曲面(M)` → `艺术曲面(U)...` | 自由造型 |
| 填充 | [CMD:UG_MODELING_FF_FILL_HOLE] 填充曲面 | `插入(S)` → `曲面(R)` → `填充曲面(L)...` | 补洞 |
| N 边 | [CMD:UG_MODELING_FF_NSIDED] N 边曲面 | `插入(S)` → `网格曲面(M)` → `N 边曲面` | 封闭区域 |
| 四点曲面 | [CMD:UG_MODELING_FF_SURF4P] 四点曲面 | `插入(S)` → `曲面(R)` → `四点曲面(F)...` | 简单过渡 |
| 截面曲面 | [CMD:UG_MODELING_FF_SECTION] 截面曲面 | `插入(S)` → `扫掠(W)` → `截面(E)...` | 截面过渡 |

## 3. 扫掠（Swept）

[CMD:UG_MODELING_FF_SWEPT] 扫掠：`插入(S)` → `扫掠(W)` → `扫掠(S)...`

| 参数 | 说明 | 合法/推荐 |
| :--- | :--- | :--- |
| 截面 | 1 条或多条曲线 | 截面必须与引导线相交 |
| 引导线 | 1–3 条 | 引导线不能自交 |
| 脊线 | 可选，控制截面方位 | 复杂扫掠时用 |
| 截面方位 | 固定/恒定/另一曲线/面法向 | 一般“恒定” |
| 缩放 | 恒定/另一曲线/面积规律 | 变截面用“另一曲线” |
| 对齐 | 参数/弧长/点 | 截面节点不匹配时用“弧长” |

**SOP**：选截面 → 选引导线 → 设方位/缩放 → 预览 → 检查扭曲 → 确定。

## 4. 通过曲线网格（Through Curve Mesh）

[CMD:UG_MODELING_FF_CURVE_MESH] 通过曲线网格：`插入(S)` → `网格曲面(M)` → `通过曲线网格(M)...`

| 参数 | 说明 | 要求 |
| :--- | :--- | :--- |
| 主曲线（U） | 一组截面曲线 | 至少 2 条；顺序一致 |
| 交叉曲线（V） | 另一组曲线 | 至少 2 条；与主曲线相交 |
| 连续性 | G0/G1/G2 | 与相邻面匹配时设 |
| 强调 | 主曲线/交叉曲线 | 影响面片走向 |
| 交点公差 | 0.001–0.1 mm | 曲线未相交时放大 |

**SOP**：主曲线按顺序选 → 交叉曲线按顺序选 → 设连续性 → 预览网格 → 确定。
**常见失败**：曲线方向不一致（用“反向”）、曲线不相交（调公差/修曲线）。

## 5. 直纹、艺术曲面、N 边曲面

| 命令 | 参数 | 适用 |
| :--- | :--- | :--- |
| [CMD:UG_MODELING_FF_RULED] 直纹 | 两条截面线；对齐方式 | 规则过渡（圆锥/圆柱面） |
| [CMD:UG_MODELING_FF_STUSRF_NXN] 艺术曲面 | 主/交叉曲线；连续性 | 自由造型，G1/G2 控制强 |
| [CMD:UG_MODELING_FF_NSIDED] N 边曲面 | 边界曲线（≥3）；修剪/不修剪 | 补洞，边界可 G0/G1 |
| [CMD:UG_MODELING_FF_FILL_HOLE] 填充曲面 | 边界、控制点、连续性 | 补面/修补破面 |
| [CMD:UG_MODELING_FF_FIT_SURFACE] 拟合曲面 | 点云/小平面体 | 逆向工程 |

## 6. 曲线质量决定曲面质量

| 检查 | 命令 | 判据 |
| :--- | :--- | :--- |
| 曲线光顺 | `分析(L)` → `曲线(C)` → `曲率梳` | 曲率梳无突变/无拐点 |
| 曲线连续性 | `分析(L)` → `曲线(C)` → `曲线连续性` | 接缝 G1/G2 |
| 曲线方向 | 显示箭头 | 同组曲线方向一致 |
| 曲线交点 | `分析(L)` → `测量(S)...` | 交点误差 < 公差 |

> 曲面失败 80% 是曲线问题：断点、方向反、曲率突变。先修线，再铺面。

## 7. 参数合法范围

| 参数 | 合法范围 | 失败表现 | 处理 |
| :--- | :--- | :--- | :--- |
| 交点公差 | 0.0001–1 mm | “曲线不相交” | 放大公差或修曲线 |
| 连续性 | G0/G1/G2 | 匹配边失败 | 先匹配边再设 G1/G2 |
| 扫掠引导线 | 1–3 条 | 扭曲/自交 | 减少引导线/加脊线 |
| 网格主/交叉曲线 | ≥2 | 无法成面 | 补曲线 |
| N 边边界 | ≥3 条 | 边界不闭合 | 修剪/补线 |
| 加厚厚度 | >0 且 < 曲率半径 | 自交 | 减小厚度/分割面 |

## 8. 最佳实践

1. **先建线框，再铺面**；线框用基准面/草图约束，别随手画 3D 曲线。
2. 曲面分片要“少而大”：能一张面解决，不要切成五片。
3. 相邻面先做 G0 缝合，再逐步匹配到 G1/G2；不要一上来就 G2。
4. 曲面命名：`SF_顶面`、`SF_过渡`；放入独立图层。
5. 每次铺面后 `分析(L)` → `形状(H)` → `曲面连续性(C)...` 检查。
6. 最终交付前 `缝合` + `加厚` 成实体，用体积/壁厚复核。

## 9. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_MODELING_FF_*`）。
- 连续性定义与判据为几何通用知识；NX 检查命令已实测可用。
