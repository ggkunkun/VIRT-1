> 曲面问题先查“线”，再查“面”，最后查“缝合/加厚”。每条 ≥3 步，带 NX 12.0 中文路径。

## 1. 扫掠扭曲、打结

**排查**：
1. 检查截面曲线方向：同组截面箭头必须同向；用“反向”统一。
2. 检查引导线是否自交/急转；`分析(L)` → `曲线(C)` → `曲率梳` 看突变。
3. 改“截面方位”为“恒定”或加“脊线”控制。

**修复**：统一下截面方向 → 减少引导线 → 加脊线 → 用“通过曲线网格”替代。
**预防**：截面用同一草图阵列/偏置生成，天然同向。

---

## 2. 通过曲线网格失败

**排查**：
1. `分析(L)` → `测量(S)...` 测主曲线与交叉曲线交点误差；超公差就失败。
2. 放大“交点公差”到 0.01–0.1 mm 试。
3. 检查主/交叉曲线顺序是否连续、有无重复选择。

**修复**：修曲线使其真相交 → 调公差 → 重选顺序。
**预防**：先做交点（`插入(S)` → `基准/点(D)` → `交点`），再铺面。

---

## 3. 曲面有棱、不连续

**排查**：
1. `分析(L)` → `形状(H)` → `曲面连续性(C)...` 看接缝是 G0/G1/G2。
2. `分析(L)` → `形状(H)` → `反射(R)...` 斑马线是否断开。
3. 检查两面边界是否真正重合（`分析(L)` → `测量(S)...`）。

**修复**：先 `匹配边(H)...` 做 G1，再 G2；或 `桥接(B)...` 生成过渡面。
**预防**：铺面时直接选相邻面做 G1/G2 约束，不要事后补。

---

## 4. 缝合失败、有缝隙

**排查**：
1. 放大缝隙处，看是“边不重合”还是“面重叠”。
2. 缝合公差 0.001 → 0.01 → 0.05 逐级试。
3. `分析(L)` → `形状(H)` → `曲面连续性(C)...` 看边界偏差值。

**修复**：延伸片体补缝 → 修剪重叠 → 提高公差（不超过 0.1）。
**预防**：铺面时边界共用同一曲线；不要“目测对齐”。

---

## 5. 加厚失败

**排查**：
1. `分析(L)` → `形状(H)` → `半径(R)...` 找最小曲率半径；厚度必须小于它。
2. 检查是否有尖角/收敛点；这些位置无法偏置。
3. 试“单侧/两侧”加厚，或分割面后分段加厚。

**修复**：减小厚度 → 倒圆角 → 分割面 → 用“片体到实体助理”。
**预防**：曲面设计时就按板厚留曲率半径（R ≥ 厚度）。

---

## 6. 偏置失败、自交

**排查**：
1. 偏置距离是否大于局部曲率半径。
2. 曲面是否有碎面/尖角；`分析(L)` → `形状(H)` → `半径(R)...`。
3. 试反向偏置/减小距离。

**修复**：减小距离 → 先整修面（`整修面(R)...`）→ 分割面分段偏置。
**预防**：偏置距离 ≤ 0.8×最小曲率半径。

---

## 7. 修剪片体失败

**排查**：
1. 检查边界是否完全贯穿片体；边界短于片体会剪不干净。
2. 投影方向是否与片体平行（平行会退化）。
3. 边界是否闭合/自交。

**修复**：延伸边界 → 改投影方向为法向 → 用“分割面”替代。
**预防**：边界曲线先在片体上投影（`曲面上的曲线`）。

---

## 8. 填充曲面鼓包

**排查**：
1. 检查边界是否 G1/G2；边界有棱会鼓包。
2. 看“控制点”是否被拖动；恢复默认。
3. 试“修剪/不修剪”与“相邻面”选项。

**修复**：边界先匹配 G1 → 减少控制点 → 用 N 边曲面替代。
**预防**：补洞边界先光顺，再填充。

---

## 9. 导入曲面碎面多

**排查**：
1. `分析(L)` → `形状(H)` → `曲面连续性(C)...` 看碎面接缝。
2. 试 `插入(S)` → `组合(B)` → `缝合(W)...` 合并。
3. `编辑(E)` → `曲面(R)` → `整修面(R)...` 重拟合。

**修复**：缝合 → 整修面 → 优化面（同步建模 → 优化面）。
**预防**：导入前要求对方导出实体/高质量曲面；不要导入 STL 当曲面用。

---

## 10. 曲面无法转实体

**排查**：
1. `分析(L)` → `测量(S)...` 测片体体积；体积=0 表示未闭合。
2. 缝合后看体类型（片体/实体）。
3. 检查是否有内部自由边（未缝合边界）。

**修复**：补缝 → 缝合 → `构造实体(K)...` 或 `加厚(T)...`。
**预防**：缝合后立即测体积，别等到出图才发现是片体。
