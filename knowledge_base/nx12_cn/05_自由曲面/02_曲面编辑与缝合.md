# 05-02 曲面编辑、缝合与实体化

> 曲面构建只是第一步；能“修剪—缝合—加厚成实体”才算完成。本文件给出编辑链与判据。

## 3. 曲面分析

| 分析 | 路径 | 判据 |
| :--- | :--- | :--- |
| 曲面连续性 | `分析(L)` → `形状(H)` → `曲面连续性(C)...` | G0/G1/G2；接缝无突变 |
| 曲面相交 | `分析(L)` → `形状(H)` → `曲面相交(I)...` | 相交线质量；无重叠 |
| 半径分析 | `分析(L)` → `形状(H)` → `半径(R)...` | 最小半径 > 刀具半径（CAM） |
| 反射/斑马线 | `分析(L)` → `形状(H)` → `反射(R)...` | 斑马线连续=曲面光顺 |
| 偏差 | `分析(L)` → `形状(H)` → `偏差(D)...` | 与点云/理论面偏差 |

## 4. 缝合标准流程（片体 → 实体）

1. `分析(L)` → `形状(H)` → `曲面连续性(C)...` 检查接缝；
2. `插入(S)` → `组合(B)` → `缝合(W)...`；
3. 目标选最大片体，工具框选其余；
4. 公差 0.001–0.01 mm（先小后大）；
5. 确定后看体类型：仍是片体说明有缝隙；
6. `分析(L)` → `测量(S)...` 测体积：体积 > 0 = 已闭合实体；
7. 需要壁厚：`加厚(T)...`，厚度 < 最小曲率半径。

## 5. 偏置与加厚的边界

| 参数 | 合法范围 | 失败原因 | 处理 |
| :--- | :--- | :--- | :--- |
| 偏置距离 | 任意实数 | 自交（距离 > 曲率半径） | 减小距离/分割面 |
| 加厚厚度 | > 0 | 自交/尖角 | 减小厚度/倒圆角 |
| 缝合公差 | 0.0001–1 mm | 缝不上 | 0.001–0.01；先修缝隙 |
| 桥接连续性 | G0/G1/G2 | 匹配失败 | 先 G0 再 G1/G2 |
| 扩大 UV | 受面片范围限制 | 无法扩大 | 用“延伸片体” |

## 6. 最佳实践

1. 缝合前把片体放同一图层，避免漏选。
2. 缝合公差不要一上来 0.1 mm——会把不该合的边粘在一起。
3. 加厚前检查最小曲率半径：`分析(L)` → `形状(H)` → `半径(R)...`。
4. 外观件做“斑马线/反射”检查，不要只看着色。
5. 曲面转实体后，用 `分析(L)` → `测量(S)...` 复核体积/壁厚。
6. 交付前 `文件(F)` → `全部保存(V)`，片体与实体分层存放。

## 7. 证据

- 命令/路径：`catalog/nx12_cn_commands.json`（`UG_MODELING_FF_*`、`UG_MODELING_EDIT_FF_*`）。
- 公差/厚度范围以 NX 对话框为准；失败边界为几何经验。
