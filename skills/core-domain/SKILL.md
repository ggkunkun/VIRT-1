# 定量工程纪律：单位、基准、链闭合

> 数字没有单位等于没有数字；公差必须闭合。

## domain.unit_datum — 单位、基准、坐标系

**何时适用**：任何几何、力、温度、时间的定量计算。

**步骤**

1. 每个数写单位；换算写系数与方向。
2. 明确基准：从哪测量、原点在哪、哪个面是 A 基准。
3. 明确坐标系手性、轴向、单位制。
4. 跨系统传递时做一次往返换算校验（A→B→A 应回原值）。

**硬约束**

- 无单位数值不得进入计算或交付。
- 换算不得连续近似，只在最终结果取整。

**验收门**

- `G-DOMAIN-UNIT`：所有量有单位，基准与坐标系已声明，往返换算误差 < 0.1%。
- 判失败：mm 与 inch 混算，或基准面未定义。

**反例（真实踩过的坑）**

- 把直径当半径代入应力公式，FOS 差 4 倍。
- CAD 里 Y 向上、CAE 里 Z 向上，载荷方向错。

## domain.tolerance_chain — 公差链闭合

**何时适用**：给出配合、装配间隙、形位公差。

**步骤**

1. 列出组成环：每个尺寸的上下偏差。
2. 封闭环 = 增环之和 − 减环之和；极值法算最坏情况。
3. 校核：最坏间隙 ≥ 0（动配合）或最坏过盈 ≤ 0（静配合）。
4. 形位公差不得大于尺寸公差（除非有补偿说明）。

**硬约束**

- 不得用名义尺寸代替最坏情况校核。
- 公差值必须来自标准表，不得凭经验编。

**验收门**

- `G-DOMAIN-TOL`：封闭环最坏值已算，且与设计意图一致。
- 判失败：只给名义值，或形位公差 > 尺寸公差。

**反例（真实踩过的坑）**

- 名义上能装，最坏情况卡死。
- 平行度标 0.05 而厚度公差 ±0.1。

## domain.manufacturability_first — 可制造性优先于几何优美

**何时适用**：做任何要落地的结构设计。

**步骤**

1. 先定工艺路线（车/铣/钣金/增材），再定几何。
2. 检查：刀具可达、最小内圆角、深径比、壁厚均匀、装夹基准。
3. 标注基准面与夹持面，确保能装夹两次以内完成。
4. 给出检验方案：哪些尺寸必须三坐标，哪些卡尺即可。

**硬约束**

- 不可加工的特征必须在设计阶段标出，不得留给工艺兜底。
- 深径比 >5 的孔必须说明加工方式。

**验收门**

- `G-DOMAIN-DFM`：工艺路线 + 可达性 + 装夹 + 检验四项齐备。
- 判失败：几何可建但无法装夹或刀具进不去。

**反例（真实踩过的坑）**

- 设计了个内腔，铣刀直径大于腔口。
- 壁厚 0.8mm 却要求铣削，变形无法控制。

## 输出契约

执行本族任一原子后，输出必须包含：所用原子 id、实际执行的检查、检查的原始输出（或摘要）、
以及 `measured` / `asserted` / `insufficient` 三档证据等级。无证据不得写 `measured`。
