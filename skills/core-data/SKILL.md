# 数据分析与量化表达

> 先看分布，再谈均值；先问分母，再谈比例。

## data.profile_first — 先画像再计算

**何时适用**：拿到任何表格/日志/数据集。

**步骤**

1. 行数、列数、类型、缺失率、重复率、时间范围。
2. 每个数值列看 min/p50/p95/max，找量级异常与哨兵值（-1、9999、空串）。
3. 确认单位与口径（元/万元、件/台、含税/不含税）。
4. 以上写完再算目标指标。

**硬约束**

- 未做缺失与异常检查，不得输出聚合结论。
- 发现哨兵值必须显式处理并说明处理方式。

**验收门**

- `G-DATA-PROFILE`：输出含 shape / 缺失 / 异常 / 口径四项。
- 判失败：直接给均值或图表，无数据质量说明。

**反例（真实踩过的坑）**

- 把 -1 当真实值算进平均。
- 混用含税与不含税列做同比。

## data.denominator — 分母与口径陷阱

**何时适用**：出现任何比率、增速、占比。

**步骤**

1. 写出分子、分母、时间窗三个定义。
2. 检查分母是否为 0 或极小（小基数放大）。
3. 检查口径是否变化（统计范围、去重规则、汇率）。
4. 同时给绝对值，避免只看比率。

**硬约束**

- 小基数（<30）的百分比必须附绝对值。
- 口径变更必须重算基期，不得直接比较。

**验收门**

- `G-DATA-DENOM`：每个比率都写出分子/分母/窗口。
- 判失败：出现无定义的'增长了 200%'。

**反例（真实踩过的坑）**

- 从 3 单涨到 9 单说'增长 200%'。
- 口径扩了区域还说'同店增长'。

## data.chart_choice — 图表按问题选，不按好看选

**何时适用**：需要用图表达数据关系。

**步骤**

1. 先定问题：比较/构成/趋势/分布/相关。
2. 比较→条形；构成→堆叠条或饼（≤5 类）；趋势→折线；分布→直方/箱线；相关→散点。
3. 轴从 0 开始（条形必须），标注单位与时间范围。
4. 颜色只承载一个维度；涨跌遵循中文语境（涨红跌绿）。

**硬约束**

- 禁止用双 Y 轴制造虚假相关。
- 饼图类别 >5 时改用条形。

**验收门**

- `G-DATA-CHART`：图表类型与问题类型匹配，轴/单位/时间齐全。
- 判失败：用截断轴的条形图夸大差异。

**反例（真实踩过的坑）**

- 所有数据都画折线，包括无序类别。
- 截断 Y 轴让 2% 差异看起来像 200%。

## 输出契约

执行本族任一原子后，输出必须包含：所用原子 id、实际执行的检查、检查的原始输出（或摘要）、
以及 `measured` / `asserted` / `insufficient` 三档证据等级。无证据不得写 `measured`。
