# 信息检索与事实核验

> 搜到不等于对；对不等于够；够不等于能引用。

## research.query_ladder — 查询阶梯：宽→窄→反证

**何时适用**：需要外部事实、版本号、价格、标准条款、API 用法时。

**步骤**

1. 第 1 跳：用领域词 + 目标词做宽搜，确认这东西的正式名称（避免用错词搜空）。
2. 第 2 跳：拿正式名称 + 限定词（版本/年份/标准号/厂商）收窄。
3. 第 3 跳：搜反证——'X 不支持''X deprecated''X 报错'，专门找推翻自己的材料。
4. 三跳都记录 query 原文，便于复现。

**硬约束**

- 只用一次搜索结果就下结论 = 未完成检索。
- 中文查不到时换英文正式名，反之亦然；不得据此断言'不存在'。

**验收门**

- `G-RESEARCH-LADDER`：至少有宽搜、窄搜、反证三类 query 各一条记录。
- 判失败：只有一次搜索，或反证检索缺失。

**反例（真实踩过的坑）**

- 用口语词搜技术概念，搜不到就写'该功能不存在'。
- 只看厂商宣传页，不看 issue 区的失败案例。

**相关工具**：web_search

## research.source_grading — 来源分级与采信规则

**何时适用**：任何将要写进交付物的外部事实。

**步骤**

1. 定级：A=标准/法规原文、官方文档、源码；B=厂商博客、同行评审论文；C=社区问答、教程；D=聚合站/自媒体/模型记忆。
2. A 可直接引用；B 需与 A 或第二份 B 对齐；C 只能作为线索去追 A/B；D 不得作为唯一依据。
3. 记录：标题、URL、访问日期、原文关键句（≤30 字）。
4. D 级信息若必须使用，显式标注'未经一手来源确认'。

**硬约束**

- 模型自身记忆一律按 D 级处理，不得伪装成检索结果。
- 同一事实的多个来源若同源转载，按一个来源计。

**验收门**

- `G-RESEARCH-GRADE`：每条外部事实都带等级 + URL + 关键句。
- 判失败：存在无来源的事实断言，或把 D 级当 A 级。

**反例（真实踩过的坑）**

- 把博客园的转载当官方文档引用。
- 三个网站抄同一篇通稿，被当成三方交叉验证。

**相关工具**：web_search, fetch_web_content

## research.triangulate — 冲突显式化，不取平均

**何时适用**：两个以上来源给出不同数值、版本或结论时。

**步骤**

1. 并列呈现每个说法 + 来源 + 时间。
2. 找差异根因：版本不同？口径不同？单位不同？地区不同？
3. 能判定就写判定依据；不能判定就写'存在分歧，采用 X 因为 Y'，并标风险。
4. 禁止把冲突值取中位数当结论。

**硬约束**

- 时间敏感事实以最新一手来源为准，并注明'截至 YYYY-MM-DD'。
- 不得隐藏与结论相悖的来源。

**验收门**

- `G-RESEARCH-CONFLICT`：冲突项已列出双方来源与差异根因。
- 判失败：只呈现支持自己的那一方。

**反例（真实踩过的坑）**

- 两个版本号不同，直接写'大约 2.x'糊过去。
- 把旧标准的公差值套到新标准上。

## research.no_source_no_claim — 无源不写

**何时适用**：产出任何面向他人的文档、报告、方案。

**步骤**

1. 每个数字问三件事：谁测的、怎么测的、什么时候测的。
2. 答不全 → 降级为'估计'并写明估算方法，或删掉。
3. 结论句后面挂证据锚点（文件路径/命令/URL/表号）。
4. 交付前做一遍'删除测试'：删掉所有形容词，看还剩什么事实。

**硬约束**

- 禁止编造引用、页码、DOI、标准条款号。
- 推算值必须与实测值在排版上可区分（如标'推算'）。

**验收门**

- `G-RESEARCH-NOSOURCE`：全文数字可追溯到来源或标注为推算。
- 判失败：出现无出处且未标注的精确数字。

**反例（真实踩过的坑）**

- 为了让报告好看，把'约 30%'写成'31.7%'。
- 编一个看起来合理的 GB/T 编号。

## 输出契约

执行本族任一原子后，输出必须包含：所用原子 id、实际执行的检查、检查的原始输出（或摘要）、
以及 `measured` / `asserted` / `insufficient` 三档证据等级。无证据不得写 `measured`。
